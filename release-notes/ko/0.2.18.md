# peetsfea 0.2.18

Release Date: `2026-03-16`

## 한 줄 요약
- 0.2.18은 기본 `TX vertical mode2` sample space를 안정화하기 위해 기본 vertical TX zone을 키우고 기본 TX-RX scene gap을 줄인 릴리즈다.

## Highlights
- 런타임/예제 스펙/패키지 버전과 문서 baseline을 `0.2.18`로 상향했다.
- 기본 runnable example의 `tx.region.z_parts.vertical_z_mm` 샘플 범위를 기존 `3..12`에서 `5..15`, `count=11`로 바꿨다.
- 실제 `tx_vertical` 높이는 계속 `min(coil_shape.tx_vertical.outer_y, tx.region.z_parts.vertical_z_mm)`을 따르므로, 기본 sample space에서는 사실상 `tx_region_vertical_z_mm`가 높이 owner처럼 동작한다.
- 기본 runnable scene은 `scene_anchor.shelf_height_mm = 461.0`을 사용해 기존 scene-anchor 공식 아래 nominal `TX-region top -> RX-region bottom` gap을 `50 mm`로 맞춘다.
- geometry topology, mode 2 winding/attachment, x-ratio naming, 현재 `YZ` guard-skip 정책은 이번 릴리즈에서 바꾸지 않는다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.18"`만 허용한다.
- versioned run output directory prefix도 `0.2.18`로 바뀐다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.18"`이 현재 공개 버전이다.
- 0.2.18에서는 새 TOML path, manifest field, CLI option을 추가하지 않는다.

## Validation & Tests
- version string 테스트, versioned output-path 테스트, removed-path validation 테스트를 모두 `0.2.18` 기준으로 갱신했다.
- `run/type1.toml`과 `examples/type1.toml`의 tuned 기본 `vertical_z_mm`, `shelf_height_mm` 값이 drift 없이 유지되도록 regression coverage를 추가했다.
