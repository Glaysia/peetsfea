# peetsfea 0.2.12

Release Date: `2026-03-09`

## 한 줄 요약
- 0.2.12는 sampling ownership과 replay/dataset 계약을 canonical owner 기준으로 고정하고, ferrite 경로와 adaptive 기본값을 단순화한 릴리즈다.

## Highlights
- `dataset.toml`의 의미를 최종 설계에 영향을 주는 canonical sampled owner ledger로 고정하고, inline sampled owner(`coil_groups[*].count_*`)를 포함하도록 정리했다 (`src/peetsfea/pipeline/selection_snapshots.py`, `tests/test_v027_snapshot_contract.py`).
- `repro.toml`을 exact replay artifact로 유지하고, `dataset.toml`과의 대응 관계로 replay safety를 정의했다 (`src/peetsfea/pipeline/run_design.py`, `PLANS/DIVIDE_AND_CONQUER/V0_2_11_00C_REPLAY_DATASET_AND_SEEDSET_CONTRACT.md`).
- 샘플링 ownership registry/preflight를 정리해 alias/derived path가 독립 sampled dimension으로 세어지지 않도록 고정했다 (`src/peetsfea/spec/resolver/sampling.py`, `tests/test_sampling_registry.py`).
- ferrite 제어를 전역 `[ferrite.present]` 하나로 통합하고, RX/TX 모두 실제 코일 footprint 기준 ferrite 배치를 계약으로 확정했다 (`examples/type1.toml`, `src/peetsfea/backend/pyaedt/geometry/build.py`, `tests/test_ferrite_geometry.py`).
- adaptive 기본 정책을 `percent_refinement=20`, `maximum_passes=20`, `max_delta_s=0.007`로 정리했다 (`src/peetsfea/backend/pyaedt/em_pipeline/contracts.py`, `tests/test_em_pipeline.py`).
- `sample.py`는 full-space TOML에서 eager uniform selection으로 sampled TOML들과 `run/toml/manifest.json`을 생성하고, `build.py`는 sampled TOML만을 단일 입력 경로로 받아 AEDT를 만든다. build 산출물은 sampled TOML stem을 그대로 따르며, 생성 후 `.aedtresults`를 정리한다 (`sample.py`, `build.py`, `tests/test_run_script_artifacts.py`).
- `tx_dd`가 2층(4 instances)일 때는 아래층 centerline box를 one-pitch inset 해 위층 trace 사이 gap 중심 쪽으로 interleave되도록 만들고, 같은 footprint 안에서 층간 broadside overlap을 줄이는 고정 형상 규칙을 적용한다 (`src/peetsfea/backend/pyaedt/geometry/group_builder_tx_dd.py`, `tests/test_tx_dd_endpoint_rule.py`).

## Breaking Changes / Migration
- 런타임은 `spec_version == "0.2.12"`만 허용한다 (`src/peetsfea/pipeline/run_design.py`, `examples/type1.toml`).
- 구형 스펙 경로 일부는 제거되었고, 접근 시 즉시 실패한다 (`src/peetsfea/spec/resolver/path_access.py`, `tests/test_manifest_validation.py`).
- `pcbs[*].present`와 `mounts`는 0.2.12 fixed-topology 규칙에 따라 정규화되며, 임의 토폴로지 입력을 그대로 유지하지 않는다 (`src/peetsfea/spec/resolver/pcbs.py`).
- 기본 산출물 설명은 `.aedt + repro/dataset/source snapshot` 기준이며, zip export는 현재 임시 비활성 상태다 (`README.md`, `tests/test_v027_zip_payload.py`).
- `run.py`는 제거되었고, 실행/디버그 엔트리포인트는 `sample.py`와 `build.py`로 분리됐다 (`.vscode/launch.json`, `.vscode/tasks.json`).
- direct full-space TOML -> AEDT 경로는 제거되었고, `build.py`는 sampled TOML만 입력으로 받는다.
- build 입력 TOML은 모든 sampling owner가 frozen(`count == 1` 및 동일 bound) 상태여야 하며, 그렇지 않으면 preflight에서 즉시 실패한다 (`src/peetsfea/pipeline/selection_snapshots.py`, `tests/test_run_script_artifacts.py`).

## Public API / Interface Changes
- 스펙 버전은 `SUPPORTED_SPEC_VERSION = "0.2.12"`로 고정됐다 (`src/peetsfea/pipeline/run_design.py`, `src/peetsfea/__init__.py`).
- `RunResult`의 핵심 snapshot 계약은 `source_toml_bytes`, `repro_snapshot`, `dataset_snapshot` 중심으로 유지된다 (`src/peetsfea/types/manifest.py`, `src/peetsfea/pipeline/run_design.py`).
- `dataset.toml`은 derived alias와 fixed field를 제외하고, 실제 설계에 영향 주는 canonical sampled owner만 export한다 (`src/peetsfea/pipeline/selection_snapshots.py`, `README.md`).
- ferrite 공개 spec path는 `[ferrite.present]`, `[ferrite.rx_thickness_mm]`, `[ferrite.tx_thickness_mm]`, `[ferrite.relative_permeability]` 기준으로 정리됐다 (`examples/type1.toml`, `PLANS/DIVIDE_AND_CONQUER/V0_2_11_01_SPEC_AND_POLICY.md`).
- `run/toml/manifest.json`이 build source of truth이며, 각 entry는 sampled TOML 절대경로와 sample-stage identity(`design_id`, `design_unique_hash`, `toml_space_hash`)를 포함한다 (`src/peetsfea/pipeline/run_batch.py`, `build.py`).
- `build.py`는 sampled TOML stem을 최종 AEDT basename으로 사용하고, build 전에 frozen sampling spec 검증을 적용한다 (`src/peetsfea/pipeline/run_batch.py`, `src/peetsfea/pipeline/selection_snapshots.py`).

## Upgrade Checklist
- 입력 TOML `spec_version`을 `0.2.12`로 고정한다.
- removed path를 새 경로로 옮기고, ferrite 제어를 전역 `ferrite.present` 기준으로 단순화한다.
- downstream이 `dataset.toml`을 읽는다면 canonical sampled owner ledger 의미에 맞춰 경로/차원 가정을 갱신한다.
- zip 산출물에 의존했다면 현재는 snapshot 기반 산출물 계약을 읽도록 조정한다.
- 기존 `run.py` 기반 워크플로가 있었다면 `sample.py -> run/toml/manifest.json -> build.py` 경로로 전환한다.
- CI에 replay/dataset/sampling registry 회귀 테스트를 포함한다.

## Known Limits
- zip export 플래그는 타입 호환성을 위해 남아 있지만 실제 zip 파일은 현재 생성하지 않는다.
- `run/toml/<design_id>.toml`은 runner 편의 산출물이며, 공개 replay contract는 계속 `repro.toml`이다.
- eager uniform selection은 현재 `sample.py`에 하드코딩된 small-range profile(`0..2000`에서 `500`개 선택) 기준으로 동작한다.
