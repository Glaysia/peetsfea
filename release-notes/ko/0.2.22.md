# peetsfea 0.2.22

Release Date: `2026-04-13`

## 한 줄 요약
- 0.2.22는 현재 런타임 계약은 유지한 채 공개 패키지/스펙/문서 버전을 `0.2.22`로 올리는 baseline-sync 릴리즈다.

## Highlights
- 공개 패키지 버전, 지원 `spec_version`, runnable example, fixtures, 문서, versioned run-output 기대값을 `0.2.22`로 동기화했다.
- 기존 런타임/스펙 동작은 유지하며, 이번 릴리즈는 topology나 파이프라인 동작 변경이 아니라 버전 라인 상향에 집중한다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.22"`만 허용한다.
- 기존 `0.2.21` TOML은 `0.2.22`로 올린 뒤 실행해야 한다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.22"`이 현재 공개 baseline이다.
- versioned sample/build output directory prefix도 `0.2.22`로 바뀐다.

## Runtime / Debug Notes
- 이번 릴리즈에서는 새 runtime flag, TOML path, fallback path를 추가하지 않는다.

## Validation
- `.venv/bin/pytest tests/pipeline_runs/test_manifest_validation.py tests/pipeline_runs/test_run_script_sample_artifacts.py tests/pipeline_runs/test_run_script_build_artifacts.py -q`
