# peetsfea 0.2.16

Release Date: `2026-03-15`

## 한 줄 요약
- 0.2.16은 저장소 baseline을 0.2.16으로 올리고, TX ferrite 비접촉 계약과 전 그룹 3턴 상한을 고정한 릴리즈다.

## Highlights
- 런타임/예제 스펙/패키지 버전과 문서 baseline을 `0.2.16`으로 상향했다.
- TX ferrite gap은 새 sampled path `ferrite.tx_gap_mm`가 소유하며, 기본 예제 range는 `3.1..12.0`, `count=8`이다.
- TX ferrite는 최하단 TX XY FR4 아래 그 gap을 유지하고, 캡처된 TX coil copper, TX bridge object, TX port sheet object, TX FR4 sheet object와 접촉하면 실패하도록 계약을 강화했다.
- `tx_dd`, `tx_vertical`, `rx_dd` 전 그룹의 `turn_count_max`를 `1..3`으로 제한했다.
- 기본 예제의 `coil_shape.tx_dd.outer_x` 하한을 `60.0mm`에서 `30.0mm`로 낮춰 더 작은 TX X-span 샘플도 직접 탐색할 수 있게 했다.
- TX DD 상단 배치 자유변수는 이제 `coil_placement.tx_dd_top_clearance_ratio`가 소유하고, 기본 예제 range는 `0.0..0.3`, `count=10`이다. 내부 `tx_dd_top_clearance_mm`는 `tx.region.z_parts.dd_z_mm`에 대한 파생값으로만 유지된다.
- AEDT output variable/report 생성은 이제 공개 `[outputs]` TOML 블록이 SSOT가 된다.
- 기본 출력 세트에 `S22_mag_ratio`와 WPT 중심 파생 효율 지표 8개를 추가했다.
- 1턴 케이스가 selection/constraint/geometry helper 경로에서 통과하는 pure-Python 계약 테스트를 추가했다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.16"`만 허용한다.
- `coil_groups_params.{tx_dd,tx_vertical,rx_dd}.turn_count_max > 3` 스펙은 더 이상 허용되지 않는다.
- 스펙은 이제 하나 이상의 `[[outputs.variables]]`를 가진 유효한 `[outputs]` 블록을 포함해야 한다.
- 기존 `coil_placement.tx_dd_top_clearance_mm` path는 제거됐고, 공개 스펙은 `coil_placement.tx_dd_top_clearance_ratio`만 사용해야 한다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.16"`이 현재 공개 버전이다.
- 기존 `ferrite.tx_thickness_mm` 배치 의미는 유지하되 더 엄격해졌고, 새 공개 TOML path `[outputs]`, `coil_placement.tx_dd_top_clearance_ratio`가 계약에 포함됐다.

## Validation & Tests
- 버전 검증, removed-path/fixed-topology 메시지, run-script artifact 테스트를 `0.2.16` 기준으로 갱신했다.
- TX ferrite gap 계약과 전 그룹 1턴/3턴 제한을 pure-Python 테스트로 고정했다.
- `tx_dd_top_clearance_ratio -> tx_dd_top_clearance_mm` 파생과 제거된 예전 `coil_placement.tx_dd_top_clearance_mm` path 거부를 pure-Python 테스트로 고정했다.
- TOML-driven output parsing, placeholder 치환, `S22`, 새 `eta_*` 식은 parser/EM pipeline 테스트로 고정했다.
