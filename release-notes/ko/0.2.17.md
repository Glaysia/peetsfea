# peetsfea 0.2.17

Release Date: `2026-03-15`

## 한 줄 요약
- 0.2.17은 TX vertical에 두 번째 layout mode를 추가하고, 그 공개 스펙 계약을 `layout_mode + mode2 x-ratio` 기준으로 재정리한 릴리즈다.

## Highlights
- 런타임/예제 스펙/패키지 버전과 문서 baseline을 `0.2.17`으로 상향했다.
- `coil_placement.tx_vertical_layout_mode` sampled path를 추가했다. `1`은 기존 `ZX` 모드, `2`는 새 `YZ` 모드다.
- `coil_spacing.tx_vertical_mode2_pair_spacing_ratio` sampled path를 추가했다. 기본 예제 range는 `0.0..0.03`, `count=25`이며 `tx.region.outer_h_mm` 기준 mode-2 internal pair gap을 소유한다.
- `coil_placement.tx_vertical_mode2_x_ratio_to_tx_dd_center` sampled path를 추가했다. 현재 기본 예제 range는 `0.7..1.0`, `count=10`이다.
- mode 2에서는 TX vertical 코일이 `YZ` plane의 opposite-wound RX-DD-style vertical DD pair 1개로 생성되고, internal pair gap은 `tx_vertical_mode2_pair_spacing_ratio * tx.region.outer_h_mm`로 결정되며, `X`는 `tx_dd_min_x + ratio * tx_dd_outer_x` 공식으로 배치된다. 즉 `1.0`은 underlying TX DD 폭의 RX-far edge를 뜻한다.
- RX DD와 TX vertical mode 2의 내부 DD 연결은 이제 중앙/근접 직선 bar 대신 RX-DD-style back-stub route를 사용한다.
- mode 2 TX vertical attachment routing을 조정해서 실제 구동 전류 방향도 의도대로 고정했다. `+X` 시점 기준으로 오른쪽 `(+Y)` half는 시계방향(`-X` local B), 왼쪽 `(-Y)` half는 반시계방향(`+X` local B)이다.
- TX DD의 TX 포트 sheet도 diagonal pairing을 사용해 TX 급전 topology를 nearest-start rectangle에서 대각선 pairing으로 바꿨다.
- 기본 예제의 `turn_count_max`는 `tx_dd`, `tx_vertical`, `rx_dd` 모두 `2..3` 범위를 사용하고, 런타임 validation 상한도 `3`이다.
- 기본 예제의 `coil_groups.tx_vertical.count_range`는 `1`로 고정했고, 커스텀 spec에서 mode 2에 더 큰 count를 줘도 realized `selected_count`는 `1`로 clamp 된다.
- TX `YZ` FR4가 생겨도 RX `YZ` FR4 subtraction과 섞이지 않도록 FR4 subtraction을 board role 기준으로 분리했다.
- RX ferrite footprint 계산은 이제 RX board의 `YZ` coil bbox만 사용하므로, TX vertical mode 2의 `YZ` bbox가 있어도 RX ferrite 배치가 오염되지 않는다.
- mode 2 feasibility hotfix로, legacy `Y`-side `tx_bridge_no_pierce` / `tx_bridge_right_y_margin_ok` guard는 `YZ` plane에서 skip 처리된다. 이 guard는 현재 `ZX` 전용 계약으로만 유지한다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.17"`만 허용한다.
- 공개 스펙은 더 이상 `coil_placement.tx_vertical_plane` path를 받지 않는다.
- `selected_parameters.tx_vertical_plane`는 입력이 아니라 realized output이다. 값 범위는 이제 `"ZX" | "YZ"`다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.17"`이 현재 공개 버전이다.
- `selected_parameters`에 `tx_vertical_layout_mode`, `tx_vertical_mode2_pair_spacing_ratio`, `tx_vertical_mode2_pair_spacing_mm`, `tx_vertical_mode2_x_ratio_to_tx_dd_center`가 추가됐다.
- AEDT design variable export는 새 `tx_vertical_layout_mode`를 정수, 새 pair-spacing ratio/x-ratio를 unitless float로 직렬화한다.

## Validation & Tests
- sampling registry, dataset owner path, replay path가 새 sampled owner 3개를 포함하도록 갱신했다.
- 제거된 `coil_placement.tx_vertical_plane` path 거부와 `layout_mode -> realized plane` 파생을 pure-Python 테스트로 고정했다.
- mode 2용 TX vertical bridge helper, ferrite filtering, FR4 subtraction 분기를 pure-Python 테스트로 보강했다.
