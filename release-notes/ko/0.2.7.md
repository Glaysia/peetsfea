# peetsfea 0.2.7

Release Date: `YYYY-MM-DD`

## 한 줄 요약
- 0.2.7은 산출물 계약을 zip 중심으로 전환하고, 재현 스냅샷(`repro/dataset/source`) 및 고정 토폴로지 정규화를 도입한 릴리즈다.

## Highlights
- 기본 산출물 계약을 `<design_id>.zip`으로 전환하고 payload를 4개 파일로 고정했다 (`src/peetsfea/pipeline/package_export.py`, `tests/test_v027_zip_payload.py`).
- 실행 결과에 `repro_snapshot`, `dataset_snapshot`을 포함해 단일 설계 재현성과 입력 추적을 강화했다 (`src/peetsfea/pipeline/run_design.py`, `tests/test_v027_snapshot_contract.py`).
- `manifest.json`, `geometry_metadata.json`은 기본 비활성으로 전환했고 옵션 플래그로만 생성한다 (`src/peetsfea/pipeline/run_design.py`, `tests/test_v027_optional_outputs.py`).
- `spec_version 0.2.7` 고정 토폴로지 규칙으로 PCB present/mounts 입력을 정규화한다 (`src/peetsfea/spec/resolver/pcbs.py`).

## Breaking Changes / Migration
- 기존 `.aedt` 직접 참조 흐름은 기본 계약이 아니다. `<design_id>.zip` 해제 후 내부 파일을 참조하도록 변경해야 한다.
- 기본 실행에서는 `manifest_<design_id>.json`, `geometry_metadata_<design_id>.json`이 생성되지 않는다.
- 런타임은 `spec_version == "0.2.7"`만 허용한다 (`src/peetsfea/pipeline/run_design.py`).
- 이 프로젝트는 장기 하위호환을 보장하지 않는다. 메이저/마이너 릴리즈에서 계약이 변경될 수 있음을 전제로 업그레이드해야 한다.

## Public API / Interface Changes
- `RunConfig` 기본값: `emit_manifest_json=False`, `emit_geometry_metadata_json=False`, `export_zip=True` (`src/peetsfea/pipeline/run_design.py`).
- `RunResult` 계약: `zip_path`, `manifest_path`, `geometry_metadata_path`, `repro_snapshot`, `dataset_snapshot` (`src/peetsfea/types/manifest.py`, `src/peetsfea/pipeline/run_design.py`).
- 공개 API: `export_design_zip(...)` 노출 (`src/peetsfea/__init__.py`, `src/peetsfea/pipeline/package_export.py`).
- 스펙 버전: `SUPPORTED_SPEC_VERSION = "0.2.7"`, 예시 TOML도 `spec_version = "0.2.7"` (`src/peetsfea/pipeline/run_design.py`, `examples/type1.toml`).

## Validation & Tests
- zip 계약/결정론성: `tests/test_v027_zip_payload.py`
- snapshot 계약: `tests/test_v027_snapshot_contract.py`
- optional output 게이트: `tests/test_v027_optional_outputs.py`
- 회귀 경로: `tests/test_manifest_determinism.py`, `tests/test_manifest_validation.py`

## Upgrade Checklist
- 소비자 코드를 zip 중심 산출물 기준으로 수정한다.
- JSON 출력이 필요하면 `emit_manifest_json`, `emit_geometry_metadata_json`를 명시한다.
- `RunResult.zip_path` 및 snapshot 필드를 읽도록 인터페이스를 갱신한다.
- 입력 TOML `spec_version`을 `0.2.7`로 고정한다.
- CI에 `tests/test_v027_*` 계약 테스트를 포함한다.

## Known Limits
- 본 릴리즈는 시뮬레이션 결과 채움(후처리 수치 산출)을 포함하지 않는다.
