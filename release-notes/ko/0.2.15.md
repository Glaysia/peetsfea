# peetsfea 0.2.15

Release Date: `2026-03-11`

## 한 줄 요약
- 0.2.15는 저장소 baseline을 0.2.15로 올리고, AEDT 기준 입력/출력 회수를 위한 design-variable 정비를 포함한 릴리즈다.

## Highlights
- 런타임/예제 스펙/패키지 버전과 문서 baseline을 `0.2.15`로 상향했다.
- unfrozen input owner를 AEDT design variable로 더 완전하게 기록할 수 있도록 design-variable 수집 기준을 정비했다.
- fixed-topology/removed-path 관련 에러 메시지와 테스트 baseline도 `0.2.15` 기준으로 올렸다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.15"`만 허용한다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.15"`이 현재 공개 버전이다.

## Validation & Tests
- 버전 검증과 run-script artifact 테스트를 0.2.15 baseline에 맞게 갱신했다.
