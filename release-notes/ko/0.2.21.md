# peetsfea 0.2.21

Release Date: `2026-04-04`

## 한 줄 요약
- 0.2.21은 TX ferrite 생성 순서와 cutout 처리를 바로잡고, `entry/build.py`의 best-effort 배치 replay를 복원한 안정화 릴리즈다.

## Highlights
- 공개 패키지/스펙 baseline, examples, fixtures, 문서, versioned run-output naming을 `0.2.21`로 동기화했다.
- TX ferrite 생성 시점을 finalize 이후로 옮겨서, bridge/stub까지 포함된 finalized TX live object 집합을 기준으로 ferrite cutout이 적용되게 했다.
- ferrite subtract로 정상 처리 가능한 경우까지 막던 TX ferrite pre-subtract positive-gap 검사를 제거했다.
- `entry/build.py`는 다시 `stop_on_error=False`를 지원하며, 실패한 엔트리는 로그와 `False` 결과로 남기고 배치를 계속 진행한다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.21"`만 허용한다.
- 기존 `0.2.20` TOML은 `0.2.21`로 올린 뒤 실행해야 한다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.21"`이 현재 공개 baseline이다.
- 배치 build entrypoint는 기본적으로는 fail-fast를 유지하지만, `stop_on_error=False`일 때는 다시 best-effort replay를 지원한다.

## Runtime / Debug Notes
- ferrite subtract로 해결 가능한 TX ferrite overlap 케이스는 더 이상 ferrite placement 단계의 조기 검증에서 중단되지 않는다.
- `stop_on_error=False` 배치에서 worker가 실패하면 `entry/build.py`가 design id, TOML path, 예외 타입, traceback을 로그에 남기고 다음 설계로 진행한다.

## Validation
- false-positive TX ferrite pre-gap rejection이 사라진 뒤 `000014_759c_475e_0`는 정상 저장된다.
