# peetsfea 0.2.14

Release Date: `2026-03-11`

## 한 줄 요약
- 0.2.14는 저장소 baseline을 0.2.14로 올리고, adaptive EM 기본값을 완화했으며, sample/build 엔트리포인트 계약을 재사용 가능한 orchestration helper 기준으로 정리한 릴리즈다.

## Highlights
- 런타임/예제 스펙/패키지 버전과 문서 baseline을 `0.2.14`로 상향했다.
- adaptive 기본값을 `maximum_passes=15`, `minimum_converged_passes=10`으로 완화하고, 나머지 simulation 계약은 유지했다.
- `sample.py`는 함수 중심 모듈이면서 기본 batch sampling 스크립트 역할도 맡는다.
- `build.py`는 `sample.py`와 같은 seed window helper를 기준으로 paired manifest를 build한다.
- `sample_build.py`는 GUI-visible 단건 sample+build 디버그 플로우를 맡는다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.14"`만 허용한다.
- 지원 스펙 버전을 참조하는 fixed-topology/removed-path 에러 메시지도 `0.2.14` 기준으로 상향됐다.
- combined sample+build 기본 디버그 launch entrypoint는 `sample_build.py`다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.14"`이 현재 공개 버전이다.
- `sample.py`는 path helper들과 `generate_sample_manifest(seed_start, seed_end, target_count, ...)`를 제공한다.
- `build.py`는 `sample.py`와 같은 default seed window helper를 사용하고, 호출자는 여전히 `manifest_path`와 `ansys_run_dir`를 함께 넘길 수 있다.

## Validation & Tests
- 버전 검증, EM policy 기본값, launch config 기대값, sample/build orchestration 테스트를 0.2.14 baseline에 맞게 갱신했다.
