# peetsfea 0.2.13

Release Date: `2026-03-10`

## 한 줄 요약
- 0.2.13은 저장소 baseline을 0.2.13으로 올리고, TX 수직코일의 Z 최대 길이를 실제로 크게 줄였으며, 메쉬 최대 엘리먼트 상한도 700000으로 낮춰 실행 시간을 줄인 릴리즈다.

## Highlights
- 런타임/예제 스펙/패키지 버전을 `0.2.13`으로 상향하고, 문서 baseline도 0.2.13 기준으로 정리했다.
- `sample.py -> run/toml/manifest.json -> build.py` 실행 경로와 sampled-TOML-only build 계약은 그대로 유지한다.
- TX 수직코일(`tx_vertical`)의 Z 최대 길이를 실제로 대폭 줄였다. 큰 vertical Z span은 결합 개선에 유의미한 도움을 주지 않는다고 판단했다.
- HFSS setup의 최대 엘리먼트 상한을 `700000`으로 낮춰 지나치게 오래 걸리는 해석을 줄이도록 조정했다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.13"`만 허용한다.
- `spec_version 0.2.13` 기준 fixed-topology/removed-path 에러 메시지와 테스트 기대값도 함께 상향됐다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.13"`이 현재 공개 버전이다.
- simulation/geometry/build workflow의 큰 계약은 유지되지만, TX vertical geometry 쪽 기본 설계 방향과 EM 해석 상한 설정은 0.2.13 기준으로 조정됐다.

## Validation & Tests
- spec version validation 회귀와 sample/build workflow의 버전 문자열 의존 테스트를 함께 갱신했다.

## Known Limits
- zip export는 계속 비활성 상태다.
