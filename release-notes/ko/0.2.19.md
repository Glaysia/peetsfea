# peetsfea 0.2.19

Release Date: `2026-03-20`

## 한 줄 요약
- 0.2.19는 저장소 baseline 버전을 `0.2.19`로 상향하는 준비 릴리즈다.

## Highlights
- 런타임 지원 스펙 버전을 `0.2.19`로 올렸다.
- 예제 TOML과 테스트 fixture의 `spec_version` baseline을 `0.2.19`로 맞췄다.
- 버전 문자열과 versioned run output path 기대값 테스트를 `0.2.19` 기준으로 갱신했다.

## Breaking Changes / Migration
- 런타임은 이제 `spec_version == "0.2.19"`만 허용한다.
- versioned run output directory prefix는 `0.2.19`를 사용한다.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.19"`이 현재 공개 버전이다.
- 이번 변경은 버전 baseline 정리에만 집중하며 새 TOML path나 manifest field는 추가하지 않는다.

## 0.2.19 계획
- 이번 버전은 버전 baseline, simulation 기본값, 입력 검증, 스펙 path 정리, 새 자유변수, corner geometry, TX/RX 포트 계약 변경을 함께 묶는 릴리즈로 잡는다.
- 최우선 변경은 포트 연결 방식이다. `RX`만이 아니라 `TX`와 `RX` 둘 다 기존 포트 생성/연결 계약을 먼저 바꾼다.
- 새 자유변수 이름은 `coil_shape.corner_mode`로 고정하고, 값 의미는 `0=sharp_90`, `1=blunt`로 문서/테스트에 함께 명시한다.
- 이번 단계는 변수명 정리와 `examples/type1.toml` 주석 한글화를 우선 범위로 잡는다.
- `coil_shape.inner_margin_x`, `coil_shape.inner_margin_y`는 형상에 영향을 주지 않는 죽은 path로 보고 완전 제거한다.
- `coil_groups_params.{tx_dd,tx_vertical,rx_dd}.turn_count` 하한은 `1`로 낮추고, 런타임 validation은 계속 `1..3` 범위를 계약으로 유지한다.
- 사후 추가: `tx_dd`가 `1-turn`일 때 half-coil 중심선이 2점 선분으로 붕괴해 폐곡선이 끊어지는 문제가 확인됐고, `turn_count >= 1` 공개 계약을 실제 geometry까지 지키도록 `1-turn` 전용 right-half topology 복구를 포함한다.
- 사후 추가: `entry/sample_build.py`의 F5 debug flow는 새 sample 생성 1건 실행이 아니라, 미리 생성된 batch manifest들을 GUI-visible build로 순차 replay하고 `release_desktop()` 직전마다 같은 세션에서 반복 정지하는 방식으로 정리한다.
- 사후 추가: 모든 `DD` 코일(`tx_dd`, `rx_dd`, `tx_vertical`의 `YZ mode-2 DD pair`)은 두 half의 최종 자기장 방향이 항상 서로 반대여야 한다. 같은 방향으로 귀결되는 wiring/topology는 생성 금지 대상으로 본다.
- 사후 추가: `tx_dd`는 더 이상 `count_mode`나 `selected_count=2/4` 공개 계약을 쓰지 않는다. 공개 입력은 `stacked_mode=0/1`뿐이고, single-layer/stacked 의미만 문서화한다.
- 공개 path 이름은 아래처럼 정상화한다.
  - `coil_groups_params.*.turn_count_max` -> `coil_groups_params.*.turn_count`
  - `coil_placement.tx_vertical_layout_mode` -> `coil_placement.tx_vertical_orientation_mode`
  - `coil_placement.tx_dd_top_clearance_ratio` -> `coil_placement.tx_dd_top_offset_ratio`
- `coil_placement.tx_vertical_mode2_x_ratio_to_tx_dd_center`는 이번 버전에서 rename하지 않고, 문서와 TOML 주석에서 의미를 더 명확히 적는다.

## 작업 분할

### 1. TX/RX 포트 계약 변경
- TX와 RX 모두 기존 detached sheet 또는 기존 연결 계약을 재검토하고, 실제 도체 기준으로 port assignment가 이뤄지도록 바꾼다.
- `tx_dd -> tx_vertical` bridge는 더 이상 가까운 터미널/짧은 거리 heuristic으로 wiring하지 않고, ordered terminal section 기반 diagonal anti-parallel topology만 허용한다.
- RX DD는 stub 생성 후 main conductor와 unite한 다음 united conductor 기준 edge pair로 lumped port를 할당한다.
- TX도 같은 방향으로 정리해서, 포트가 별도 sheet 의존 계약이 아니라 실제 conductor 기준 계약이 되도록 맞춘다.
- 포트 생성 시 `TX_TML`, `RX_TML` 같은 custom excitation name은 별도로 지정하지 않는다.
- edge-based lumped port가 만든 실제 excitation 이름(`1`, `2`, `1_T1`, `2_T1` 등)은 생성 직후 TX/RX 역할별로 캡처해서 후처리까지 전달한다.
- `TX_TML`, `RX_TML`은 예제 TOML과 output/report 식에서만 쓰는 logical alias로 유지하고, 런타임이 실제 excitation 이름으로 치환한다.
- 관련 pure-Python geometry tests는 기존 detached port sheet 기대를 제거하고 conductor 기준 포트 회귀로 교체한다.
- 완료 기준: TX와 RX 모두 conductor 기준 포트 계약으로 정리되고, reversed source ordering이나 auto-generated excitation naming에서도 TX/RX 역할 매핑과 report/source 치환이 유지된다.

### 2. Baseline / Simulation
- 버전 baseline을 `0.2.19`로 고정한다.
- `[simulation]` 기본값을 `maximum_passes = 10`, `minimum_passes = 8`, `minimum_converged_passes = 10`, `percent_refinement = 22`로 바꾼다.
- 예제 TOML, fixture, 문서, 테스트의 기본값 문자열도 같은 값으로 맞춘다.
- 완료 기준: 런타임/예제/fixture/test baseline이 모두 `0.2.19`와 새 simulation 기본값으로 일치한다.

### 3. 입력 검증 / 제거 path
- `run()` 초기에 TOML basename 길이를 검사해 `30`자를 초과하면 즉시 실패시킨다.
- `coil_shape.inner_margin_x`, `coil_shape.inner_margin_y`를 scalar registry, selected parameter, manifest type, fixture, 문서, 테스트에서 제거한다.
- 특별취급 removed list를 늘리는 쪽보다, 공개 example/spec 계약에 없는 키는 그대로 실패시키는 방향을 기본 원칙으로 잡는다.
- 완료 기준: basename 30자는 통과, 31자는 실패하고, `inner_margin_x/y`는 selected parameter, manifest, hash, fixture 어디에도 남지 않는다.

### 4. 새 자유변수: `coil_shape.corner_mode`
- `coil_shape.corner_mode`를 integer sampled owner path로 추가한다.
- 형식은 `range = [true, 0, 1, 2]`를 기본 계약으로 잡는다.
- sampling registry, selected parameter, manifest, AEDT design-variable export, 문서에 함께 반영한다.
- 완료 기준: `corner_mode`가 sampling registry에 정확히 1회 canonical owner로 등록되고, manifest/AEDT design variable까지 내려간다.

### 5. Corner Geometry
- `corner_mode = 0`이면 현재 90도 형상을 그대로 유지한다.
- `corner_mode = 1`이면 코일 코너를 뭉툭하게 만든 형상을 생성한다.
- 구현은 가능하면 공통 중심선 생성부에서 처리해 `tx_dd`, `tx_vertical`, `rx_dd`가 같은 규칙을 공유하게 한다.
- winding, endpoint label, trace/gap/pitch 계산 계약은 유지한다.
- 완료 기준: `0`은 기존 형상과 동일, `1`은 뭉툭한 코너 형상이 나오고 self-crossing/zero-length segment가 없어야 한다.

### 6. RX DD Metal Ratio 조정
- 기본 runnable spec과 fixture의 `coil_groups_params.rx_dd.metal_ratio` range를 `0.40..0.90`으로 상향한다.
- validation/determinism/constraint/pcb-topology 테스트 기대 문자열도 새 baseline으로 맞춘다.
- 완료 기준: example/fixture/test가 모두 `0.40..0.90` baseline을 사용한다.

### 7. 변수명 정리 / TOML 주석 한글화
- `coil_groups_params.{tx_dd,tx_vertical,rx_dd}.turn_count_max`를 `turn_count`로 바꾼다.
- `coil_groups_params.{tx_dd,tx_vertical,rx_dd}.turn_count`의 공개 계약 하한을 `1`로 낮추고, 기존 `turn_count_max` 기준 구현/테스트도 1-turn acceptance를 유지한다.
- `tx_dd`의 `1-turn`은 unsupported로 막지 않고, `A->d` right-half path에 1-turn 전용 centerline topology를 둬서 single-layer와 four-layer upper-half 모두 폐곡선이 유지되게 한다.
- lower right `c->A`와 inter-layer `A` bridge 계약, port/source/report naming 계약은 유지한다.
- `DD` 계열 전체는 `nearest-terminal`, `shortest-cost`, `closest-edge` 같은 wiring heuristic을 active path에서 금지하고, 두 half의 최종 자기장 방향이 항상 반대인 topology를 불변식으로 강제한다.
- `tx_dd`는 `count_mode 2/4` 대신 `stacked_mode 0/1`만 사용하고, `selected_count=2/4`는 private local helper 안에서만 파생한다.
- `coil_placement.tx_vertical_layout_mode`를 `tx_vertical_orientation_mode`로 바꾼다.
- `coil_placement.tx_dd_top_clearance_ratio`를 `tx_dd_top_offset_ratio`로 바꾼다.
- `coil_placement.tx_vertical_mode2_x_ratio_to_tx_dd_center`는 이름은 유지하되, `tx_dd_min_x + ratio * tx_dd_outer_x` 식으로 mode2 vertical pair의 `center_x`를 정하는 비율이라는 설명을 문서와 주석에 명확히 적는다.
- `examples/type1.toml`의 영문 주석을 전부 한글로 바꾸고, 값 의미, 단위, 파생식, mode 값 의미, 제약 설명은 유지한다.
- `run/type1.toml`은 symlink이므로 별도 편집 대상에서 제외한다.
- 완료 기준: 공개 계약 문서와 테스트에 기존 이름이 남지 않고, `examples/type1.toml` 주석이 한글 기준으로 정리된다.

### 8. 검증 / 마감
- 최소 검증 범위는 version sync, simulation default, sampling registry, selection result, manifest validation, design vars, hashing, fixture sync, TX/RX geometry/port 회귀다.
- `coil_groups_params.{tx_dd,tx_vertical,rx_dd}.turn_count`가 공개 계약상 `1..3` 범위를 가지며, 1-turn selection/constraint/geometry regression이 유지되는지 확인한다.
- `tx_dd`의 `1-turn`에서 single-layer right와 four-layer upper right가 2점 선분으로 붕괴하지 않고, 최종 TX conductor가 연속 topology를 이루는지 확인한다.
- `tx_dd`, `rx_dd`, `tx_vertical YZ mode-2`에서 각 DD pair의 좌우 half가 같은 자기장 방향으로 귀결되는 케이스가 0건인지 확인한다.
- `entry/sample_build.py`를 F5로 실행하면 `prepare-build-debug` 이후 기존 manifest 전부를 seed_start 오름차순으로 replay build하고, `Continue` 시 다음 디자인으로 자동 진행되는지 확인한다.
- `turn_count`가 실제 확정 턴수로 내려가고, `tx_vertical_orientation_mode`가 `1=ZX`, `2=YZ`로 반영되며, `tx_dd_top_offset_ratio`가 기존 파생값 계산과 의미상 동일함을 확인한다.
- `.venv/bin/pytest`와 `.venv/bin/pyright` 기준으로 마감한다.
- 완료 기준: pure-Python 테스트 통과, pyright 에러 0.
