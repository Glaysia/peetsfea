# peetsfea 0.2.16

Release Date: `2026-03-15`

## One-line Summary
- 0.2.16 raises the repository baseline to 0.2.16 and locks in the TX ferrite non-contact contract plus the global 3-turn cap.

## Highlights
- Runtime, example spec, package version, and documentation baseline are all bumped to `0.2.16`.
- The TX ferrite gap is now owned by the sampled path `ferrite.tx_gap_mm`, with the default example range set to `3.1..12.0`, `count=8`.
- TX ferrite must keep that gap below the lowest TX XY FR4 layer and fail fast if it touches captured TX coil copper, TX bridge objects, TX port sheet objects, or TX FR4 sheet objects.
- `turn_count_max` is now limited to `1..3` for `tx_dd`, `tx_vertical`, and `rx_dd`.
- The default example now lowers the `coil_shape.tx_dd.outer_x` minimum from `60.0mm` to `30.0mm` so smaller TX X-span samples are explored directly.
- TX DD top placement is now owned by the sampled path `coil_placement.tx_dd_top_clearance_ratio`, with the default example range set to `0.0..0.3`, `count=10`. Internal `tx_dd_top_clearance_mm` is now kept only as a value derived from `tx.region.z_parts.dd_z_mm`.
- AEDT output-variable/report generation is now driven by the public `[outputs]` TOML block.
- The default output set now includes `S22_mag_ratio` and 8 WPT-centered derived efficiency metrics.
- Pure-Python contract tests now cover 1-turn selection/constraint/geometry-helper scenarios.

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.16"`.
- Specs with `coil_groups_params.{tx_dd,tx_vertical,rx_dd}.turn_count_max > 3` are no longer accepted.
- Specs must now provide a valid `[outputs]` block with one or more `[[outputs.variables]]` entries.
- The old `coil_placement.tx_dd_top_clearance_mm` path is removed; public specs must use `coil_placement.tx_dd_top_clearance_ratio` instead.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.16"` is now the public version baseline.
- `ferrite.tx_thickness_mm` keeps its meaning, but TX ferrite placement is stricter and the public contract now includes `[outputs]` plus `coil_placement.tx_dd_top_clearance_ratio`.

## Validation & Tests
- Version validation, removed-path/fixed-topology messages, and run-script artifact tests were updated to the `0.2.16` baseline.
- TX ferrite gap behavior and 1-turn/3-turn limits are now pinned by pure-Python tests.
- The `tx_dd_top_clearance_ratio -> tx_dd_top_clearance_mm` derivation and rejection of the removed `coil_placement.tx_dd_top_clearance_mm` path are now pinned by pure-Python tests.
- TOML-driven output parsing, placeholder substitution, `S22`, and the new `eta_*` formulas are covered by parser and EM pipeline tests.
