# peetsfea 0.2.14

Release Date: `2026-03-11`

## One-Line Summary
- 0.2.14 raises the repository baseline to 0.2.14, relaxes the adaptive EM defaults, and replaces direct `sample.py` execution with reusable sampling orchestration modules.

## Highlights
- Runtime, example spec, package metadata, and documentation baseline are all bumped to `0.2.14`.
- Adaptive defaults are relaxed to `maximum_passes=15` and `minimum_converged_passes=10`, while keeping the broader simulation contract unchanged.
- `sample.py` is now a function-oriented module with explicit sampling profile arguments instead of a direct-script entrypoint.
- `multi_sample.py` adds hardcoded profile orchestration for repeated sampling batches without introducing a CLI.
- `multi_build.py` adds hardcoded multi-manifest orchestration for repeated AEDT builds without manifest scanning.

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.14"`.
- Fixed-topology and removed-path error text that references the supported spec version is also bumped to `0.2.14`.
- The default debug launch entrypoint for sampling moves from `sample.py` to `multi_sample.py`.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.14"` is now the public version baseline.
- `sample.py` exposes path helpers plus `generate_sample_manifest(seed_start, seed_end, target_count, ...)`.
- `build.py` no longer imports a seed constant from `sample.py`; callers can pass both `manifest_path` and `ansys_run_dir`.

## Validation & Tests
- Version validation, EM-policy defaults, launch config expectations, and sample/build orchestration tests were updated for the 0.2.14 baseline.
