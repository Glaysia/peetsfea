# peetsfea 0.2.14

Release Date: `2026-03-11`

## One-Line Summary
- 0.2.14 raises the repository baseline to 0.2.14, relaxes the adaptive EM defaults, and standardizes the sample/build entrypoint contract around reusable orchestration helpers.

## Highlights
- Runtime, example spec, package metadata, and documentation baseline are all bumped to `0.2.14`.
- Adaptive defaults are relaxed to `maximum_passes=15` and `minimum_converged_passes=10`, while keeping the broader simulation contract unchanged.
- `sample.py` is now a function-oriented module that also serves as the default batch sampling script.
- `build.py` remains the paired manifest builder and derives its default manifest path from the `sample.py` seed window.
- `sample_build.py` is the dedicated GUI-visible single-sample debug flow.

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.14"`.
- Fixed-topology and removed-path error text that references the supported spec version is also bumped to `0.2.14`.
- The default debug launch entrypoint for combined sample+build flows is `sample_build.py`.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.14"` is now the public version baseline.
- `sample.py` exposes path helpers plus `generate_sample_manifest(seed_start, seed_end, target_count, ...)`.
- `build.py` uses the same default seed window helpers as `sample.py`, while callers can still pass both `manifest_path` and `ansys_run_dir`.

## Validation & Tests
- Version validation, EM-policy defaults, launch config expectations, and sample/build orchestration tests were updated for the 0.2.14 baseline.
