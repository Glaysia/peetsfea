# peetsfea 0.2.22

Release Date: `2026-04-13`

## One-line Summary
- 0.2.22 is a baseline-sync release that raises the public package/spec/documentation version to `0.2.22` without changing the current runtime contract.

## Highlights
- Synced the public package version, supported spec version, runnable example, fixtures, docs, and versioned run-output expectations to `0.2.22`.
- Kept the existing runtime/spec behavior intact; this release is a version-line bump, not a topology or pipeline behavior change.

- Runtime now accepts only `spec_version == "0.2.22"`.
- Older `0.2.21` TOML files must be bumped to `0.2.22` before they will run under the current baseline.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.22"` is the current public baseline.
- Versioned sample/build output directories now use the `0.2.22` prefix.

## Runtime / Debug Notes
- No new runtime flags, TOML paths, or fallback paths are introduced in this release.
