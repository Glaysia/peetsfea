# peetsfea 0.2.7

Release Date: `YYYY-MM-DD`

## One-line Summary
- 0.2.7 moves to a zip-first artifact contract and introduces reproducibility snapshots (`repro/dataset/source`) plus fixed-topology normalization.

## Highlights
- Default artifact contract is now `<design_id>.zip` with a fixed 4-file payload (`src/peetsfea/pipeline/package_export.py`, `tests/test_v027_zip_payload.py`).
- Run outputs now include `repro_snapshot` and `dataset_snapshot` for reproducibility and input traceability (`src/peetsfea/pipeline/run_design.py`, `tests/test_v027_snapshot_contract.py`).
- `manifest.json` and `geometry_metadata.json` are disabled by default and emitted only via explicit flags (`src/peetsfea/pipeline/run_design.py`, `tests/test_v027_optional_outputs.py`).
- Fixed topology rules for `spec_version 0.2.7` normalize PCB present/mount inputs (`src/peetsfea/spec/resolver/pcbs.py`).

## Breaking Changes / Migration
- Direct `.aedt`-only workflows are no longer the default contract. Consume extracted files from `<design_id>.zip`.
- Default runs no longer emit `manifest_<design_id>.json` and `geometry_metadata_<design_id>.json`.
- Runtime accepts only `spec_version == "0.2.7"` (`src/peetsfea/pipeline/run_design.py`).
- Long-term backward compatibility is not guaranteed. Assume major/minor releases may change contracts.

## Public API / Interface Changes
- `RunConfig` defaults: `emit_manifest_json=False`, `emit_geometry_metadata_json=False`, `export_zip=True` (`src/peetsfea/pipeline/run_design.py`).
- `RunResult` contract includes `zip_path`, `manifest_path`, `geometry_metadata_path`, `repro_snapshot`, `dataset_snapshot` (`src/peetsfea/types/manifest.py`, `src/peetsfea/pipeline/run_design.py`).
- Public API exposes `export_design_zip(...)` (`src/peetsfea/__init__.py`, `src/peetsfea/pipeline/package_export.py`).
- Spec version is fixed to `SUPPORTED_SPEC_VERSION = "0.2.7"` and the example TOML also pins `spec_version = "0.2.7"` (`src/peetsfea/pipeline/run_design.py`, `examples/type1.toml`).

## Validation & Tests
