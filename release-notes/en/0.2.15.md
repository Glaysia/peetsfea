# peetsfea 0.2.15

Release Date: `2026-03-11`

## One-Line Summary
- 0.2.15 raises the repository baseline to 0.2.15 and includes AEDT design-variable alignment for more direct input/output dataset extraction.

## Highlights
- Runtime, example spec, package metadata, and documentation baseline are all bumped to `0.2.15`.
- AEDT design-variable collection is aligned to better preserve unfrozen input owners for downstream dataset recovery.
- Fixed-topology and removed-path error text, plus versioned tests, are updated to the `0.2.15` baseline.

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.15"`.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.15"` is now the public version baseline.

## Validation & Tests
- Version validation and run-script artifact tests were updated for the 0.2.15 baseline.
