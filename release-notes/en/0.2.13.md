# peetsfea 0.2.13

Release Date: `2026-03-10`

## One-line Summary
- 0.2.13 raises the repository baseline to 0.2.13, materially reduces the TX vertical-coil maximum Z span, and lowers the mesh element ceiling to 700000 to keep solve time under control.

## Highlights
- Runtime, example spec, package metadata, and documentation baseline are all bumped to `0.2.13`.
- The `sample.py -> run/toml/manifest.json -> build.py` workflow and sampled-TOML-only build contract remain unchanged.
- For TX vertical coils (`tx_vertical`), the maximum Z span is now reduced in practice; large vertical Z spans are not considered meaningfully helpful for coupling.
- The HFSS setup now uses a mesh element ceiling of `700000` to cut down overly long solves.

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.13"`.
- Fixed-topology and removed-path error text that references the supported spec version is also bumped to `0.2.13`.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.13"` is now the public version baseline.
- The broader simulation/geometry/build contracts remain intact, but the TX vertical geometry direction and EM solve ceiling are adjusted in the 0.2.13 baseline.

## Validation & Tests
- Spec-version validation regressions and version-string-dependent sample/build workflow tests were updated together.

## Known Limits
- Zip export remains disabled.
