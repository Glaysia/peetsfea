# peetsfea 0.2.18

Release Date: `2026-03-16`

## One-line Summary
- 0.2.18 stabilizes the default `TX vertical mode2` sample space by increasing the default vertical TX zone and tightening the default TX-RX scene gap.

## Highlights
- Runtime, example spec, package version, and documentation baseline are bumped to `0.2.18`.
- The default runnable example now samples `tx.region.z_parts.vertical_z_mm` over `5..15`, `count=11`, replacing the earlier `3..12` window.
- Realized `tx_vertical` height still follows `min(coil_shape.tx_vertical.outer_y, tx.region.z_parts.vertical_z_mm)`, so in the default sample space the active height owner is effectively `tx_region_vertical_z_mm`.
- The default runnable scene now uses `scene_anchor.shelf_height_mm = 461.0`, which keeps the nominal `TX-region top -> RX-region bottom` gap at `50 mm` under the existing scene-anchor formula.
- Geometry topology, mode-2 winding/attachment, x-ratio naming, and the current `YZ` guard-skip policy remain unchanged in this release.

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.18"`.
- Versioned run output directories now use the `0.2.18` prefix.

## Public API / Interface Changes
- `SUPPORTED_SPEC_VERSION = "0.2.18"` is now the public version baseline.
- No new TOML paths, manifest fields, or CLI options are introduced in 0.2.18.

## Validation & Tests
- Version-string tests, versioned output-path tests, and removed-path validation tests are updated to `0.2.18`.
- Added regression coverage to keep `run/type1.toml` and `examples/type1.toml` aligned on the tuned default `vertical_z_mm` and `shelf_height_mm` values.
