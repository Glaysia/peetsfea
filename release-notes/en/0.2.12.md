# peetsfea 0.2.12

Release Date: `2026-03-09`

## One-line Summary
- 0.2.12 locks sampling ownership and replay/dataset semantics to canonical owners, while simplifying ferrite spec control and adaptive defaults.

## Highlights
- `dataset.toml` is now firmly defined as the ledger of canonical sampled owners that affect the final design, including inline sampled owners such as `coil_groups[*].count_*` (`src/peetsfea/pipeline/selection_snapshots.py`, `tests/test_v027_snapshot_contract.py`).
- `repro.toml` remains the exact replay artifact, and replay safety is defined by its correspondence with `dataset.toml` (`src/peetsfea/pipeline/run_design.py`, `PLANS/DIVIDE_AND_CONQUER/V0_2_11_00C_REPLAY_DATASET_AND_SEEDSET_CONTRACT.md`).
- Sampling ownership registry/preflight rules now prevent alias/derived paths from being counted as independent sampled dimensions (`src/peetsfea/spec/resolver/sampling.py`, `tests/test_sampling_registry.py`).
- Ferrite control is unified behind the global `[ferrite.present]` path, and RX/TX ferrite placement is standardized around the actual coil footprint (`examples/type1.toml`, `src/peetsfea/backend/pyaedt/geometry/build.py`, `tests/test_ferrite_geometry.py`).
- Adaptive defaults are standardized to `percent_refinement=20`, `maximum_passes=20`, and `max_delta_s=0.007` (`src/peetsfea/backend/pyaedt/em_pipeline/contracts.py`, `tests/test_em_pipeline.py`).
- `sample.py` now generates sampled TOMLs plus `run/toml/manifest.json` from the full-space TOML via eager uniform selection, and `build.py` consumes only sampled TOMLs as the single AEDT build path. Build outputs follow the sampled TOML stem and clean up `.aedtresults` after generation (`sample.py`, `build.py`, `tests/test_run_script_artifacts.py`).
- When `tx_dd` resolves to two stacked XY layers (4 instances), the lower layer uses a one-pitch inset centerline box so its traces interleave near the upper-layer gap centers within the same footprint, reducing broadside overlap (`src/peetsfea/backend/pyaedt/geometry/group_builder_tx_dd.py`, `tests/test_tx_dd_endpoint_rule.py`).

## Breaking Changes / Migration
- Runtime now accepts only `spec_version == "0.2.12"` (`src/peetsfea/pipeline/run_design.py`, `examples/type1.toml`).
- Some legacy spec paths are removed and fail fast when referenced (`src/peetsfea/spec/resolver/path_access.py`, `tests/test_manifest_validation.py`).
- `pcbs[*].present` and `mounts` are normalized to the 0.2.12 fixed-topology rules rather than preserving arbitrary topology input (`src/peetsfea/spec/resolver/pcbs.py`).
- The default artifact contract is described as `.aedt + repro/dataset/source snapshots`, while zip export remains temporarily disabled (`README.en.md`, `tests/test_v027_zip_payload.py`).
- `run.py` is removed, and the execution/debug entrypoints are now split between `sample.py` and `build.py` (`.vscode/launch.json`, `.vscode/tasks.json`).
- The direct full-space TOML -> AEDT path is removed; `build.py` now accepts sampled TOMLs only.
- Build input TOMLs must be fully frozen across all sampling owners (`count == 1` with equal bounds), or preflight validation fails immediately (`src/peetsfea/pipeline/selection_snapshots.py`, `tests/test_run_script_artifacts.py`).

## Public API / Interface Changes
- The spec version is pinned to `SUPPORTED_SPEC_VERSION = "0.2.12"` (`src/peetsfea/pipeline/run_design.py`, `src/peetsfea/__init__.py`).
- The key `RunResult` snapshot contract remains centered on `source_toml_bytes`, `repro_snapshot`, and `dataset_snapshot` (`src/peetsfea/types/manifest.py`, `src/peetsfea/pipeline/run_design.py`).
- `dataset.toml` exports only canonical sampled owners that actually affect the design, excluding derived aliases and fixed fields (`src/peetsfea/pipeline/selection_snapshots.py`, `README.en.md`).
- Public ferrite spec paths are consolidated around `[ferrite.present]`, `[ferrite.rx_thickness_mm]`, `[ferrite.tx_thickness_mm]`, and `[ferrite.relative_permeability]` (`examples/type1.toml`, `PLANS/DIVIDE_AND_CONQUER/V0_2_11_01_SPEC_AND_POLICY.md`).
- `run/toml/manifest.json` is now the build source of truth, and each entry carries the sampled TOML absolute path plus sample-stage identity fields such as `design_id`, `design_unique_hash`, and `toml_space_hash` (`src/peetsfea/pipeline/run_batch.py`, `build.py`).
- `build.py` uses the sampled TOML stem as the final AEDT basename and applies frozen-sampling-spec validation before build execution (`src/peetsfea/pipeline/run_batch.py`, `src/peetsfea/pipeline/selection_snapshots.py`).

## Upgrade Checklist
- Pin input TOML files to `spec_version = "0.2.12"`.
- Move removed paths to their current replacements and simplify ferrite control around the global `ferrite.present` flag.
- If downstream code reads `dataset.toml`, update path/dimension assumptions to the canonical sampled-owner ledger contract.
- If you depended on zip artifacts, switch to the current snapshot-based artifact contract.
- If you used the old `run.py` workflow, move to `sample.py -> run/toml/manifest.json -> build.py`.
- Include replay/dataset/sampling-registry regression suites in CI.

## Known Limits
- The zip export flag remains for type compatibility, but no zip file is currently emitted.
- `run/toml/<design_id>.toml` is a runner convenience artifact; the public replay contract remains `repro.toml`.
- Eager uniform selection currently runs with the small-range profile hardcoded in `sample.py` (`0..2000` selecting `500` designs).
