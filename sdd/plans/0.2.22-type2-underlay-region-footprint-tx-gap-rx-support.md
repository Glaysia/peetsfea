# 0.2.22 Type2 Underlay Region Footprint + TX Gap + RX Support

## Goal
- underlay contract를 TX-only coil-footprint 모델에서 role-aware region-footprint 모델로 재정의한다.
- shared `underlay_repeat_count`, TX-only `underlay_gap_mm`, RX underlay exact-name taxonomy를 문서로 먼저 고정한다.
- 이번 패스는 `sdd/` 문서만 수정하고, Python/example/test code는 후속 구현 패스로 남긴다.

## Scope
- 포함:
  - `underlay_repeat_count` shared modeled-object contract
  - TX-only `underlay_gap_mm` public field contract
  - TX/RX underlay footprint, anchor, naming, material ownership
  - architecture / diagram / code-note / test-note drift cleanup
- 제외:
  - Python 구현
  - example TOML 수정
  - pytest 수정
  - non-SDD docs 수정

## Decisions
- underlay owner는 계속 `tx_rect_void` core가 아니라 type2 scene/export/import 계층이다.
- `underlay_repeat_count`는 TX/RX shared modeled-object range field다.
  - canonical encoding: `[true, 0, 8, 5]`
  - realized candidate set: `{0, 2, 4, 6, 8}`
- `underlay_gap_mm`는 TX-only modeled-object range field다.
  - canonical encoding: `[false, 1.0, 10.0, 4]`
  - realized candidate set: `{1.0, 4.0, 7.0, 10.0}`
  - 의미: TX coil canonical minimum-Z plane에서 첫 ferrite top face까지의 거리
- TX underlay footprint canonical source는 `tx_region` full `XY` bounds다.
- RX underlay footprint canonical source는 `rx_region_max` full `YZ` bounds다.
- RX underlay는 `rx_region_max`의 `-X` boundary에 anchor한다.
- RX coil-facing material은 ferrite다.
  - physical `-X -> +X` order: `air -> PET_PSA -> ferrite`
  - semantic exported body order: `ferrite -> pet_psa -> air`
- exact names:
  - TX:
    - `tx_underlay_ferrite_u{n}`
    - `tx_underlay_pet_psa_u{n}`
    - `tx_underlay_air_u{n}`
  - RX:
    - `under_rx_ferrite_u{n}`
    - `under_rx_pet_psa_u{n}`
    - `under_rx_air_u{n}`
- new underlay exact object/body names must be `<= 32` chars.
  - 이 규칙은 repo-global AEDT validator보다 stricter한 feature-local invariant다.
- underlay bodies는 TX/RX 모두 explicit imported solids지만 conductor mesh owner는 아니다.

## Acceptance
- SDD 문서가 TX/RX 모두에 대해 region-footprint underlay contract를 일관되게 설명한다.
- SDD 문서가 RX underlay unsupported / RX non-zero fail-fast / coil-footprint underlay 문구를 더 이상 canonical contract처럼 쓰지 않는다.
- SDD 문서가 TX-only `underlay_gap_mm`, RX `under_rx_*`, conductor-only mesh exclusion, 32-char naming invariant를 명시한다.
- `git diff --check` 기준으로 문서 포맷 문제가 없다.
