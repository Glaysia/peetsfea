# Type2 Plate-Stack `z_usage_ratio`

## Intent
- Add an independent sampled `z_usage_ratio` owner to `tx_plate_stack` and `rx_plate_stack`.
- Use the ratio to restrict the full plate stack to a role-specific active Z window instead of always using the full owner Z span.

## Contract
- TOML field: `[modeled_objects.z_usage_ratio] range = [false, start, end, count]`
- Valid realized values: `0 < z_usage_ratio <= 1`.
- TX uses the top `z_usage_ratio` fraction of `tx_region`.
- RX uses the bottom `z_usage_ratio` fraction of `rx_region_max`.
- The active Z window applies to copper, PCB, PET/PSA, ferrite, air, bridges, stubs, terminal metadata, and modeled ledger bounds.

## Implementation Notes
- Keep X anchoring at owner `min_x` and stack growth in `+X`.
- Keep Y footprint and the existing `-Y` terminal stub overhang unchanged.
- Register both ratio paths as sampled owners so `sampled.toml`, manifest metadata, and design variables remain deterministic replay inputs.
- Update docs and tests with the same contract; do not add a default or compatibility fallback for missing fields.

## Verification
- Parser tests must reject missing, integer, non-positive, and above-one ranges.
- Sampling tests must freeze and report both TX/RX ratio owner paths.
- Export tests must verify TX top anchoring, RX bottom anchoring, reduced full-stack body bounds, and terminal metadata translation.
