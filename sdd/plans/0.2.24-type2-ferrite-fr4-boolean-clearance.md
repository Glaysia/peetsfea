# Type2 Ferrite FR4 Boolean Clearance

## Intent
- Remove Type2 STEP-level overlaps between ferrite/PET_PSA sheet stacks and PCB/FR4 solids before AEDT import.
- Preserve ferrite/PET_PSA sheet geometry as the material-priority source of truth and cut the intersecting PCB/FR4 solids.
- Keep the fix in deterministic build123d/OCC STEP generation; do not add AEDT-side subtract or GUI-only validation paths.

## Decisions
- Ferrite/PET_PSA solids are mandatory cut tools; path-specific air spacer solids may be included only where the local exported group contract treats them as ferrite-family branch spacers.
- PCB/FR4 bodies are the cut blanks. Copper, terminal sheets, air boxes, ports, and non-PCB guide bodies are not cut.
- Boolean work should be grouped by blank body: build one compound/fused tool set per local ferrite family and subtract it from each affected PCB/FR4 blank once.
- Body labels, body order, body groups, ledger member names, and canonical coordinate contracts remain stable after cutting.
- A missing or invalid tool/blank set for a path expected to contain ferrite and PCB/FR4 is a fail-fast error, not a fallback.

## Work Slots
- Slot A: implement reusable single-coil underlay boolean helpers in `src/peetsfea/type2_single_coil_underlay.py` and focused geometry tests.
- Slot B: integrate the helper into `src/peetsfea/type2_single_coil_scene.py` while preserving modeled scene data, expected body names, and exported group contracts.
- Slot C: add the same ferrite-priority cut policy to `src/peetsfea/type2_tx_plate_stack_array.py` and its plate-stack-array tests.
- Slot D: add end-to-end STEP/export contract tests proving representative Type2 outputs keep existing ledger names/groups while removing FR4/ferrite overlaps.

## Invariants
- No PyAEDT fallback is introduced; AEDT import should receive already non-overlapping material solids.
- `bd.export_step()` must still be checked for exact success.
- Boolean failures, empty post-cut PCB/FR4 solids, unexpected unlabeled results, or body count/name drift fail immediately.
- Deterministic seed inputs must produce deterministic cut geometry and ledger metadata.
