# 0.2.22 Type2 Plate-Stack Equivalent 3-Slab

## Goal
- active `tx_plate_stack` / `rx_plate_stack`에서 ferrite-family를 여러 내부 sheet 조각으로 만들지 않고
  material별 등가 두께 slab 3개로 직접 생성한다.
- public type2 v2 TOML에서 `ferrite_set_count`를 제거한다. 남아 있으면 fallback 없이 unsupported key로 실패한다.
- legacy `type1`과 active single-coil underlay는 범위 밖이다.

## Decisions
- this milestone kept `peetsfea.type2.step.v2`; later TX array work supersedes active examples to `peetsfea.type2.step.v4`.
- 기존 baseline 10세트의 총 두께는 내부 고정 등가 두께로 유지한다.
  - PET/PSA: `10 * 0.15 mm = 1.5 mm`
  - ferrite: `10 * 0.20 mm = 2.0 mm`
  - air: `10 * 0.02 mm = 0.2 mm`
- final handoff exact names와 role groups는 유지한다.
  - `*_stack_pet_psa`
  - `*_stack_ferrite`
  - `*_stack_air`
  - `g_ferrite_tx`, `g_ferrite_rx`
- `*_stack_*_uN` plate-stack labels, generic `SOLID*` drift, or old `ferrite_set_count` TOML input are contract violations.

## Acceptance
- examples and sampled TOML fixtures no longer include `ferrite_set_count`.
- loader accepts plate-stack v2 TOML without `ferrite_set_count` and rejects TOML that still includes it.
- generated plate-stack geometry has exactly one solid each for PET/PSA, ferrite, and air.
- stack X order is `pcb_wall -> PET/PSA -> ferrite -> air -> pcb_coil`.
- total stack thickness remains the old 10-set baseline.
- import-only and setup-ready contracts still see the same 6 final role bodies and the same copper/ferrite groups.
