# 0.2.24 Type2 TX Outer Void Stack

## Goal
- Add passive PET/PSA and MULL12060ferrite sheets to the realized `tx_outer_single_coil` central void.
- Keep the stack geometry-only and passive: it must not create TX outer ports, sources, mesh targets, reports, or active EM setup inputs.
- Shape the outer void stack in the same `tx_outer_region` prism-local frame as the outer coil, then extend the final passive void bodies through the full `tx_region` top boundary per [0.2.24 Type2 TX Outer Void Stack TX Region Extension](0.2.24-type2-tx-outer-void-stack-tx-region-extension.md).
- Add the same PET/PSA and MULL12060ferrite bottom underlay stack under `tx_outer_single_coil` that `tx_inner_single_coil` already uses under its actual/design footprint.

## Decisions
- No new public TOML fields or schema id bump are introduced.
- `tx_outer_single_coil` derives stack activation and thickness values from its source `tx_inner_rect_void_coil`:
  - `underlay_repeat_count`
  - `underlay_pet_psa_thickness_mm`
  - `underlay_ferrite_thickness_mm`
- Sampling remains unchanged: no sampled owner path is added under `modeled_objects.tx_outer_rect_void_coil.*` except existing `x_position_ratio`.
- Outer stack bodies use outer-specific labels to keep STEP labels unique:
  - `tx_outer_void_ferrite_u{n}`
  - `tx_outer_void_pet_psa_u{n}`
- Outer bottom underlay bodies use outer-specific labels to keep them distinct from inner underlay bodies:
  - `tx_outer_underlay_pet_psa_u{n}`
  - `tx_outer_underlay_ferrite_u{n}`
- The stack starts at realized outer `void.min_x` with ferrite and alternates PET/PSA and ferrite in local +X. The final sheet is shortened to end exactly at realized outer `void.max_x`.
- The local stack footprint spans the realized outer void in X/Y. The extension plan changes the final top clipping target from the prism-local outer guide top face to the world `tx_region.max_z` plane while preserving the same outer tilt transform.
- Outer bottom underlay footprint uses the realized outer design/actual bounds, stacks below that footprint in local `-Z`, and is transformed by the same outer tilt transform as the coil and void stack.
- Final exported bodies are transformed with the same world-Y rotation and translation used by `tx_outer_single_coil`; downstream code must not infer or reconstruct the sloped frame from STEP vertices.
- Because inner and outer stacks can coexist in one scene, outer passive sheets and bottom underlay bodies must use an outer-specific HFSS group name such as `g_ferrite_tx_outer` rather than a duplicate top-level `g_ferrite_tx`.

## Acceptance
- Fixed type2 STEP export includes outer void ferrite/PET bodies when the inner underlay repeat count is positive.
- Outer void stack and outer bottom underlay bodies are listed in `tx_outer_rect_void_coil.expected_exported_body_names` and grouped in its expected exported body groups.
- Projecting outer stack body vertices into `tx_outer_region` prism-local coordinates shows:
  - local X stays within realized outer void min/max,
  - local Y stays within realized outer void min/max,
  - final world Z reaches `tx_region.max_z`,
  - final top clipping is no longer the outer prism-local top plane.
- Projecting outer bottom underlay vertices into `tx_outer_region` prism-local coordinates shows its footprint matches the outer design/actual footprint and its top aligns immediately below the outer body.
- Import partition and style accept outer passive void and bottom-underlay bodies, assign ferrite/PET materials, and recreate the outer passive group without making TX outer active in setup-ready.
- Sample/build metadata remains deterministic and does not add new public sampled owners for outer passive stack fields.

## Work Split
- Geometry worker: outer void raw overshoot/top clipping plus outer bottom underlay scene construction.
- Export/contract worker: STEP expected body names, group membership, and export contract validation for outer passive void and bottom bodies.
- Import worker: import-ledger, partition, and style acceptance for outer passive void/bottom bodies and group name.
- Tests worker: prism-local geometry, sampled-owner invariants, setup-ready, and entry regression coverage.

## Follow-up Split
- The TX-region top extension work is owned by [0.2.24 Type2 TX Outer Void Stack TX Region Extension](0.2.24-type2-tx-outer-void-stack-tx-region-extension.md).
