# Type2 Sweep Report Contract

## Goal
- Apply the staged AEDT sweep/report behavior to the active type2 setup-ready path.
- Enable the recorded interpolating frequency sweep and make `Output Variables Table1` resolve against `Setup1 : Sweep`.

## Decisions
- Type2 setup-ready creates an enabled interpolating sweep named `Sweep`.
- The sweep follows the staged AEDT contract: `LogScale`, `0.1MHz` to `100MHz`, `RangeCount=401`, `RangeSamples=100`, plus the recorded DC subrange.
- `Output Variables Table1` is the active CSV export report and uses solution `Setup1 : Sweep` with context `Domain := Sweep`.
