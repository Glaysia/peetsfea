# Type2 TV Aluminum Sheet Presence

## Goal
- Replace the current `tv_aluminum_plate` 0.04 mm STEP solid with an HFSS sheet on the source `tv` `+X` face.
- Add one sampled owner, `modeled_objects.tv_aluminum_plate.sheet_present`, so generated designs can include or omit the aluminum sheet.
- Remove the thin-solid tetrahedral mesh failure source while preserving aluminum thickness through a finite-conductivity boundary in setup-ready flows.

## Scope
- Active type2 spec, examples, sampling, STEP ledger/export, AEDT import, setup-ready boundary assignment, tests, and directly affected code notes are in scope.
- Legacy type1 code and GUI AEDT validation are out of scope.
- The existing `0.04` mm value remains the aluminum sheet thickness, not an exported solid thickness.

## Decisions
- `tv_aluminum_plate.primitive` becomes `"sheet"`.
- `sheet_present` is a required `RangeSpec` on the TV aluminum modeled object.
- `examples/type2_sweep.toml` uses `range = [true, 0, 1, 2]`; this raises the active sweep dimension count from 13 to 14.
- `examples/type2_fixed.toml` uses `range = [true, 1, 1, 1]` so the fixed example keeps the aluminum sheet enabled.
- STEP export emits no `tv_aluminum_plate` body. The modeled ledger entry remains present with `expected_exported_body_count = 0` and sheet canonical metadata.
- Import-only creates sheet geometry when `sheet_present == 1` and creates no boundary.
- Setup-ready assigns finite conductivity to `tv_aluminum_plate` when `sheet_present == 1`, with material `aluminum`, `use_thickness = True`, thickness `0.04mm`, and a deterministic boundary name `bc_tv_aluminum_plate`.
- `sheet_present == 0` must produce no `tv_aluminum_plate` AEDT object; finding one is a fail-fast error.
- Current task distribution intentionally follows the user's explicit override of the sub-agent policy: six `gpt-5.5` `medium` workers instead of the policy default four Spark workers.

## Work Split
- Spec and examples worker: parser/types/examples/spec docs for `primitive = "sheet"` and `sheet_present`.
- Sampling worker: sampled owner discovery, integer design variable handling, dataset/repro propagation, and sampling tests.
- Export and ledger worker: no-solid STEP export, zero exported body contract, canonical sheet metadata, and export tests.
- Import worker: zero-body partition/ledger validation, import-time sheet creation, styling behavior, and import tests.
- Setup-ready boundary worker: AEDT finite-conductivity wrapper/protocol support, setup-ready boundary assignment, and fail-fast tests.
- Integration/docs worker: active docs, SDD code notes, dimension audit coverage, and cross-suite consistency fixes.

## Acceptance
- `examples/type2_sweep.toml` reports 14 sampled dimensions, including `modeled_objects.tv_aluminum_plate.sheet_present`.
- Exported STEP body names do not include `tv_aluminum_plate`.
- Enabled import creates the `tv_aluminum_plate` sheet and setup-ready assigns finite conductivity.
- Disabled import creates no `tv_aluminum_plate` object and setup-ready skips the finite-conductivity boundary.
- PyAEDT `False` returns from finite-conductivity assignment raise immediately with context.
- Targeted type2 sampling/export/import/setup-ready tests pass through `.venv` commands from `run/`.
