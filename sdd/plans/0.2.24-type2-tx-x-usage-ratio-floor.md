# 0.2.24 Type2 TX X Usage Ratio Floor

## Goal
- Raise the active Type2 sweep lower bound for TX coil local X outer-size usage from `0.2` to `0.4`.
- Keep the upper bound, candidate count, and TX Y usage range unchanged.
- Preserve the current ownership rule: `tx_outer_single_coil` derives its sampled X usage from `tx_inner_rect_void_coil` and must not add a public sampled owner.

## Decisions
- The only public sweep change is `modeled_objects.tx_inner_rect_void_coil.outer_x_usage_ratio.range`.
- New sweep range is `[false, 0.4, 0.9, 75]`.
- `modeled_objects.tx_inner_rect_void_coil.outer_y_usage_ratio.range` is `[false, 0.2, 0.9, 150]`.
- `examples/type2_fixed.toml` remains fixed at `outer_x_usage_ratio = 0.5`; no fixed example update is required.
- No Python runtime behavior change is intended. Parser, sampler, actual-region, and derived outer TX behavior should consume the changed TOML range through existing one-to-one TOML ownership.

## Implementation Boundary
- Worker A owns the public TOML authoring input and any direct example contract update needed for the TX X range.
- Worker B owns focused parser/sampling tests that should assert the new TX X range without broad fixture rewrites.
- Worker C owns focused generation/export tests affected by the example sweep range.
- Worker D owns validation execution and any narrowly required test expectation update discovered by the focused runs.
- Workers must not modify legacy `type1` paths or unrelated dirty workspace state such as `notebooks/view_step_files.ipynb`.
- Workers must preserve other agents' in-flight edits and avoid overlapping write sets.

## Acceptance
- `examples/type2_sweep.toml` exposes TX inner `outer_x_usage_ratio` as `[false, 0.4, 0.9, 75]`.
- Loading `examples/type2_sweep.toml` yields the same range for the derived `tx_outer_single_coil`.
- Sampled owner discovery still records `modeled_objects.tx_inner_rect_void_coil.outer_x_usage_ratio` and does not add `modeled_objects.tx_outer_rect_void_coil.outer_x_usage_ratio`.
- Focused pure-Python type2 tests pass from `run/`.
