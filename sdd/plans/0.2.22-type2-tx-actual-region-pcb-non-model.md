# type2 tx actual-region stack-space non-model

## Intent
- Add derived non-modeled stack-space bodies centered in each realized `tx_region_actual` concrete tile top-view rectangle.
- Keep each stack-space top face coplanar with its owning `tx_region_actual` tile top face before tilt.
- Use a fixed 5 mm total reservation thickness and one sampled scale ratio shared by all tile stack spaces.
- Always tilt each stack-space body so its face normal points toward the modeled RX object center.
- Treat the body as future TX content allocation space, not as a PCB non-model body. The future contents are a 0.4 mm PCB plus ferrite-sheet equivalent fill in the remaining thickness.

## Scope
- Source TOML adds `tx_region_actual_stack_space` as a derived non-model object.
- The derived stack-space TOML does not accept `material`; it is materialless reservation geometry.
- Parser requires fixed `total_thickness_mm = 5.0`.
- Parser accepts only the canonical sampled `scale_ratio = [false, 0.35, 0.95, 25]` or a fixed single candidate.
- Parser accepts only fixed `tilt_enabled = [true, 1, 1, 1]`.
- Scene resolution derives one stack-space body per realized concrete `tx_region_actual` tile.
- Sampling metadata and AEDT design variables include the new scale owner when it is sampled.
- `tilt_enabled` is fixed on and is not a sampled owner or AEDT design variable.

## Invariants
- `tx_region_actual` concrete tiles remain the canonical owners for per-tile stack-space placement.
- Each stack-space `XY` footprint is centered in its owning concrete tile and scaled uniformly by the shared `scale_ratio`.
- Each stack-space `Z` span is exactly 5 mm and its max Z equals the owning tile max Z before tilt.
- Stack-space generation fails if `tx_region_actual` has not been resolved or if scale/total-thickness invariants drift.
- `tilt_enabled = 1` is the only accepted contract and rotates only the stack-space bodies, not `tx_region_actual` guide tiles.
- Tilt target is the modeled RX object's canonical outer-bounds center.
- Tilt uses the stack-space body center as the rotation basis, then shifts the tilted body down in global Z if needed so its bounding box does not exceed the owning tile top.
- Tilted stack-space generation fails if the shifted body would drop below the owning tile bottom.
