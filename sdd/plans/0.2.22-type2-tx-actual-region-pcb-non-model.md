# type2 tx actual-region pcb non-model

## Intent
- Add derived non-modeled PCB bodies centered in each realized `tx_region_actual` concrete tile top-view rectangle.
- Keep each PCB top face coplanar with its owning `tx_region_actual` tile top face.
- Use a fixed 5 mm PCB thickness and one sampled scale ratio shared by all tile PCBs.
- Always tilt each PCB body so its face normal points toward the modeled RX object center.

## Scope
- Source TOML adds `tx_region_actual_pcb` as a derived non-model object.
- Parser accepts only the canonical sampled `scale_ratio = [false, 0.35, 0.95, 25]` or a fixed single candidate.
- Parser accepts only fixed `tilt_enabled = [true, 1, 1, 1]`.
- Scene resolution derives one PCB body per realized concrete `tx_region_actual` tile.
- Sampling metadata and AEDT design variables include the new scale owner when it is sampled.
- `tilt_enabled` is fixed on and is not a sampled owner or AEDT design variable.

## Invariants
- `tx_region_actual` concrete tiles remain the canonical owners for per-tile PCB placement.
- Each PCB `XY` footprint is centered in its owning concrete tile and scaled uniformly by the shared `scale_ratio`.
- Each PCB `Z` span is exactly 5 mm and its max Z equals the owning tile max Z.
- PCB generation fails if `tx_region_actual` has not been resolved or if scale/thickness invariants drift.
- `tilt_enabled = 1` is the only accepted contract and rotates only the PCB bodies, not `tx_region_actual` guide tiles.
- Tilt target is the modeled RX object's canonical outer-bounds center.
- Tilt uses the PCB body center as the rotation basis, then shifts the tilted body down in global Z if needed so its bounding box does not exceed the owning tile top.
- Tilted PCB generation fails if the shifted body would drop below the owning tile bottom.
