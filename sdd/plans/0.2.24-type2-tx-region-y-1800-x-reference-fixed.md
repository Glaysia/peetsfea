# Type2 TX Region Y 1800 X Reference Fixed

## Goal
- TX non-modeled guide 영역의 Y 폭을 1800 mm로 확장한다.
- 단일 TX inner coil 체계에서 중복 X reference 자유도만 제거한다.
- TX inner guide와 실제 TX coil의 Y 크기 비율 owner는 유지한다.

## Implementation Contract
- Official examples set base `tx_region` Y bounds to `origin_y = -600.0`, `size_y = 1200.0`, preserving Y center at 0.
- Official examples fix only `non_model_objects.tx_region.tx_reference_line.x_ratio.range = [false, 0.99, 0.99, 1]`.
- `non_model_objects.tx_region.tx_reference_line.y_usage_ratio` remains alive:
  - sweep keeps `[false, 0.2, 1.0, 85]`
  - fixed keeps `[false, 1.0, 1.0, 1]`
- `modeled_objects.tx_inner_rect_void_coil.outer_y_usage_ratio` remains alive:
  - sweep keeps `[false, 0.2, 0.9, 150]`
  - fixed keeps `[false, 0.6, 0.6, 1]`
- `modeled_objects.tx_inner_rect_void_coil.x_position_ratio` remains the active X placement sampled owner.
- Do not remove the `x_ratio` TOML field; it remains required provenance for `tx_inner_region`.
- Do not apply `stash@{0}` wholesale. It contains a prior incorrect Y-ratio fixed implementation and notebook edits that are out of scope.
