# 0.2.22 STEP Viewer Notebook Registry

## Goal
- tracked STEP artifacts를 VS Code의 `bernhard-42.ocp-cad-viewer`로 바로 확인할 수 있는 notebook registry를 둔다.
- 앞으로 durable STEP artifact를 생성하는 소스코드가 추가되면 같은 notebook에 등록하도록 SDD 정책으로 강제한다.

## Scope
- 포함:
  - `examples/type2/view_step_files.ipynb`
  - `.vscode/extensions.json`
  - [[sdd/code/examples/type2/generate_non_model_step.py]]
  - `SDD.md`
- 제외:
  - `tmp/` 아래 scratch STEP artifact
  - AEDT import와 GUI AEDT validation
  - STEP 생성 로직 변경

## Decisions
- registry scope는 `git ls-files '*.step' '*.stp'`에 잡히는 tracked STEP artifact로 제한한다.
- notebook registry 항목은 label, STEP artifact path, generator source path를 기록한다.
- notebook은 registry와 tracked STEP 목록이 다르면 즉시 예외를 발생시킨다.
- 각 tracked STEP artifact는 `build123d.import_step()`과 `ocp_vscode.show()`를 쓰는 전용 viewer cell을 가진다.

## Acceptance
- `examples/type2/view_step_files.ipynb`가 `examples/type2/artifacts/type2_non_model_objects.step`와 `examples/type2/generate_non_model_step.py`를 등록한다.
- notebook JSON 파싱이 성공한다.
- `.venv/bin/python`에서 `build123d`, `ocp_vscode` import와 current tracked STEP load가 성공한다.
- `.obsidian/graph.json`의 기존 local change는 건드리지 않는다.
