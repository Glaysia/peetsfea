# 0.2.22 STEP Viewer Notebook Registry

## Goal
- `notebooks/view_step_files.ipynb`를 type2 single scene STEP 전용 viewer notebook으로 단순화한다.
- future canonical generated artifact `run/step/type2/type2_scene.step`를 VS Code의 `bernhard-42.ocp-cad-viewer`로 바로 확인할 수 있게 한다.
- notebook refresh contract를 single artifact + retained ledger 중심으로 재정의한다.

## Scope
- 포함:
  - `notebooks/view_step_files.ipynb`
  - `entry/refresh_type2_step_viewer_artifacts.py`
  - [[sdd/plans/0.2.22-type2-single-step-setup-ready-pipeline]]
- 제외:
  - notebook registry/index selection UI 유지
  - AEDT import notebook 계약
  - source/notebook JSON 수정

## Decisions
- future canonical viewer input은 `run/step/type2/type2_scene.step` 하나다.
- notebook은 artifact index나 registry selection 없이 fixed path single STEP만 보여준다.
- notebook refresh는 `type2_scene.step`와 `type2_step_ledger.json`을 canonical generated artifact set으로 본다.
- generated refresh는 `run/step/type2`만 삭제 대상으로 삼고 다른 `run/` 하위 산출물은 보존한다.
- notebook은 generated refresh를 repo-local `.venv/bin/python`으로 `run/` cwd에서 실행한다.
- notebook-visible placement truth는 refreshed ledger canonical coordinates다.

## Acceptance
- `notebooks/view_step_files.ipynb`는 future contract에서 `type2_scene.step` fixed-path viewer로 설명된다.
- generated viewer flow는 기존 `run/step/type2` 산출물을 재사용하지 않고 clean refresh를 먼저 수행한다고 설명된다.
- ledger는 viewer contract에서 제거되지 않고 placement/ownership truth로 유지된다고 설명된다.
- registry mismatch/index selection 같은 기존 notebook contract는 future active contract에서 제거된다.
