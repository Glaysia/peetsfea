# 0.2.22 STEP Viewer Notebook Registry

## Goal
- `notebooks/view_step_files.ipynb`를 type2 STEP viewer notebook으로 유지하되 fixed example와 sampled manifest selection을 함께 다루게 한다.
- `VIEW_INDEX = -1`이면 `examples/type2_fixed.toml` fixed refresh path를 보여준다.
- `VIEW_INDEX >= 0`이면 `run/sampled/type2/manifest.json`의 `entries` 순서를 인덱스 SSOT로 써서 sampled STEP를 바로 연다.

## Scope
- 포함:
  - `notebooks/view_step_files.ipynb`
  - `src/peetsfea/type2_step_export.py`
  - `src/peetsfea/type2_sampled.py`
- 제외:
  - AEDT import notebook 계약

## Decisions
- notebook top-level constant `VIEW_INDEX`가 selection surface다.
- `VIEW_INDEX == -1`은 fixed example reserved index다.
- sampled mode에서는 manifest top-level `entries` 배열 순서가 viewer index list다.
- sampled mode는 `entries[VIEW_INDEX]["scene_step_path"]`를 그대로 열고, missing manifest / out-of-range index / missing step path를 모두 즉시 raise한다.
- fixed mode는 `examples/type2_fixed.toml`에서 `run/step/type2/type2_scene.step`를 refresh한 뒤 연다.

## Acceptance
- `VIEW_INDEX = -1`이면 fixed example refresh/show가 동작한다고 설명된다.
- `VIEW_INDEX >= 0`이면 manifest `entries` index selection이 동작한다고 설명된다.
- manifest `entries` order가 notebook index SSOT라고 설명된다.
