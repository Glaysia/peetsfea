# 0.2.22 Type2 RX Single Coil Full Backing

## Summary
- RX stays `rx_rect_void_coil` / `rx_single_coil`.
- RX coil physical stack is fixed to `4.0 mm`: PCB `3.965 mm` + copper `0.035 mm`.
- The space behind RX is filled with a three-slab backing family using the plate-stack equivalent ratio PET/PSA:ferrite:air = `1.5:2.0:0.2`.

## Decisions
- No new public TOML field is added.
- Active RX examples fix `underlay_repeat_count = [true, 8, 8, 1]` to request backing presence, but RX backing thickness is not `8 * unit_thickness`.
- RX backing total thickness is computed from available owner depth: `rx_region_max.size_x - (pcb_thickness_mm + copper_thickness_mm)`.
- For current `rx_region_max.size_x = 5.0`, backing total is `4.6 mm`.
- Physical `-X -> +X` order remains `air -> PET_PSA -> ferrite -> RX coil`.
- Exported semantic order remains `under_rx_ferrite_u0`, `under_rx_pet_psa_u0`, `under_rx_air_u0`, grouped by `g_ferrite_rx`.
- If available backing thickness is not positive, generation fails immediately.

## Tests
- Example parser tests verify RX `pcb_thickness_mm = 3.965`, `copper_thickness_mm = 0.035`, `layer_count = 1`, and fixed backing request.
- Export tests verify three backing solids exist, fill all space behind the coil, keep the material ratio, and do not positive-volume overlap RX copper/PCB.
- Sampling/build tests verify `underlay_repeat_count` is fixed and excluded from sampled owner/design-variable paths.
