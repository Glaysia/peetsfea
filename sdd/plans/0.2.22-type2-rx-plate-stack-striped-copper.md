# 0.2.22 Type2 RX Plate Stack Striped Copper

## Goal
- active plate-stack role set을 유지한 채 TX/RX copper를 full-face slab에서 multi-turn striped copper coil로 바꾼다.
- TOML이 `turn_count`, `metal_fill_factor`, `shoe_depth_mm`를 받아 front/back plate, bridge, shoe fill, terminal stub geometry를 deterministic하게 만든다.
- current `rx_plate_stack` geometry/export-only 방향은 유지하고, import/setup-ready/EM은 계속 guardrail로 막는다.

## Scope
- 포함:
  - `tx_plate_stack`, `rx_plate_stack` TOML/spec 확장
  - sampled owner-path 수집과 realized fixed/free range 처리
  - shared TX/RX striped copper geometry/export/ledger body contract
  - 관련 tests/docs/SDD note 갱신
- 제외:
  - plate-stack import/setup-ready/EM 지원
  - direct EM enablement

## Decisions
- active TX/RX role/object id는 계속 `tx_plate_stack` / `rx_plate_stack`이다.
- public plate spec은 `turn_count`, `metal_fill_factor`, `shoe_depth_mm`를 가진다.
- `turn_count`는 wall-side copper turn owner이며 coil-side copper는 항상 `turn_count - 1`이다.
- current example baseline은 `turn_count = 3`, `metal_fill_factor = 0.4`, `shoe_depth_mm = 7.0`으로 고정한다.
- placement owner source of truth는 TX `tx_region` full `YZ`, RX `rx_region_max` full `YZ` bounds다.
- shoe fill은 side별 `pcb_total_thickness_mm` full span을 `PET/PSA -> ferrite -> air` 순서로 반복하고 마지막 layer는 잘라서 끝낸다.
- copper exact-name family는 아래로 고정한다.
  - wall-side stripes: `<tx|rx>_copper_wall_t0..t{N-1}`
  - coil-side stripes: `<tx|rx>_copper_coil_t0..t{N-2}`
  - bridges: `<tx|rx>_bridge_s0..s{2N-3}`
  - terminal stubs: `<tx|rx>_stub_in`, `<tx|rx>_stub_out`
- bridge sequence는 `wall_t0 -> coil_t0 -> wall_t1 -> ... -> coil_t{N-2} -> wall_t{N-1}`를 alternating `Y=max/min` 규칙으로 잇는다.
- terminal stub는 wall-side `t0`와 `t{N-1}`에 붙고 `+Y` 방향으로 `5.0 mm` 돌출한다.
- `terminal_metadata`는 sentinel `{"kind": "none"}` 대신 `kind = "stub_port"`를 쓴다.
- import/setup-ready/style/mesh/port/EM path는 direct EM enablement 없이 current guardrail을 유지한다.

## Acceptance
- active example TX/RX modeled object가 plate-stack role로 parse되고, 세 field를 포함해도 fail-fast validation을 통과한다.
- fixed baseline body count는 TX `69`, RX `51`이다.
- stripe bbox는 wall-side `0, pitch_z, 2*pitch_z...`, coil-side `pitch_z/2, 3*pitch_z/2...` half-pitch offset을 만족한다.
- TX는 top shoe, RX는 bottom shoe로 인해 conductor/PCB bbox가 owner full-height보다 줄어들고, shoe fill bbox는 cutout Z band만 점유한다.
- stub bbox는 `+Y 5.0 mm` overhang와 metadata-only port-sheet rectangle을 만족한다.
- sampled owner-path와 realized snapshot이 `turn_count`, `metal_fill_factor`, `shoe_depth_mm`를 lossless로 보존한다.
- import/setup-ready/EM은 plate-stack roles를 계속 explicit unsupported role로 거부한다.
