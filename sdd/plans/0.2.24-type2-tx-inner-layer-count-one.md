# 0.2.24 Type2 TX Inner Layer Count One

## Goal
- Active `type2_fixed.toml` and `type2_sweep.toml` use `tx_inner_rect_void_coil.layer_count = [true, 1, 1, 1]`.
- Active sample/build/STEP tests treat TX inner as effectively single-layer.
- Parser synthetic multilayer support remains out of scope for this active fixed/sweep cleanup.

## Decisions
- Do not add parser rejection for `tx_inner_single_coil.layer_count > 1`.
- Remove active sweep exposure of TX inner layer-count sampling by fixing the TOML range to `[true, 1, 1, 1]`.
- Keep `modeled_objects.tx_inner_rect_void_coil.layer_count` out of sampled owner and build design-variable contracts.
- Active fixed/sweep STEP expectations use `tx_inner_pcb_l0` and `tx_inner_copper_l0`, not `tx_inner_pcb_l1` or `tx_inner_copper_stack`.
- Generic `tx_single_coil`, `tx_rect_void_columns`, and legacy type1 multilayer behavior are out of scope.

## Work Slots
- Slot A owns active TOML and setup/sample/build parser expectations for fixed/sweep layer-count ranges.
- Slot B owns STEP generation tests and fixed-example body-name expectations for single-layer TX inner artifacts.
- Slot C owns backend EM/import/setup tests that previously expected active TX inner multilayer names or `tx_inner_copper_stack`.
- Slot D owns SDD/code-note cleanup for examples, tests, and related active plans.
