# 0.2.22 Type2 Plate-Stack Material Merge

## Goal
- active `tx_plate_stack`, `rx_plate_stack` STEP import에서 ferrite-family object 수를 줄여 import 속도를 개선한다.
- same-material plate-stack slab는 per-set `uN` body contract를 버리고 per-material merged body contract로 축약한다.
- later equivalent-slab cleanup removes the public `ferrite_set_count` field and creates the three material slabs directly;
  see [[sdd/plans/0.2.22-type2-plate-stack-equivalent-3-slab]].
- 이번 패스는 active plate-stack path만 다룬다. legacy `type1`, active `single_coil`은 범위 밖이다.

## Decisions
- plate-stack ferrite-family export contract는 per-set `uN` exact bodies가 아니라 per-material exact bodies로 바꾼다.
- TX exact names:
  - `tx_stack_pet_psa`
  - `tx_stack_ferrite`
  - `tx_stack_air`
- RX exact names:
  - `rx_stack_pet_psa`
  - `rx_stack_ferrite`
  - `rx_stack_air`
- merged body는 export-side canonical handoff 전에 explicit unite를 완료한 exact named STEP body여야 한다.
- ferrite-family member는 ungrouped child/compound 상태로 STEP handoff에 남기지 않는다. united body 3개를 `g_ferrite_tx` / `g_ferrite_rx`로 explicit group export한다.
- PCB naming과 plate-stack terminal metadata는 유지한다.
- copper/bridge/stub segment labels는 pre-unite provenance only로 유지하고, final copper handoff는
  role당 `tx_plate_copper` / `rx_plate_copper` united body로 축약한다.
- `g_ferrite_tx`, `g_ferrite_rx` 그룹 이름은 유지하되 member는 flattened 30개 body가 아니라 merged 3개 body만 가진다.
- `g_copper_tx`, `g_copper_rx` 그룹은 각각 `tx_plate_copper`, `rx_plate_copper` single-member group이다.
- import partition/style/runtime도 같은 merged exact-name contract를 사용한다. old `*_u0..u9` plate-stack contract에 대한 fallback은 추가하지 않는다.
- `ferrite_set_count` remains historical baseline context only after the equivalent 3-slab cleanup; it is not a public plate-stack field.
- import에서 generic `SOLID*`가 생기면 export contract violation로 간주하고 즉시 실패한다.
- stale STEP/imported-ledger/AEDT artifact는 재생성 전제로 다룬다.

## Acceptance
- plate-stack `expected_exported_body_names`와 `expected_exported_body_count`가 merged 3-body contract를 반영한다.
- plate-stack `expected_exported_body_groups`는 role당 copper group과 ferrite group을 가지며 member 순서와 일치한다.
- STEP export/import round-trip에서 united merged body label이 유지되고 generic `SOLID*` drift가 없다.
- import partition은 plate-stack merged 3-body names를 exact-name contract로 검증한다.
- import styling은 merged ferrite/PET_PSA/air object 각각에 expected material/visual state를 적용한다.
- targeted `pytest`와 `pyright`가 통과한다.
