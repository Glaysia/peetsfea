# 0.2.22 Type2 Plate-Stack Equal Stripes

## Summary
- Active TX/RX plate-stack copper topology moves from asymmetric `wall=N / coil=N-1`
  to equal `wall=N / coil=N`.
- The output terminal moves from wall-side `t{N-1}` to coil-side `t{N-1}` while both
  terminal stubs continue to protrude in `+Y`.
- Final exported/imported copper ownership remains one united conductor body per role:
  `tx_plate_copper` and `rx_plate_copper`.

## Contract
- `turn_count` owns both wall-side and coil-side stripe counts.
- Serpentine path order is `wall0 -> coil0 -> wall1 -> ... -> wallN-1 -> coilN-1`.
- Bridge count is `2 * N - 1`.
- Port sheets remain metadata-only and are reconstructed by AEDT import/style helpers as
  `tx_plate_port_sheet` / `rx_plate_port_sheet`.
- Terminal metadata must describe actual stub contact edges; it must not rely on a long
  full-height edge that spans non-conducting regions.

## Acceptance
- STEP ledger final body names stay at the existing 6-body role-local contract.
- Pre-unite provenance has equal wall/coil stripe counts and no final handoff leaks.
- Focused pure-Python tests cover equal stripe count, bridge count, and output-on-coil
  terminal semantics.
