# 0.2.22 Type2 TX Underlay MULL12060ferrite

## Goal
- type2 TX modeled object 아래에 들어가는 explicit underlay tri-layer stack 계약을 Python 구현 전에 문서로 먼저 고정한다.
- ferrite material ownership을 conductor에서 underlay ferrite slab로 옮기고, exact material/body naming을 고정한다.
- port sheet가 STEP body라는 오래된 문서 드리프트를 metadata-driven reconstruction 계약으로 정리한다.

## Scope
- 포함:
  - `underlay_repeat_count` public modeled-object field
  - TX underlay body taxonomy, naming, placement, material ownership
  - export/import/test SDD notes
  - public spec doc / architecture / flow diagram
- 제외:
  - Python 구현
  - pytest 수정
  - generated artifact 재생성
  - notebook/manual validation

## Decisions
- shared modeled-object surface에 `underlay_repeat_count` range field를 추가한다.
  - canonical encoding: `[true, 0, 8, 5]`
  - realized candidate set: `{0, 2, 4, 6, 8}`
  - TX는 이 집합을 지원한다.
  - RX는 current milestone에서 `0`만 허용한다.
- underlay 1 unit는 TX bottom-down 방향으로 다음 순서를 가진다.
  1. `MULL12060ferrite` / `0.20 mm`
  2. `PET_PSA` / `0.15 mm`
  3. `vacuum` / `0.02 mm`
- air 20 um는 spacing-only gap이 아니라 explicit exported body다.
- underlay owner는 `tx_rect_void` core geometry engine이 아니라 type2 scene/export/import 계층이다.
- underlay XY footprint는 TX modeled object의 actual exported PCB/copper union planar bounds를 그대로 따른다.
- `u0`는 TX에 가장 가까운 첫 unit이다.
  - first ferrite top face touches TX canonical minimum-Z plane
  - later units stack downward in the same tri-layer order
- TX exact body names는 기존 PCB/copper bodies 뒤에 다음 순서로 append된다.
  - `tx_underlay_ferrite_u{n}`
  - `tx_underlay_pet_psa_u{n}`
  - `tx_underlay_air_u{n}`
- conductor material ownership은 TX/RX 모두 `copper`로 고정한다.
- `MULL12060ferrite`는 TX underlay ferrite slabs에만 적용한다.
- `PET_PSA`는 air-like dielectric이며 explicit documented difference는 `permittivity = 2.8`이다.
- underlay bodies는 modeled exact-name children이지만 conductor mesh owner도 아니고 port-sheet reconstruction owner도 아니다.

## Acceptance
- 문서가 `underlay_repeat_count`의 exact encoding/candidate set/TX-RX support matrix를 명시한다.
- 문서가 TX underlay unit order, thickness, exact material names, exact body names를 명시한다.
- 문서가 air 20 um를 explicit exported body로 고정한다.
- export/import/test notes가 port-sheet STEP body 가정을 제거하고 metadata-driven reconstruction 계약으로 맞춰진다.
- import/material notes가 conductor=`copper`, underlay ferrite=`MULL12060ferrite`, underlay dielectric=`PET_PSA`, underlay air=`vacuum` ownership을 명시한다.
- mesh contract 문서가 underlay bodies를 제외한 conductor-only ownership을 유지한다고 명시한다.
