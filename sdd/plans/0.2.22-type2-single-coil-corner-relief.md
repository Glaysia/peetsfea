# 0.2.22 Type2 Single-Coil Blunt Corner

## Goal
- Type2 `tx_single_coil` / `rx_single_coil`의 모든 turn corner를 `45-degree beveled blunt corner` 하나의 계약으로 고정한다.
- square-corner path, preview path, fallback path, 선택 필드는 두지 않는다.
- public modeled-object TOML schema와 metadata JSON shape는 유지한다.

## Canonical Contract
- TX/RX는 `src/peetsfea/tx_rect_void.py`의 같은 single-coil geometry engine을 공유한다.
- `build_tx_rect_void_centerline()`는 더 이상 sharp path를 뜻하지 않고 blunt-only canonical centerline을 뜻한다.
- same-corner terminal seed, start/end terminal ownership, winding direction, placement-owner contract, exported PCB+copper body contract는 유지한다.
- exported copper는 planar strip footprint와 terminal stub prism을 fuse한 layer별 단일 solid다.
- exported PCB footprint와 modeled bounds는 routing envelope가 아니라 실제 generated copper footprint/bounds에서 파생된다.

## Implemented State
- centerline은 type1-derived same-corner seed path를 private sharp seed로 만든 뒤, public export path에 들어가기 전에 45도 blunt corner로 항상 변환된다.
- inner corner는 void keepout을 침범하지 않도록 bevel trim을 줄여 blunt corner를 유지한다.
- live copper authoring path는 각 segment polygon이 offset-line intersection join vertex를 직접 소유하는 exact joined strip polygon + terminal stub prism 경로 하나뿐이다. separate corner join primitive는 없다.
- root cause는 segment polygon, separate join filler, debug `boxes`가 모두 geometry owner처럼 읽히던 구조였다. recurrence 방지는 joined segment polygon만 live owner로 두고, `boxes`를 derived AABB payload로만 제한하는 데 있다.
- geometry helper semantics도 고정한다. positive-area overlap만 void/short overlap으로 간주해야 하며, edge touch를 overlap으로 넓히면 bevel trim과 final validation이 다시 흔들린다.
- validation은 polygon 기반 void overlap / non-adjacent short 검사로 blunt geometry를 직접 검증한다.
- RX `YZ` plane extrusion도 profile normal을 따라 authoring되어 TX와 같은 fused-solid contract를 유지한다.

## Remaining Work
- [ ] `_build_same_corner_centerline_sharp()` 같은 private migration residue naming을 더 blunt-neutral한 seed naming으로 정리한다.
- [ ] TX/RX direct parity regression을 늘려 same-corner seed, winding, placement, modeled bounds를 role pair로 함께 검증한다.
- [ ] public schema에 남아 있는 `terminal_stub_length_mm` compatibility field를 계속 유지할지, later version에서 정리할지 별도 계획으로 결정한다.

## Acceptance
- 관련 SDD 노트들은 모두 같은 사실을 말해야 한다:
  - type2 single-coil의 canonical corner wording은 `blunt corner` / `45-degree beveled corner`다.
  - current runtime/export path는 square-corner path를 canonical path로 취급하지 않는다.
  - TX/RX는 같은 engine을 사용하고 metadata/import contract를 유지한다.
- pure-Python regression은 blunt centerline, fused copper, placement, metadata bounds를 검증해야 한다.
- existing type2 export/import smoke는 blunt geometry로도 유지되어야 한다.
