# 0.3.0 Minimal STEP Two-Port Reset

## Summary

0.3.0 removes the accumulated geometry generation implementation and replaces the active path with one minimal STEP scene containing non-model boxes plus Tx/Rx two-port metal cells. The active runtime remains fail-fast and headless by default.

## Implementation Boundary

- New active parser: `src/peetsfea/minimal_spec.py`
- New STEP exporter and ledger owner: `src/peetsfea/minimal_step.py`
- New HFSS setup/solve facade: `src/peetsfea/backend/pyaedt/minimal_em.py`
- Entrypoints `entry/sample.py` and `entry/build.py` call only the new minimal path.
- Existing type2, tx_rect_void, and legacy geometry modules are removed rather than moved.

## Contracts

- TOML accepts `[design] units = "mm"` and non-empty `[[non_model_objects]]`.
- The parser rejects `modeled_objects`, `outputs`, `simulation`, `backend`, `constraints`, and old geometry-specific sections.
- STEP body names are canonical and recorded in `minimal_step_ledger.json`.
- Mesh targets are the four copper pad bodies.
- Port assignment resolves sheet edges from `tx_port_sheet` and `rx_port_sheet` and creates fixed boundary slots `1` and `2`.

## Verification

- Parser tests cover valid minimal TOML and old-section rejection.
- STEP tests cover generated body names, ledger contents, and `bd.export_step` failure conversion.
- Backend fake-HFSS tests cover import, mesh, ports, sources, setup/report, validation, save, and solve export.
- Default pytest must not require old geometry modules.
