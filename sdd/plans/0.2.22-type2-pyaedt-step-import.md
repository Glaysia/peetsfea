# 0.2.22 Type2 PyAEDT STEP Import

상위 정책은 [[SDD]], 전체 허브는 [[sdd/sdd-index]], 계획 허브는 [[sdd/plans/sdd-plans-index]]다.

## Goal
- `examples/type2/artifacts/type2_non_model_objects.step`를 headless HFSS 세션으로 import하는 smoke path를 둔다.
- PyAEDT `0.25.1`의 `Modeler3D.import_3d_cad()` 계약을 repository fail-fast wrapper 안에 고정한다.
- runtime manifest/build dispatch에는 아직 연결하지 않고 AEDT import 가능성만 빠르게 검증한다.

## Scope
- 포함:
  - [[sdd/code/examples/type2/import_non_model_step_to_hfss.py]]
  - [[sdd/code/src/peetsfea/aedt/wrappers.py]]
  - [[sdd/code/src/peetsfea/aedt/protocols.py]]
  - [[sdd/code/tests/backend_em/test_type2_step_import_smoke.py]]
- 제외:
  - `entry/build.py`, `entry/sample.py`, manifest runtime dispatch 변경
  - EM pipeline 실행
  - GUI validation
  - PyAEDT stable docs의 newer `input_file_unit` 인자 사용

## Decisions
- smoke script는 `Hfss(project=None, design=..., non_graphical=True, new_desktop=True)`로 headless 세션을 만든다.
- import 전후 `modeler.object_names` 차이를 새 imported object ledger로 삼고, 빈 diff는 fail-fast 대상이다.
- imported object는 모두 `set_object_model_state(name, False)`로 AEDT non-model guide object가 된다.
- `.aedt` 출력은 `run/aedt/type2_step_import_smoke/type2_non_model_objects_import.aedt` 아래에 저장한다.
- wrapper는 PyAEDT `0.25.1` 로컬 시그니처만 노출하고 `input_file_unit` fallback/대체 경로를 추가하지 않는다.
