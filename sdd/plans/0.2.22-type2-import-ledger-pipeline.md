# 0.2.22 Type2 Import Ledger Pipeline

## Goal
- `examples/type2_fixed.toml`에서 생성된 single scene STEP + metadata ledger를 headless HFSS로 import한다.
- import 전후 AEDT object name diff를 canonical STEP metadata와 결합한 imported ledger를 만든다.
- future 단계는 runtime-owned setup-ready까지 확장한다. 즉, imported ledger 이후 `EmPipelineInput`, explicit port/boundary/source/analysis, `ValidateDesign()`를 완료하고 solve 직전 state를 만든다. notebook은 그 결과를 호출/확인하는 thin consumer로 둔다.

## Decisions
- type2 SSOT는 `examples/type2_fixed.toml`이다.
- handoff input은 `run/step/type2/type2_step_ledger.json`이다.
- runtime output은 `run/aedt/type2_step_import/type2_import.aedt`와 `run/aedt/type2_step_import/type2_imported_ledger.json`이다.
- future canonical import input STEP는 `run/step/type2/type2_scene.step`이다.
- combined non-model ledger entry는 `member_objects` metadata를 유지해서 `tx_region` canonical coordinates를 import 단계에서 다시 읽을 수 있어야 한다.
- ledger는 retained object-level metadata handoff이며 single STEP 전환 뒤에도 유지한다.
- retained STEP ledger boundary-policy field는 top-level `em_policy`를 canonical 이름으로 사용한다.
- non-model imported object는 `set_object_model_state(False)`로 고정한다.
- non-model imported object는 import 직후 회색/반투명 visual state로 통일한다.
- modeled imported object는 `set_object_model_state(True)`로 고정한다.
- imported ownership partition은 single scene STEP diff 위에서 role metadata를 기준으로 수행한다.
- `tx_single_coil` modeled object metadata는 [[sdd/code/src/peetsfea/backend/pyaedt/type2_modeled_import_adapter.py]]로 검증한다.
- 역할, 좌표, terminal semantics는 STEP export metadata에서만 읽는다. AEDT geometry reverse-calculation은 하지 않는다.
- 기존 type1 `entry/build.py` 경로는 변경하지 않는다.
- `notebooks/view_type2_hfss_import.ipynb`는 import-only smoke를 넘어서 runtime이 만든 setup-ready/manual-solve-ready state를 호출/확인하는 thin manual consumer다.
- 현재 importer가 `import_time_policy`를 기대하는 구현은 known drift다. 이 계획의 canonical 문서 계약은 `em_policy` 기준이며 runtime fix는 후속 코드 변경으로 남긴다.

## Acceptance
- Pure-Python fake HFSS tests cover import order, model-state assignment, non-model visual state, TX material/color assignment, TX placement into `tx_region`, ledger writing, missing STEP, missing required field, duplicate object id, missing `tx_region`, empty/duplicate import diff, PyAEDT `False`, and release-on-failure.
- CLI tests cover fresh exporter invocation and `--ledger` existing-ledger mode.
- Required checks:
  - `.venv/bin/python -m pytest tests/type2 tests/backend_em`
  - `.venv/bin/pyright`

## Follow-up
- Imported ledger to `EmPipelineInput` adapter.
- TX/RX conductor role taxonomy beyond `tx_single_coil`.
- Single scene STEP import diff에서 ownership partition을 고정하는 adapter.
- Explicit port/boundary/source/analysis contract for runtime-owned setup-ready state that notebooks/manual callers can consume.
- `ValidateDesign()`까지 완료한 runtime handoff that a thin notebook can call and inspect.
