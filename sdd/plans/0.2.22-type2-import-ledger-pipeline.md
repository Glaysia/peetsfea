# 0.2.22 Type2 Import Ledger Pipeline

## Status
- Import ledger handoff remains active.
- 0.2.24 setup-ready target is RxOnly.

## Active Contract
- Export ledger records RX modeled handoff, non-modeled guide/context entries, source path, seed, and output policy.
- Imported ledger records imported ownership and imported object names only.
- Imported ledger does not own mesh, boundary, ports, reports, validation, or solve state.
- Import-only runtime must not create setup-ready state.
- RxOnly setup-ready consumes the retained ledger and builds RX mesh, one RX port, and RX reports only.
