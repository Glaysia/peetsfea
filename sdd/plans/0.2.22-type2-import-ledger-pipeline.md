# 0.2.22 Type2 Import Ledger Pipeline

## Goal
- type2 STEP handoff를 import-only와 setup-ready로 분리한다.
- import-only ledger는 imported ownership handoff artifact로 축소하고, setup-ready는 runtime-owned `.aedt` state만 남긴다.

## Decisions
- imported ledger schema는 source paths, seed, imported ownership, imported object names만 유지한다.
- mesh/boundary/ports/analysis summary는 imported ledger에 저장하지 않는다.
- radiation boundary와 explicit lumped port의 canonical owner는 setup-ready runtime이다.
- import-only runtime은 `AssignLengthOp`, boundary, `AssignLumpedPort`, source, analysis, `ValidateDesign()`를 호출하지 않는다.
- setup-ready result는 in-memory summary + final `.aedt`만 남긴다.

## Remaining
- current setup-ready baseline은 single-layer TX/RX exact contract만 지원한다.
- TX multilayer mesh/port generalization은 separate follow-up이다.
- type2 public outputs spec/policy ownership은 아직 type2 TOML에 직접 승격하지 않았다.
