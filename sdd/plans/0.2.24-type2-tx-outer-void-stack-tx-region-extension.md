# 0.2.24 Type2 TX Outer Void Stack TX Region Extension

## Goal
- Extend the passive `tx_outer_single_coil` central void stack through the full `tx_region` top boundary instead of stopping at the `tx_outer_region` sloped guide top face.
- Apply the extension to both `tx_outer_void_ferrite_u*` and `tx_outer_void_pet_psa_u*` bodies.
- Preserve the existing realized outer void X/Y footprint, TX outer tilt frame, body labels, passive material/grouping contract, and sampled owner surface.

## Decisions
- The extension target is `tx_region.max_z`, resolved from the base `tx_region` non-model object and already passed into modeled scene construction.
- The outer void stack remains prism-local for X/Y placement:
  - local X fills the realized outer void min/max,
  - local Y fills the realized outer void min/max,
  - local stack bodies are rotated and translated through the same TX outer tilt transform as the outer coil.
- The final top cut is a world-horizontal clip at `tx_region.max_z`, not the current prism-local `z=0` top clip.
- No TOML/schema/version/sampling changes are introduced.
- `tx_outer_underlay_*` bottom-underlay behavior is unchanged.
- `tx_outer_region` guide and `tx_outer_actual_region` bounds remain guide/actual provenance only; neither becomes the Z-extension owner.

- Worker A owns `src/peetsfea/type2_single_coil_scene.py` and its code note. Replace the outer void-stack prism-top clipping path with a `tx_region.max_z` world-top clipping path while keeping fail-fast solid validation and existing tilt transform.
- Worker B owns `tests/type2/test_type2_tx_outer_centering.py` and its code note. Update the focused pure-scene test so outer void stack vertices still project into realized outer void X/Y but now reach `tx_region.max_z` instead of prism-local top `z=0`.
