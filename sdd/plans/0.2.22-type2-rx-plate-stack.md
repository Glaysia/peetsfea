# 0.2.22 Type2 RX Plate Stack

## Goal
- active RX modeled object를 coil-backed `rx_single_coil`에서 geometry-only `rx_plate_stack`으로 교체한다.
- active RX export path가 `tx_rect_void` reusable coil bridge를 더 이상 호출하지 않도록 분리한다.
- 초기 패스는 `geometry/export/spec/sampled/docs` 중심으로 시작했지만, active branch 기준 setup-ready 이후 full EM chain으로 이어지는 계약이 canonical이다.

## Decisions
- active RX role/object id는 `rx_plate_stack` / `rx_plate_stack`으로 고정한다.
- RX plate stack footprint source of truth는 `rx_region_max` full `YZ` bounds다.
- stack anchor는 `rx_region_max.min_x`이고, wall-to-coil order는 다음으로 고정한다.
  1. `rx_copper_wall`
  2. `rx_pcb_wall`
  3. `rx_stack_ferrite_u0..u9`
  4. `rx_stack_pet_psa_u0..u9`
  5. `rx_stack_air_u0..u9`
  6. `rx_pcb_coil`
  7. `rx_copper_coil`
- public RX plate spec field 서술은 historical 초기안이며, active shared striped contract에서는 `turn_count`, `metal_fill_factor`, `shoe_depth_mm`를 포함한다.
- RX plate stack terminal metadata의 sentinel `{"kind": "none"}` 서술은 historical 상태이며, active contract는 `terminal_metadata.kind = "stub_port"`를 사용한다.
- `type2_modeled_import_adapter` 계열 import-only helper는 geometry inspection ownership을 유지하고, active setup-ready facade는 `rx_plate_stack`를 포함한 plate-stack ledger를 full EM chain으로 전달한다.

## Acceptance
- active example RX modeled object parses as `rx_plate_stack`.
- this historical plan has been superseded by the shared TX/RX plate-stack contract; current active RX export
  uses striped copper plus shoe fill and no longer targets a 34-body contract.
- sampled owner-path collection no longer requires coil-only RX range fields.
- import-only helper는 geometry inspection 계약으로 동작하고, active setup-ready path는 `rx_plate_stack` handoff를 포함해 full EM chain까지 연결된다.
