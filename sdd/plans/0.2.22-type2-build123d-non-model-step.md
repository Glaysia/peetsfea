# 0.2.22 Type2 Build123d Non-Model STEP

## Status
- 완료된 baseline milestone.
- 현재 확보된 결과는 non-model STEP 생성과 시각화다.
- 이후 계획 문서는 이 노트를 future task가 아니라 completed prerequisite로 참조한다.
- 이 노트의 `type2_non_model_objects.toml`은 historical baseline input이며, 앞으로의 public type2 SSOT는 [[sdd/plans/0.2.22-type2-toml-unification]]의 `examples/type2/type2.toml`이다.

## Goal
- `examples/type2/type2_non_model_objects.toml`을 historical non-model scene baseline으로 사용해 geometry authoring 가능성을 확인했다.
- TOML의 non-model vacuum box들을 `build123d` compound로 생성하고 STEP artifact로 export했다.
- artifact 생성 이후 시각화 가능한 durable baseline을 남겨 headless import smoke의 입력으로 사용한다.
- 이 baseline의 non-model object list는 다음 구현 단계에서 `examples/type2/type2.toml`의 `[[non_model_objects]]`로 이동한다.

## Scope
- 포함:
  - [[sdd/code/examples/type2/generate_non_model_step.py]]
  - `examples/type2/type2_non_model_objects.toml`
  - `examples/type2/artifacts/type2_non_model_objects.step`
- 제외:
  - `entry/sample.py`, `entry/build.py` 변경
  - AEDT import와 EM pipeline 실행
  - modeled coil, ferrite, port, source spec 설계

## Decisions
- 이 단계의 SSOT 방향은 object registry다. 각 non-model object는 최소한 `id`, `role`, `material`, `model_state=false`, canonical creation coordinates를 가진다고 본다.
- 이 baseline의 `id` field는 `type2.toml` 통합 시 `object_id` naming으로 정리한다.
- `origin_xyz`는 build123d box의 min corner로 해석한다.
- `size_xyz`는 세 축 모두 양수여야 한다.
- type2 non-model TX 영역은 sub-zone으로 쪼개지 않고 단일 `tx_region` box로 둔다.
- 이번 단계의 지원 primitive는 `box`뿐이다.
- `present`와 `non_model`은 모두 `true`여야 하며, 다른 값은 fail-fast 대상이다.
- 중복 object `id`는 허용하지 않는다.
- STEP 생성 실패 또는 `export_step is not True`는 즉시 예외로 처리한다.
