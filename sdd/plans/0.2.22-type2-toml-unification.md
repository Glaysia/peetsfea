# 0.2.22 Type2 TOML Unification

## Goal
- `examples/type2_fixed.toml`을 type2의 단일 SSOT로 만든다.
- 기존 split non-model baseline과 standalone coil prototype 입력은 제거하고, 새 구현은 `type2_fixed.toml`만 기준으로 한다.
- type2 STEP authoring은 하나의 TOML에서 non-model guide objects와 modeled objects를 함께 읽어 object-level STEP artifact와 metadata ledger를 생성한다.

## Scope
- 포함:
  - `examples/type2_fixed.toml`
  - type2 non-model object registry
  - type2 modeled object registry
  - `tx_rect_void` modeled TX coil object를 type2 modeled object로 표현하는 계약
  - object-level STEP artifact + metadata ledger handoff
- 제외:
  - 제거된 split TOML 입력을 새 기능 SSOT로 계속 확장하는 작업
  - EM port/source/solve 계약
  - multi-coil role taxonomy
  - global placement transform

## Decisions
- `type2_fixed.toml`은 type2의 public authoring input이다.
- `type2_fixed.toml`은 최소한 아래 두 registry를 가진다:
  - `[[non_model_objects]]`
  - `[[modeled_objects]]`
- `[[modeled_objects]]`의 지원 object는 현재 `role = "tx_single_coil"`과 `role = "rx_single_coil"`이며 둘 다 rect/void single-coil geometry를 재사용한다.
- `tx_rect_void` standalone TOML의 geometry parameters는 `type2_fixed.toml`의 modeled object entry 아래로 이동한다. 구현은 기존 `src/peetsfea/tx_rect_void.py`의 geometry authoring logic을 재사용할 수 있지만, public input ownership은 `examples/type2_fixed.toml`이 가진다.
- non-model boxes는 `type2_fixed.toml`의 `[[non_model_objects]]`가 소유한다.
- 생성 시점 metadata가 canonical state다. AEDT import 뒤 geometry를 역산해 role, coordinates, terminal semantics를 복원하지 않는다.
- prototype 단계의 imported ledger는 `type2_fixed.toml`의 modeled object entry와 import-time `imported_object_names`를 합쳐 만든다.
- current implementation-era single-coil modeled object는 `terminal_stub_length_mm`를 explicit TOML field로 소유하고, placement fit과 canonical bounds는 stub 포함 높이로 계산한다.
- future canonical single-coil contract에서 stub semantics는
  [0.2.22-type2-multilayer-tx-generic-single-coil](0.2.22-type2-multilayer-tx-generic-single-coil.md)가 정의하는
  derived `layer_gap_mm * 0.8` 방향으로 이동한다.

## Migration Steps
1. `examples/type2_fixed.toml`을 만든다.
2. 기존 split non-model boxes를 `type2_fixed.toml`로 옮긴다.
3. 기존 standalone TX coil fields를 `type2_fixed.toml`의 `[[modeled_objects]]` entry로 옮긴다.
4. type2 exporter가 `type2_fixed.toml`만 읽어 non-model objects와 `tx_single_coil` object를 생성하도록 한다.
5. viewer notebook은 `type2_fixed.toml`에서 생성되는 STEP artifact를 보여준다.
6. modeled import smoke는 `type2_fixed.toml`에서 생성된 STEP artifact와 metadata ledger를 입력으로 사용한다.

## Acceptance
- SDD 문서가 제거된 split TOML 입력을 앞으로의 public SSOT로 설명하지 않는다.
- 새 계획/아키텍처 문서는 `examples/type2_fixed.toml`을 type2의 단일 authoring input으로 설명한다.
- `tx_rect_void`는 standalone workflow가 아니라 `type2_fixed.toml`의 첫 modeled object role로 설명된다.
- non-model and modeled objects share the same object-registry handoff model.
