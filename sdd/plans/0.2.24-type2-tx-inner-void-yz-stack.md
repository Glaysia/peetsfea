# Type2 TX Inner Void YZ Stack

## Intent
- Fill the realized `tx_inner_single_coil` central void and its connected central Y corridor with passive YZ-parallel PET/PSA and MULL12060ferrite sheets.
- The stack starts at the RX/wall-facing `void.min_x`, advances in +X through `void.max_x`, and spans Y across the copper-free central corridor connected to the realized void.
- The stack spans Z from the existing under-coil stack contact plane (`tx_inner_actual_region.min_z`) up to `tx_region.max_z`.
- The purpose is to bring ferrite as close to RX as possible while staying inside the TX inner void footprint and touching the already-installed under-coil stack at its top plane.

## Decisions
- `tx_inner_single_coil` now owns a public integer range field named `void_stack_present`.
- Canonical sampled range is `[true, 0, 1, 2]`; fixed supported ranges are `[true, 0, 0, 1]` and `[true, 1, 1, 1]`.
- `void_stack_present = 0` omits only the `tx_void_*` YZ stack bodies. It must not remove the bottom `tx_underlay_*` bodies.
- `void_stack_present = 1` emits the existing `tx_void_ferrite_u*` / `tx_void_pet_psa_u*` YZ stack contract.
- `underlay_repeat_count` remains the canonical bottom-stack repeat owner and is not reused as the void-stack presence switch.
- Reuse `tx_inner_single_coil.underlay_pet_psa_thickness_mm` and `underlay_ferrite_thickness_mm` as nominal sheet thicknesses.
- Existing XY under-coil stack is coarsened for simulation speed: 1 PET/PSA+ferrite pair below `tx_inner_actual_region`, each nominally `2.0 mm`.
- New YZ void stack uses body prefixes:
  - `tx_void_ferrite_u{n}`
  - `tx_void_pet_psa_u{n}`
- New YZ void stack order starts with ferrite at `void.min_x`, then alternates PET/PSA and ferrite in +X.
- If the void X width is not an exact multiple of the next nominal sheet thickness, the last sheet is shortened to end exactly at `void.max_x`.
- The Y extent is not the central rectangular void height when a longer copper-free central corridor exists. It is the nearest blocker-to-blocker Y interval from the actual copper primitive area inside the selected void X strip, so the stack uses the available central Y gap while still failing if it would overlap copper.
- The fixed example currently yields void X width `71.28 mm`, so it should emit 36 void sheets: thirty-five full `2.0 mm` sheets and a final `1.28 mm` sheet. Those sheets should use the central corridor Y span rather than the smaller central rectangular void Y span.

## Invariants
- The YZ stack is emitted only for `tx_inner_single_coil` when `void_stack_present` resolves true.
- Bottom TX inner underlay is emitted when `underlay_repeat_count > 0` regardless of `void_stack_present`.
- `tx_outer_single_coil` remains no-underlay and receives no void stack.
- All YZ stack bodies are passive and grouped under `g_ferrite_tx` together with the existing TX inner underlay bodies.
- `tx_void_ferrite_u*` must style/materialize as `MULL12060ferrite`; `tx_void_pet_psa_u*` must style/materialize as `PET_PSA`.
- The YZ stack must fail fast if the void footprint or resolved central corridor footprint is non-positive, if the central corridor cannot be proven copper-free, if `tx_region.max_z <= tx_inner_actual_region.min_z`, or if sheet thickness values are non-finite/non-positive.

## Implementation Slots
- Slot A owns spec/types/parser/sampling surface: dataclass field, parser validation, resolver, public import surface, sampled owner ordering, integer design-variable handling, and matching SDD code notes.
- Slot B owns scene/export behavior: separate bottom underlay emission from void-stack emission, expected body/group validation, fixed-disabled STEP regression, and matching SDD code notes.
- Slot C owns official examples and sampling/build/spec-tool tests: add descriptions, expected owner paths, generated sampled TOML checks, viewer/build fixture expectations, and matching example/test notes.
- Slot D owns backend/import/setup-ready regressions and focused validation: import/style/setup-ready expectations for enabled/disabled void stacks, no type1 edits, and matching test notes.
