# Type2 TX Inner Void YZ Stack

## Intent
- Fill the realized `tx_inner_single_coil` central void and its connected central Y corridor with passive YZ-parallel PET/PSA and MULL12060ferrite sheets.
- The stack starts at the RX/wall-facing `void.min_x`, advances in +X through `void.max_x`, and spans Y across the copper-free central corridor connected to the realized void.
- The stack spans Z from the existing under-coil stack contact plane (`tx_inner_actual_region.min_z`) up to `tx_region.max_z`.
- The purpose is to bring ferrite as close to RX as possible while staying inside the TX inner void footprint and touching the already-installed under-coil stack at its top plane.

## Decisions
- No new public TOML fields are introduced for this change.
- Reuse `tx_inner_single_coil.underlay_pet_psa_thickness_mm` and `underlay_ferrite_thickness_mm` as minimum sheet thicknesses for the void X direction.
- Existing XY under-coil stack remains 1 PET/PSA+ferrite pair below `tx_inner_actual_region`, but both configured sheet thicknesses are increased to `6.0 mm` for a `12.0 mm` total bottom stack.
- New YZ void stack uses body prefixes:
  - `tx_void_ferrite_u{n}`
  - `tx_void_pet_psa_u{n}`
- New YZ void stack order starts each pair with ferrite at the lower-X side, then PET/PSA in +X.
- The stack attempts to emit 4 ferrite/PET_PSA pairs. If dividing the void X span into 4 pairs would make either sheet thinner than its configured minimum thickness, the pair count is reduced until every emitted sheet can be at least its configured minimum.
- If the void X span cannot fit one ferrite/PET_PSA pair at the configured minimum thicknesses, export fails immediately.
- For the chosen pair count, the void X span is divided into equal pair spans. Inside each pair, ferrite and PET/PSA are assigned their configured minimum thicknesses first, and any remaining pair span is split evenly between the two sheets.
- The Y extent is not the central rectangular void height when a longer copper-free central corridor exists. It is the nearest blocker-to-blocker Y interval from the actual copper primitive area inside the selected void X strip, so the stack uses the available central Y gap while still failing if it would overlap copper.
- With active `6.0 mm`/`6.0 mm` minimums and the fixed-example `15.84 mm` void X span, the void stack should emit 1 pair: `tx_void_ferrite_u0` and `tx_void_pet_psa_u0`, each `7.92 mm` wide.

## Invariants
- The YZ stack is emitted only for `tx_inner_single_coil` when underlay repeat count is positive.
- `tx_outer_single_coil` remains no-underlay and receives no void stack.
- All YZ stack bodies are passive and grouped under `g_ferrite_tx` together with the existing TX inner underlay bodies.
- `tx_void_ferrite_u*` must style/materialize as `MULL12060ferrite`; `tx_void_pet_psa_u*` must style/materialize as `PET_PSA`.
- The YZ stack must fail fast if the void footprint or resolved central corridor footprint is non-positive, if the central corridor cannot be proven copper-free, if `tx_region.max_z <= tx_inner_actual_region.min_z`, if sheet thickness values are non-finite/non-positive, or if the void X span cannot fit one minimum ferrite/PET_PSA pair.

## Implementation Slots
- Slot A owns TX inner void stack pair-count selection and body construction in `type2_single_coil_underlay.py` plus its code note.
- Slot B owns active example/default thickness updates to `6.0 mm` and parser/sample/build/setup tests.
- Slot C owns STEP export geometry assertions for reduced-pair void stacks and `12.0 mm` bottom underlay.
- Slot D owns backend import/style/grouping/setup-ready expectations for the computed void body names.
