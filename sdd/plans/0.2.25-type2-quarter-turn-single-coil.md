# 0.2.25 Type2 Quarter-Turn Single Coil

## Goal
- Replace single-coil integer `turn_count`/fixed `terminal_path` ownership with sampled quarter-turn ownership.
- Use per-coil sampled owners `x_ratio`, `y_ratio`, `turn_qcount`, `void_factor`, `metal_fill_factor`, `terminal_start`, and `void_stack_present`.
- Derive clockwise terminal metadata internally from `terminal_start` and `turn_qcount`; TOML no longer owns `terminal_path`.

## Contract
- `turn_qcount` is an integer quarter-turn count. Effective turn count is `turn_qcount / 4.0`.
- `terminal_start` is an integer owner with candidates `0..3`, mapped to `A/B/C/D`.
- Winding direction is fixed to `cw`; the derived end corner is `(terminal_start + turn_qcount) % 4`.
- `turn_qcount=4n` must preserve the prior same-corner `n`-turn geometry.
- RX gains `void_stack_present` with the same semantic switch as TX inner void stack presence.
- Legacy single-coil TOML keys `outer_x_usage_ratio`, `outer_y_usage_ratio`, `turn_count`, `void_usage_ratio`, and `terminal_path` are unsupported in the new active type2 examples.

## Dimension Audit
- Active sampled-owner count is 15.
- The 15 owners are `non_model_objects.tx_region.z_gap_from_rx_plane_mm` plus TX inner and RX single-coil `x_ratio`, `y_ratio`, `turn_qcount`, `void_factor`, `metal_fill_factor`, `terminal_start`, and `void_stack_present`.
- Fixed guide/reference owners and fixed `modeled_objects.tv_aluminum_plate.sheet_present` remain outside sampled metadata and build design-variable handoff.
