# 0.2.22 Type2 Plate Stack Bridge Non-Overlap Export

## Goal
- active TX/RX plate-stack bridge geometry가 STEP export 시점부터 non-overlap solid contract를 만족하게 만든다.
- HFSS import 이후 boolean 정리나 fallback 없이, exported scene 자체가 validate 가능한 canonical geometry가 되게 한다.
- `solve inside` material-side warning은 무시하고, true failure인 body intersection만 source geometry에서 제거한다.

## Scope
- 포함:
  - shared plate-stack generator의 bridge/slab geometry contract 수정
  - exported STEP scene non-overlap regression 추가
  - 관련 code note / plan note 갱신
- 제외:
  - pre-unite bridge family 제거
  - HFSS import 단계 bridge 재구성
  - import 후 boolean heal/subtract에 의존하는 해결

## Decisions
- `tx_bridge_s*`, `rx_bridge_s*` source label family는 pre-unite provenance로 유지한다.
- final `expected_exported_body_names`는 role당 united copper body(`tx_plate_copper`, `rx_plate_copper`)를 사용하고, ferrite/copper grouping과 terminal metadata contract를 유지한다.
- bridge는 wall copper outer face에서 coil copper inner face까지의 interior X span만 소유한다. wall/coil copper와는 face contact만 허용하고 positive-volume overlap은 금지한다.
- `pcb_wall`, `stack_pet_psa_u*`, `stack_ferrite_u*`, `stack_air_u*`, `pcb_coil`는 bridge가 지나는 serpentine edge strip과 Z window를 clearance notch로 비워서 bridge와 positive-volume overlap이 없게 만든다.
- import/runtime path는 geometry repair를 하지 않는다. import partition/style/setup-ready는 existing name-based contract만 계속 소비한다.
- fail-fast 기준은 exported solid pair positive-volume overlap이다. edge touch와 face touch는 허용한다.

## Acceptance
- active fixed TX/RX plate-stack export는 role당 final exact body names/count `6`을 유지한다.
- 모든 `tx_bridge_s*` / `rx_bridge_s*`는 adjacent copper turn, PCB slab, ferrite/PET/air slab과 positive-volume intersection이 없어야 한다.
- bridge bbox는 full-thickness span이 아니라 interior X span을 반영해야 한다.
- final exported copper body는 role당 `tx_plate_copper` / `rx_plate_copper` exactly one solid contract를 유지해야 한다.
- import-side pure-Python tests는 existing object name/material/port-sheet reconstruction contract를 그대로 통과해야 한다.
