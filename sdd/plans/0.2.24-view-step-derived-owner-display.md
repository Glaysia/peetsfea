# 0.2.24 View STEP Derived Owner Display

## Summary
- `notebooks/view_step_files.ipynb` must display sampled TOML owner values using canonical sampled owner labels while reading aliased values from their raw TOML source fields.
- The immediate failure is `modeled_objects.tx_outer_rect_void_coil.x_position_ratio`: it is public sampled metadata, but its frozen sampled TOML value is stored at `modeled_objects.tx_inner_rect_void_coil.tx_outer_x_position_ratio`.
- The notebook display layer must use the same canonical-to-raw source mapping already documented for `peetsfea.type2_spec_tools`, without adding fallback behavior or requiring a raw `tx_outer_rect_void_coil` TOML table.

## Implementation Boundary
- Notebook helper logic owns local display extraction only. It must not change sampling, build, export, or TOML schema behavior.
- Library-facing tests should verify notebook-visible behavior without relying on stale `run/sampled/type2/manifest.json` artifacts.
- Static notebook tests should keep checking that descriptions come from `type2_range_owner_descriptions(sampled_toml_path)`.
- Any Python test file substantively edited for this work must update its matching `sdd/code/...md` note in the same change.

## Work Distribution
- Worker A owns the notebook helper in `notebooks/view_step_files.ipynb`; it should add the explicit canonical-to-raw owner mapping and keep the printed owner path canonical.
- Worker B owns notebook artifact/static tests in `tests/type2/test_refresh_type2_step_viewer_artifacts.py` and its SDD note.
- Worker C owns generated sampled TOML/value extraction coverage in `tests/type2/test_type2_spec_tools.py` and its SDD note.
- Worker D owns integration review and focused validation around sampled owner mapping, without editing the notebook or the same test files unless a blocker requires coordination.

## Acceptance
- `show_selected_toml_parameters(VIEW_INDEX)` must no longer raise `KeyError: owner id not found: tx_outer_rect_void_coil` for sampled TOMLs whose metadata includes `modeled_objects.tx_outer_rect_void_coil.x_position_ratio`.
- The displayed line must keep `modeled_objects.tx_outer_rect_void_coil.x_position_ratio` as the label and show the frozen scalar from `modeled_objects.tx_inner_rect_void_coil.tx_outer_x_position_ratio.range`.
- Missing raw source fields, malformed range tables, or non-frozen sampled ranges must still raise immediately with actionable context.
- Focused verification should include `.venv/bin/pytest tests/type2/test_refresh_type2_step_viewer_artifacts.py tests/type2/test_type2_spec_tools.py`.
