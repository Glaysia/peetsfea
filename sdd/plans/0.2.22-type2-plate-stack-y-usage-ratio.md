# Type2 Plate-Stack `y_usage_ratio`

## Intent
- Add an independent sampled `y_usage_ratio` owner to `tx_plate_stack` and `rx_plate_stack`.
- Use the ratio to restrict the full plate stack to a global `Y=0` centered active Y window instead of always using the full owner Y span.

## Contract
- TOML field: `[modeled_objects.y_usage_ratio] range = [false, start, end, count]`
- Valid realized values: `0 < y_usage_ratio <= 1`.
- Active Y size is `owner_size_y * y_usage_ratio`.
- Active Y bounds are centered on global `Y=0`: `[-active_size_y / 2, active_size_y / 2]`.
- The centered active Y window must stay within the placement owner Y bounds. If it does not fit, generation fails immediately.
- The active Y window applies to copper, PCB, PET/PSA, ferrite, air, bridges, stubs, terminal metadata, and modeled ledger bounds.

## Implementation Notes
- Keep X anchoring at owner `min_x` and stack growth in `+X`.
- Keep the existing TX top-Z and RX bottom-Z `z_usage_ratio` behavior unchanged.
- Keep terminal stubs protruding in `-Y`, but make the protrusion start from `active_y_min`, not owner `min_y`.
- Register both ratio paths as sampled owners after `z_usage_ratio` so `sampled.toml`, manifest metadata, and design variables remain deterministic replay inputs.
- Do not add clipping, defaults, compatibility fallback, or owner-center anchoring.

## Verification
- Parser tests must reject missing, integer, non-positive, and above-one ranges.
- Export tests must verify `Y=0` centered bounds, reduced full-stack body bounds, bridge edge translation, and terminal metadata translation.
- Sampling/build tests must freeze and report both TX/RX ratio owner paths and design variables.
- Import tests must verify that setup-ready validation accepts the reduced active Y window plus `-Y` stub overhang and rejects off-center plate-stack Y bounds.
