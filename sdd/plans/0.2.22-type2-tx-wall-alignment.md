# 0.2.22 Type2 TX Wall Alignment

## Goal
- `type2` `tx_single_coil` 배치 계약을 `tx_region` centered-X에서 `tx_region -X` wall-touch로 바꾼다.
- TX는 `-X` anchor만 바꾸고, centered Y + owner max-Z touch 계약은 유지한다.
- export ledger, viewer refresh, HFSS import validation이 같은 TX placement truth를 공유하게 한다.

## Scope
- 포함:
  - TX single-coil export placement
  - viewer refresh placement validation
  - import-side owner-fit validation
  - 관련 pure-Python regression과 code note/doc drift 정리
- 제외:
  - RX placement contract
  - TOML schema/type 추가
  - underlay geometry/taxonomy 변경
  - port-sheet geometry rule 변경

## Decisions
- wall-touch 기준은 copper-only가 아니라 exported modeled outer bounds(PCB+copper union bbox)다.
- `tx_single_coil` canonical placement는 `tx_region.min_x` touch + centered Y + `tx_region.max_z` touch다.
- RX는 계속 `rx_region_max.max_x` touch + centered Y + `rx_region_max.min_z` touch를 유지한다.
- import runtime은 placement mismatch를 repair하지 않고 fail-fast로 유지한다.

## Acceptance
- TX export ledger canonical bounds의 `outer_bounds_min_x`가 `tx_region.min_x`와 같아야 한다.
- viewer refresh validation이 centered-X를 기대하지 않고 `tx_region.min_x` touch를 기대해야 한다.
- import validation이 TX `min_x` mismatch를 `tx_region min_x` 접촉 위반으로 fail-fast해야 한다.
- 관련 pytest와 `pyright`가 통과해야 한다.
