# 0.2.24 View Step GUI Setup-Ready

## Goal
- Keep `notebooks/view_step_files.ipynb` `BUILD_W_GUI=True` on the existing setup-ready debug path.
- Allow sampled TxRx scenes that include geometry-only `tx_outer_single_coil` to reach setup-ready instead of failing at the runtime role gate.
- Keep the notebook's displayed `VIEW_INDEX` aligned with the actual manifest `sample_index`, even when skipped samples make successful entry order differ from sample index.

## Decisions
- `tx_outer_single_coil` remains geometry-only in this change.
- Runtime setup-ready validation may accept `rx_single_coil`, `tx_inner_single_coil`, and one `tx_outer_single_coil` together, because backend setup-ready already filters outer TX from mesh, port, source, and report activation.
- Notebook sample selection uses manifest `entry["sample_index"]`, not successful-entry list position.
- GUI validation remains opt-in and is not part of automated verification for this change.

## Implementation Boundaries
- Runtime gate owner: `src/peetsfea/type2_runtime.py`.
- Runtime regression owner: `tests/type2/test_build_type2_entry.py`.
- Notebook selection owner: `notebooks/view_step_files.ipynb`.
- Static notebook regression owner: `tests/type2/test_refresh_type2_step_viewer_artifacts.py`.

## Acceptance
- `BUILD_W_GUI=True` for `VIEW_INDEX=5` selects the manifest entry whose `sample_index` is `5`.
- `entry/build.py --debug` can proceed past runtime precheck for `('tx_inner_single_coil', 'rx_single_coil', 'tx_outer_single_coil')`.
- Existing unsupported TX-only and TX-column role sets remain rejected before runner execution.
- Focused pure-Python tests and pyright pass from `run/` without launching GUI AEDT.
