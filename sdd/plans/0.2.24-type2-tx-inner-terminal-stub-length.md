# Type2 TX Inner Terminal Stub Length

## Goal
- Make `terminal_stub_length_mm` the realized rect/void single-coil geometry owner instead of deriving stub length from `layer_gap_mm`.
- Fix the official Type2 TX inner coil examples to a 7.5 mm terminal stub.
- Preserve the existing terminal-path convention: the first terminal path token is the start/input/+ terminal, and the last token is the end/output terminal.

## Implementation Boundaries
- `src/peetsfea/tx_rect_void_spec.py` owns range selection and fail-fast validation for the realized stub length.
- `src/peetsfea/tx_rect_void_export.py` and scene assembly should continue consuming `RealizedSingleCoilRectVoid.terminal_stub_length_mm`; they should not introduce a second length owner.
- `examples/type2_fixed.toml` and `examples/type2_sweep.toml` should set TX inner `terminal_stub_length_mm` to `[false, 7.5, 7.5, 1]`.
- No new TOML key is needed because `terminal_stub_length_mm` already exists and is required.

## Acceptance
- Rect/void tests prove the selected TOML stub length is realized and non-positive values fail.
- Type2 STEP tests prove fixed-example TX inner terminal metadata and canonical modeled bounds reflect a 7.5 mm downward stub.
- SDD code notes for substantively edited Python files are updated in the same change.
