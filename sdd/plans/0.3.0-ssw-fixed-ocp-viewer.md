# 0.3.0 SSW Fixed OCP Viewer

## Summary

Add a 0.3.0 fixed-spec debug path that reads `examples/0.3.0_fixed.toml`, generates TX and RX SSW coil STEP geometry, and displays the result in OCP CAD Viewer through the VS Code F5 launch path.

## Implementation Boundary

- New geometry owner: `src/peetsfea/ssw_step.py`
- New F5/debug entrypoint: `entry/debug_view_0_3_0_ssw.py`
- Launch config points at the new entrypoint from `run/`.
- The implementation remains headless except for OCP CAD Viewer display.

## Contracts

- `examples/0.3.0_fixed.toml` remains the source of fixed values.
- `fixed_dimensions.tx_rx_min_distance_mm` defines the Z gap between the TV bottom and the top of the derived TX placement region.
- `tx_region` is the TX non-model placement envelope, not a coil-tight body.
- `tx_region_max` and `rx_region_max` are transparent non-model boxes; `tx_region_max` follows the current TX placement and uses 15 mm thickness, while `rx_region_max` keeps the TOML Y/Z max size envelope, aligns X max to the TV back face, aligns Z min to the TV bottom, and uses 5 mm thickness.
- TX stays on the XY plane, RX stays on the YZ plane, and both coils keep their long dimension along the Y axis.
- TX remains SSW-only. RX mode is explicit in TOML and may use coilmaker normal/spiral mode when RX `is_ssw_enabled` is false.
- TX's SSW port anchor is on the lower Z face of the TX coil, RX's SSW port anchor remains on the RX X-min copper face when RX is in SSW mode, and RX normal/spiral port copper is on the RX X-min back face.
- RX normal/spiral port landing pad width and AEDT direct edge-port length follow the realized trace width.
- RX normal/spiral port landing direction follows the pad edge perpendicular to the outer-terminal trace segment's cardinal direction rather than a frame-axis heuristic.
- TX/RX each get one modeled MULL ferrite sheet with 0.12 mm thickness and the same in-plane footprint as the current coil bounds.
- `ferrite.mull_position_ratio` is a shared TX/RX position variable: `0.0` means TX starts at `tx_region_max.zmin` and RX starts at `rx_region_max.xmin`; `1.0` means the sheet sits closest to the coil without overlap.
- Non-model bodies are transparent in the generated CadQuery/OCP scene.
- TX and RX each contain the same coil fields, including SSW enable and non-SSW quarter-turn values; TX keeps SSW enabled.
- Every fixed range must have `min == max` and `count == 1`.
- Generated artifacts include `coil_making_token.toml`, `ssw_scene.step`, and `ssw_step_ledger.json`.

## Verification

- TOML parsing fails fast on missing fields, invalid ranges, duplicate object ids, and unsupported object roles.
- Unit tests verify TX/RX object loading, frozen range enforcement, derived `tx_region`, sweep-maximum TX/RX non-model bounds, generated ledger names, token TOML parsing, port-anchor face placement, RX normal/spiral back-side port placement, trace-width RX normal/spiral pad, terminal-trace-axis landing direction, AEDT semantic edge endpoint length, MULL ferrite sheet placement, RX explicit normal/spiral token export, long-axis placement, and STEP export failure conversion.
- The VS Code launch command can be replayed from terminal and generates an importable STEP artifact.
