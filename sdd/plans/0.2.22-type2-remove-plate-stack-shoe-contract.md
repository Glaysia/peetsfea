# 0.2.22 Type2 Remove Plate-Stack Shoe Contract

## Goal
- active type2 plate-stack public schema에서 `shoe_depth_mm`를 제거한다.
- this milestone introduced `schema_id = "peetsfea.type2.step.v2"` for shoe removal; later TX array work supersedes active examples to `peetsfea.type2.step.v4`.
- TX/RX plate-stack geometry를 owner full-height contract로 단순화하고 shoe fill body family를 더 이상 export/import하지 않는다.

## Decisions
- `shoe_depth_mm`는 active type2 public schema, sampled owner path, runtime resolver, geometry/export/import contract 어디에도 남기지 않는다.
- v2 plate-stack modeled object에 `shoe_depth_mm`가 나타나면 unsupported key로 즉시 실패한다.
- TX/RX plate-stack final exact body order는
  `*_plate_copper -> *_pcb_wall -> *_stack_pet_psa -> *_stack_ferrite -> *_stack_air -> *_pcb_coil`다.
- striped copper/bridge/stub labels are pre-unite provenance only and must not remain final exported bodies.
- wall/coil PCB와 striped copper active height는 더 이상 trimmed band가 아니라 owner full Z span을 사용한다.
- setup-ready/mesh/port/EM boundary는 기존 import-only ownership을 유지한다. 이번 변경은 plate-stack geometry/schema surface만 정리한다.

## Acceptance
- type2 examples contain no `shoe_depth_mm`; active schema version may be later than this milestone.
- loader rejects `peetsfea.type2.step.v1` for type2 TOML with an explicit schema error.
- plate-stack expected/exported body labels contain no `_shoe_` family.
- fixed TX/RX plate-stack baselines both resolve to `6` final exported bodies.
- import-only material/style partitioning still succeeds for remaining PCB/copper/ferrite/PET_PSA/air bodies.
