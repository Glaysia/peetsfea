# 0.2.24 Type2 TX Inner Region Non-Model STEP

## Goal
- Add the first forward TX guide geometry after RxOnly reset without restoring active TX modeled coils.
- Keep `tx_region` as the maximum future TX guide region.
- Add a Y-axis-parallel TX reference line and an `inner` TX guide volume derived from that line.
- Carry the new non-modeled guide geometry through type2 STEP export and retained ledger only.

## Scope
- Include:
  - type2 TOML/spec support for TX reference-line and inner Y-usage ratios inside `tx_region`
  - deterministic resolution of `x_ref` and `z_ref` from `tx_region` bounds
  - visible non-modeled `tx_inner_region` STEP body
  - retained step-ledger entries for `tx_region`, reference-line facts, and `tx_inner_region`
  - pure-Python tests for parse, realization, export, and ledger handoff
- Exclude:
  - TX modeled coil bodies
  - TX ports, sources, mesh targets, setup-ready EM changes, or active TX output variables
  - `tx_region_actual`, grid, stack-space, tilt, collector, plate-stack, or columns reuse
  - outer/diagonal TX coil region implementation

## Decisions
- `tx_region` remains the only maximum TX placement guide.
- The reference line is not a modeled conductor. It is a guide derived from three sampled ratios owned by `tx_region`:
  - `tx_region.tx_reference_line.x_ratio`
  - `tx_region.tx_reference_line.y_usage_ratio`
  - `tx_region.tx_reference_line.z_ratio`
- The resolved anchor is:
  - `x_ref = tx_region.min_x + tx_region.size_x * x_ratio`
  - `z_ref = tx_region.min_z + tx_region.size_z * z_ratio`
  - line span: `(x_ref, tx_inner_region.min_y .. tx_inner_region.max_y, z_ref)`
- `tx_inner_region` is the non-modeled guide volume bounded by:
  - X: `tx_region.min_x .. x_ref`
  - Y: centered span with size `tx_region.size_y * y_usage_ratio`
  - Z: `tx_region.min_z .. z_ref`
- X/Z ratios must be strictly inside `(0, 1)`, and Y usage ratio must be in `(0, 1]`; invalid values fail before STEP construction.
- `tx_inner_region` is visible in STEP as a vacuum non-model body and is not an EM setup target.
- The retained ledger must preserve creation-time coordinates and the source ratios; later code must not infer the inner region from imported geometry.
- RxOnly behavior remains active: RX mesh, one RX port, RX reports only. The dormant future two-terminal output-variable contract remains owned by [[sdd/architecture/type2-em-report-contract]].

## Sub-Agent Work Packages
- Spec/parser package:
  - Own `src/peetsfea/type2_step_spec_non_model.py` and related type definitions.
  - Add fail-fast parsing for TX reference-line ratios and forbid fallback defaults.
  - Update the matching code note before or alongside code changes.
- Non-model scene/export package:
  - Own `src/peetsfea/type2_non_model_scene.py`, `src/peetsfea/type2_step_export.py`, and ledger handoff touch points.
  - Resolve `tx_inner_region`, export it as non-modeled STEP geometry, and record canonical bounds in the ledger.
  - Keep `tx_region_actual` and stack-space inactive.
- Test package:
  - Own type2 pure-Python tests for fixed/sampled parse, deterministic realization, STEP body names, and ledger entries.
  - Verify the new guide objects do not create TX modeled metadata, TX ports, or TX output variables.

## Acceptance
- `tx_region` still exports as a guide-only non-model body.
- `tx_inner_region` exports as a new guide-only non-model body derived from the reference-line ratios.
- The retained step ledger records `tx_inner_region` canonical coordinates and reference-line ratio provenance.
- Active setup-ready remains RxOnly and does not consume `tx_inner_region` for mesh, ports, sources, reports, or validation.
- Tests prove invalid ratios fail fast, centered Y sizing is deterministic, and valid ratios are deterministic for the same TOML and seed.
