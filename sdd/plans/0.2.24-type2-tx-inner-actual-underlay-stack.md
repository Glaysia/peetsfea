# 0.2.24 Type2 TX Inner Actual Underlay Stack

## Goal
- Add a TOML-controlled backing stack below `tx_inner_single_coil`.
- Use the resolved `tx_inner_actual_region` X/Y footprint, not the larger `tx_inner_region` guide and not the smaller physical copper/PCB bbox.
- Keep the stack imported and styled while preserving existing setup-ready EM scope.

## Decisions
- Physical direction is `-Z` from `tx_inner_actual_region.outer_bounds_min_xyz[2]`.
- Per repeat, the order from coil side downward is `PET_PSA` then `MULL12060ferrite`.
- Fixed example default is 4 repeats, `PET_PSA 0.5 mm` and ferrite `0.5 mm`, total stack thickness `4.0 mm`.
- Public fields live on `tx_inner_single_coil`:
  - `underlay_repeat_count = [true, 4, 4, 1]`
  - `underlay_pet_psa_thickness_mm = [false, 0.5, 0.5, 1]`
  - `underlay_ferrite_thickness_mm = [false, 0.5, 0.5, 1]`
- `underlay_gap_mm` and `wall_parallel_stack_present` remain unsupported for `tx_inner_single_coil`.
- `tx_outer_single_coil` inherits no backing stack; its generated companion underlay count remains fixed zero.
- Active schema id remains `peetsfea.type2.step.v8`.

## Acceptance
- Fixed and sweep examples parse with the new TX inner stack fields.
- STEP export emits `tx_underlay_pet_psa_u0..u3` and `tx_underlay_ferrite_u0..u3` for fixed example TX inner.
- Each underlay body X/Y bounds exactly match `tx_inner_actual_region`; first PET/PSA top touches actual-region minimum Z.
- Import styling applies `PET_PSA` to PET/PSA bodies and `MULL12060ferrite` to ferrite bodies.
- TxRx/RxOnly setup-ready keeps ports, sources, reports, and mesh targets unchanged except imported/styled passive bodies existing in the scene.
