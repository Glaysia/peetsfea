# 0.2.22 Type2 Step Scene Split

## Goal
- Split oversized `src/peetsfea/type2_step_scene.py` by responsibility without changing exported STEP geometry, ledgers, sampled determinism, or import handoff contracts.
- Keep `type2_step_scene.py` as the compatibility facade for existing public scene entrypoints.
- Remove `type2_step_export.py` imports of private helpers from `type2_step_scene.py` by moving shared scene/export helpers to explicit internal modules.

## Target Boundaries
- `src/peetsfea/type2_step_scene.py`
  - Facade only: public scene imports, plate-stack dispatch, and single-coil dispatch.
  - Must remain the stable import path for existing public functions.
- `src/peetsfea/type2_scene_geometry.py`
  - Build123d shape helpers shared by scene/export code: canonical coordinate extraction, labeled solid/group construction, and bounding-box helpers.
- `src/peetsfea/type2_non_model_scene.py`
  - Non-model scene resolution and ledger shape creation.
  - Owns `tx_region_actual`, `tx_region_actual_stack_space`, stack-space tilt transforms, tile id parsing, candidate selection for non-model derived fields, and non-model scene member ordering.
- `src/peetsfea/type2_single_coil_ports.py`
  - Single-coil terminal path parsing, terminal metadata, local terminal plane points, port-sheet labels, and port-sheet vertex/shape helpers.
- `src/peetsfea/type2_single_coil_underlay.py`
  - Single-coil TX wall-parallel underlay and RX backing underlay geometry.
  - Owns underlay thickness/ratio constants and fail-fast underlay fit checks.
- `src/peetsfea/type2_single_coil_scene.py`
  - Single-coil scene orchestration: placement offset, `tx_rect_void` bridge, transformed box specs, ferrite grouping, underlay integration, canonical coordinates, and final `ModeledObjectSceneData`.

## Implementation Rules
- Do not change public behavior, TOML schema, sampling, body names, group names, ledger keys, or tests expectations.
- Do not touch legacy `type1` code.
- Do not introduce fallback paths. Missing unsupported state must raise with context.
- New modules must not import from `type2_step_scene.py`; the facade imports from the new modules.
- `type2_step_export.py` must import shared helpers directly from `type2_scene_geometry.py` and `type2_non_model_scene.py`, not from `type2_step_scene.py`.
- Preserve existing in-flight edits in `type2_step_export.py`, `type2_tx_rect_void_columns.py`, examples, and tests.

## Sub-Agent Work Split
- Worker A owns `type2_scene_geometry.py` and `type2_non_model_scene.py`.
- Worker B owns `type2_single_coil_ports.py`.
- Worker C owns `type2_single_coil_underlay.py`.
- Worker D owns `type2_single_coil_scene.py`, the final `type2_step_scene.py` facade, and `type2_step_export.py` import rewiring.

## Acceptance
- `src/peetsfea/type2_step_scene.py` is below 800 lines after the split.
- Every new tracked Python file has a matching `sdd/code/src/peetsfea/...py.md` note.
- `type2_step_export.py` has no import from `type2_step_scene.py` whose imported name starts with `_`.
- Default pure-Python type2 STEP tests pass from `run/`.
- Pyright passes for the changed scene/export modules.
