# 0.2.25 Type2 TX/RX Shared Plate Stack Import-Only

## Goal
- active type2 modeled objects를 TX/RX 모두 coil family에서 plate-stack family로 옮긴다.
- TX와 RX는 하나의 shared plate-stack generator를 쓰고, active path에서는 `tx_rect_void` coil generator를 더 이상 호출하지 않는다.
- geometry/export와 AEDT geometry-view import-only는 지원하되, setup-ready/mesh/port/EM은 명시적으로 막는다.

## Decisions
- active TX role/object id는 `tx_plate_stack` / `tx_plate_stack`이다.
- active RX role/object id는 `rx_plate_stack` / `rx_plate_stack`이다.
- TX footprint source of truth는 `tx_region` full `YZ`, anchor는 `min_x`, stack axis는 `+X`다.
- RX footprint source of truth는 `rx_region_max` full `YZ`, anchor는 `min_x`, stack axis는 `+X`다.
- 두 role 모두 PCB 2장 + literal 10 ferrite/PET/air sets를 유지하고 terminal metadata는 `{"kind": "none"}`만 가진다.
- import-only path는 두 role을 허용하고, setup-ready/mesh/port/EM path는 fail-fast unsupported role로 처리한다.

## Acceptance
- active examples use `tx_plate_stack` + `rx_plate_stack`.
- export preserves exact TX/RX 34-body contracts.
- import-only can open the active geometry in AEDT and write imported ledger artifacts.
- setup-ready/mesh/port/EM reject plate-stack roles with one explicit unsupported message.
