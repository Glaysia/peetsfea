# 0.2.22 Type2 Plate-Stack Full EM

## Goal
- active `tx_plate_stack` + `rx_plate_stack` exact pair를 current port-ready branch에서 full EM-ready branch로 확장한다.
- import-only helper는 geometry inspection surface로 유지하고, active default build/runtime owner는 role-aware setup-ready facade로 유지한다.
- plate-stack exact pair도 coil exact pair처럼 mesh, explicit ports, source phase, analysis/report, `ValidateDesign()`까지 완료된 `.aedt`를 남긴다.

## Decisions
- active exact pair는 계속 `tx_plate_stack` / `rx_plate_stack`이다.
- numeric port/excitation naming은 유지한다.
  - TX: `1` / `1_T1`
  - RX: `2` / `2_T1`
- plate-stack terminal metadata contract는 계속 `kind = "stub_port"`다.
- reconstructed sheet contract는 유지한다.
  - `tx_plate_port_sheet`
  - `rx_plate_port_sheet`
- plate-stack mesh owner는 conductor-only exact set이다. underlay solids, PCB bodies, reconstructed port sheets는 mesh 대상이 아니다.
- plate-stack mesh exact set은 imported exact-name order의 모든 copper family다.
  - `*_copper_wall_t*`
  - `*_copper_coil_t*`
  - `*_bridge_s*`
  - `*_stub_in`
  - `*_stub_out`
- `build_type2_em_input()`는 plate-stack exact pair를 더 이상 reject하지 않는다.
- plate-stack `EmPipelineInput.ready_objects`는
  - TX/RX conductor = role-local `copper_names` 전체
  - FR4 = `*_pcb_wall`, `*_pcb_coil`
  - ferrite = empty list 유지
  로 조립한다.
- plate-stack endpoint world coordinate는 `stub_port.start_point_plane_mm` / `end_point_plane_mm`와 modeled plane `YZ`에서 직접 계산한다.
- endpoint typing은 plate-stack semantic을 숨기지 않게 확장한다.
  - `GroupEndpointEntry.group_kind`에 `tx_plate_stack`, `rx_plate_stack` 추가
  - `TerminalLabel`에 `input_stub`, `output_stub` 추가
- setup-ready facade는 plate-stack exact pair에 대해서도 coil branch와 동일한 후반부를 실행한다.
  - post-import mesh
  - radiation boundary
  - explicit lumped ports
  - source phase
  - analysis/report
  - `validate_pipeline()`
  - `ValidateDesign()`
  - final save
- result contract는 plate-stack도 full `Type2SetupReadyResult` shape를 반환하는 쪽으로 수렴한다.

## Acceptance
- plate-stack exact pair build path가 full setup-ready result를 반환한다.
- plate-stack mesh payload는 imported exact-name order의 copper family 전체만 포함한다.
- underlay/PCB/reconstructed port sheet가 mesh payload에 섞이면 즉시 실패한다.
- plate-stack exact pair는 source phase, analysis/report, `validate_pipeline()`, `ValidateDesign()`까지 통과한다.
- mixed coil/plate role set과 malformed role set은 계속 HFSS launch 전에 fail-fast다.
- import-only helper는 계속 boundary/ports/analysis owner가 아니다.
- active docs와 code notes가 더 이상 plate-stack를 port-ready-only branch로 설명하지 않는다.
