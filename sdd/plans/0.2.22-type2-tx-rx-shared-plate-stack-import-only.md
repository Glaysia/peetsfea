# 0.2.22 Type2 TX/RX Shared Plate Stack Port-Ready

## Goal
- active type2 modeled objects를 TX/RX 모두 coil family에서 plate-stack family로 옮긴다.
- TX와 RX는 하나의 shared plate-stack generator를 쓰고, active path에서는 `tx_rect_void` coil generator를 더 이상 호출하지 않는다.
- geometry/export와 AEDT geometry-view import-only surface는 유지하되, active plate-stack exact pair의
  canonical build/runtime path는 setup-ready facade의 port-ready branch로 승격한다.
- default `entry/build.py` path는 active plate-stack manifest에서 import-only helper가 아니라
  role-aware setup-ready facade를 호출한다.

## Decisions
- active TX role/object id는 `tx_plate_stack` / `tx_plate_stack`이다.
- active RX role/object id는 `rx_plate_stack` / `rx_plate_stack`이다.
- TX footprint source of truth는 `tx_region` full `YZ`, anchor는 `min_x`, stack axis는 `+X`다.
- RX footprint source of truth는 `rx_region_max` full `YZ`, anchor는 `min_x`, stack axis는 `+X`다.
- 두 role 모두 PCB 2장 + literal 10 ferrite/PET/air sets를 유지한다.
- `shoe_depth_mm`는 active conductor trim과 cutout-replace shoe fill을 동시에 소유한다.
- plate-stack `turn_count`는 wall-side copper owner이며 coil-side copper는 항상 `turn_count - 1`이다.
- plate-stack terminal metadata는 `kind = "stub_port"`를 쓰고, import/runtime path는
  `tx_plate_port_sheet` / `rx_plate_port_sheet`를 metadata로 재구성한다.
- role-aware setup-ready facade는 exact plate-stack pair를 허용하고, 그 branch에서는
  import core 재사용 뒤 radiation boundary, explicit ports, final `.aedt` save까지만 수행한다.
- plate-stack branch는 `assign_post_import_mesh`, `build_type2_em_input`, source/analysis/report,
  `ValidateDesign()`를 호출하지 않는다.
- mixed coil/plate role set과 malformed role set은 HFSS work 시작 전에 fail-fast로 막는다.
- import-only helper는 geometry inspection/debug owner로 유지되며, active default build owner는 아니다.

## Acceptance
- active examples use `tx_plate_stack` + `rx_plate_stack`.
- export preserves exact TX/RX no-shoe body contracts.
- active fixed example counts are TX `43`, RX `43`.
- import/runtime path can open the active geometry in AEDT and write imported ledger artifacts.
- reconstructed names include `tx_plate_port_sheet` / `rx_plate_port_sheet`.
- default build path writes plate-stack port-ready `.aedt` artifacts with radiation boundary and
  explicit TX/RX ports.
- plate-stack branch keeps mesh/direct EM helper execution unsupported with one explicit message.
