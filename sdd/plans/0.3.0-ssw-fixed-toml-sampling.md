# 0.3.0 SSW Fixed TOML Sampling

## Summary
- Add a public SSW design-space sampling API that writes deterministic fixed TOML points from a sweep candidate.
- Accept only sweep candidates that are subsets of `examples/0.3.0_sweep.toml`.
- Require every generated TOML to pass the fixed SSW parser and constraints before it is accepted.

## Contracts
- Sampling takes `sample_count`, `seed`, `sweep_toml_path`, `output_dir`, `reference_toml_path`, and `max_attempts_per_sample`.
- Reference free paths are the only sampled owners; fixed paths remain unchanged and non-reference varying paths are rejected.
- Integer ranges sample uniformly over inclusive integer bounds; float ranges sample uniformly over candidate lower/upper bounds.
- Output TOML freezes sampled free paths as `[is_integer, value, value, 1]`.
- Output filenames use the existing short point identity stem: `{design_id}.toml`.

## Validation
- The candidate sweep must pass the existing subset check before any output file is accepted.
- Generated point identities must be unique within the batch.
- Pre-existing output files are rejected instead of overwritten.
- Constraint failures are resampled up to `max_attempts_per_sample`, then raised with sample index context.
