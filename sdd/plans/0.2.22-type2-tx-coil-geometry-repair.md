# 0.2.22 Type2 TX Coil Geometry Repair

## Goal
- Type2 TX modeled export를 shared single-coil engine 기준으로 정리한다.
- public example/source of truth는 계속 `examples/type2_fixed.toml`이다.
- corner geometry의 canonical source는 [[sdd/plans/0.2.22-type2-single-coil-corner-relief]]가 맡는다.

## Decisions
- `tx_single_coil`은 `src/peetsfea/tx_rect_void.py`의 shared engine을 사용하고, TX/RX 차이는 profile/placement/body-name prefix에 한정한다.
- TX centerline/export path의 canonical corner는 이제 always-on blunt corner다.
- same-corner terminal seed, exported 2-body contract, placement-owner contract, metadata/import contract는 유지한다.
- PCB footprint는 routing envelope가 아니라 generated copper planar bounds에서 파생된다.
- `boxes`는 debug/decomposition payload이며, 최종 exported copper ownership은 exact joined segment strip + stub geometry가 가진다.
- recurrence root cause는 joined segment owner와 separate join filler/debug payload가 같이 살아 있던 해석 혼선이었다. TX path는 joined segment primitive 하나만 live owner로 유지해야 한다.
- current public example은 single-layer지만, corner contract 자체는 layer count와 무관하게 blunt-only다.
