# 0.2.22 Type2 TX Coil Geometry Repair

## Goal
- Type2 TX coil STEP export를 type1 TX DD baseline에 가까운 단층 mm 기반
  geometry로 정리한다.
- Type2 public input은 `examples/type2/type2.toml` 하나만 사용한다.
- STEP export 시 copper segment decomposition을 그대로 내보내지 않고 단일
  fused copper body를 생성한다.

## Decisions
- Modeled `tx_single_coil` outer dimensions are `outer_x_mm` and `outer_y_mm`.
- Type2 v1 supports `turn_count` 1..4 and `layer_count` exactly 1.
- Multi-layer coil requests fail fast until via, layer polarity, and inter-layer
  terminal contracts are specified.
- The coil centerline follows the type1 neo TX DD same-corner planner. This
  avoids the historical shortcut where an outer terminal corner connected
  directly into the inner path and shorted turns.
- Outer terminal points are seeded to the next ring coordinate, matching the
  type1 fix for `D_ccw_to_d` and related same-corner paths.
- Segment boxes extend by half trace at both ends along the segment direction,
  so adjacent traces meet by their rectangular vertices instead of only at
  centerline endpoints.
- Type2 v1 fixes void center ratios at zero; off-center void routing needs a
  separate path planner before it can be enabled safely.
- Copper segment boxes remain debug metadata only. Exported STEP bodies must be
  `tx_pcb_l0` and `tx_copper_l0`.
- Metadata records `expected_exported_body_names` and
  `expected_exported_body_count`; import smoke validates imported object count
  against that contract.
- Non-adjacent copper segment overlap is a fail-fast turn-to-turn short check.

- No active code path uses removed split TOML inputs as defaults.
- `examples/type2/view_step_files.ipynb` registers the unified generated type2
  modeled object viewer, not the removed tracked non-model STEP artifact.
