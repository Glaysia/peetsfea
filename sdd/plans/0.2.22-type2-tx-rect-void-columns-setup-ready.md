# type2 tx rect-void columns setup-ready

## Intent
- Promote the active SSOT pair `tx_rect_void_columns` + `rx_single_coil` from STEP export to setup-ready AEDT generation.
- Keep HFSS solve execution out of scope; `entry/build.py` remains a bulk `.aedt` producer for the external solve fleet.
- Preserve the current `examples/type2_sweep.toml` / `examples/type2_fixed.toml` public field surface.

## Decisions
- Supported active pair is exactly `tx_rect_void_columns` + `rx_single_coil`.
- TX conductor is the fused exact exported body `tx_rect_void_columns_copper`.
- TX PCB members are exact `txrvc_*_pcb_l*` bodies.
- TX port sheet is reconstructed from `terminal_metadata.tab_face_vertices_xyz` and named `tx_rect_void_columns_port_sheet`.
- TX port uses numeric boundary/excitation `1` / `1_T1`; RX remains `2` / `2_T1` in paired mode.
- Mesh targets are conductor-only: `tx_rect_void_columns_copper` and `rx_copper_l0`.
- Source phase uses existing paired behavior: TX `288V`, RX `0V`.
- Report/output variables use the full 0.2.21-style TX/RX set, including self, mutual, S-parameter,
  acceptance, normalized S21, and FOM efficiency terms.

## Acceptance
- `entry/build.py` can build sampled/fixed manifests containing `tx_rect_void_columns` + `rx_single_coil` through setup-ready save.
- Import ledger validation accepts columns metadata kinds `parallel_collector_tabs` and `series_collector_tabs`.
- Malformed columns tab metadata, duplicate/missing tab terminals, unsupported role sets, and generic `SOLID*` drift fail fast.
- Tests cover mesh, reconstructed port sheet, port names, sources, report creation, `ValidateDesign()`, and saved `.aedt` result for the columns+RX pair.
