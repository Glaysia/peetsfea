# type2 tx rect-void columns geometry

## Intent
- Reopen `tx_rect_void_columns` at the STEP geometry layer while preserving the current TOML field surface as the SSOT.
- Use realized `tx_region_actual_stack_space` tiles as the concrete TX coil owners; realized coil count is `x_division_count * y_division_count`.
- Resolve per-tile turn counts from the new mode-aware allocation contract before rendering rect/void tile geometry.
- Keep AEDT setup-ready, import semantics, source/port assignment, and TX EM output variables out of this phase.

## Scope
- Add a new modeled role `tx_rect_void_columns` with object id `tx_rect_void_columns`.
- Public TX fields are exactly the current `examples/type2_sweep.toml` / fixed realization surface. Do not create a second example path and do not edit the example TOMLs while implementing this milestone.
- Shared TX fields include `pcb_thickness_mm`, `copper_thickness_mm`, `layer_count`, `layer_gap_mm`, `terminal_stub_length_mm`, `void_usage_ratio`, `margin_ratio`, `metal_fill_factor`, and `terminal_path`.
- TX column outer size is owned by each concrete `tx_region_actual_stack_space` footprint; `outer_x_usage_ratio`, `outer_y_usage_ratio`, `outer_x_mm`, and `outer_y_mm` are unsupported for `tx_rect_void_columns`.
- Removed old public fields `turn_count_x0`, `turn_count_x1`, `turn_count_x2`, `column_connection_mode`, and `row_connection_mode` must not be read by geometry code.
- Per-tile turn counts are resolved from `connection_mode`, the single public `equivalent_turn_count` owner, and `turn_weight_a/b/c` using `type2_tx_turns.resolve_tx_turns`.
- `connection_mode = 0` means parallel allocation; `connection_mode = 1` means series allocation.
- `equivalent_turn_count` is the one electrical target used by both connection modes. Series mode treats it as the whole-chain physical turn-sum target and allocates approximately `round(equivalent_turn_count)` turns across the realized chain. Series allocation must never exceed 31 total physical turns.
- Parallel mode does not sum all physical branch turns into the equivalent count. It chooses integer branch turns `n_i` and computes equivalent turns as `1 / sum(1 / n_i)` across the realized parallel branches. Each branch must stay in `1..10` turns.
- Parallel targets that are not exactly representable by integer branch turns choose the deterministic closest realized equivalent value. Equal-distance groups still keep equal turn counts.
- The supported public sweep range is `0.1111111111111111..31.0` with 31 candidates. High values are series-only feasible; parallel feasibility depends on realized branch count and the `1..10` per-branch cap.
- `layer_count` is shared by all realized TX columns and must resolve to 1, 2, 3, or 4.
- Export support stops at STEP and ledger generation. AEDT build/setup-ready remains unsupported for this role until a later port/connection plan.
- `sample_type2(..., make_step_on_sample=true)` and direct `export_type2_step_artifacts(...)` are in scope for generating STEP artifacts.
- Direct single-coil export helpers remain role-specific and should continue to reject `tx_rect_void_columns`.
- Each realized TX column tile emits exactly two geometry-only terminal bodies (`start`/`end`). In multilayer tiles, each terminal body first parallels the corresponding layer anchors and then descends toward the world floor (`-Z`), not normal to the tilted coil plane.
- `terminal_stub_length_mm` owns the world-vertical stub length for `tx_rect_void_columns`; the active examples keep it fixed at 10.0 mm.

## Invariants
- Geometry is placed inside the matching tilted `tx_region_actual_stack_space` members, not inside the axis-aligned guide tiles.
- Every realized X/Y tile gets separate PCB and copper bodies for each PCB layer.
- No TX ferrite/underlay bodies are emitted in this phase.
- No `tx_copper_stack`, separate inter-layer terminal bus, reconstructed TX port sheet, or source metadata is emitted for `tx_rect_void_columns`.
- Turn allocation order is the deterministic resolved stack-space tile order, sorted by `(x_index, y_index, object_id)`.
- Turn-weight normalized `|x|` is computed from realized stack-space tile centers relative to the resolved `rx_region_max` center X.
- Series allocation satisfies `sum(n_i) <= 31` and targets the rounded equivalent count. Parallel allocation satisfies the closest feasible harmonic equivalent turn target and does not use physical turn sum as the electrical equivalent.
- Generated TX coil PCB/copper bodies must remain inside their owning tilted stack-space body; terminal bodies may protrude below that stack-space and are validated separately. Their bottom travel is world-axis-aligned while their contact face must match the tilted coil/collector face, like a slanted cut.

## 40 Percent STEP Milestone
- Full scene STEP export accepts `tx_rect_void_columns` and writes scene STEP, modeled metadata, and ledger entries for geometry-only TX columns.
- Sampling with `make_step_on_sample=true` works for TX columns source TOML because it uses the same full scene exporter.
- Build/setup-ready still fails fast before AEDT setup for `tx_rect_void_columns`.
- Metadata records geometry-only TX tile members and the resolved allocation facts needed to audit turn count choices; it does not define TX electrical connection or port semantics.
- Tests must treat `examples/type2_sweep.toml` and `examples/type2_fixed.toml` as the source of truth, not rewrite them.

## Parallel Collector Milestone
- `connection_mode = 0` now adds underside collector routing and exports one fused TX copper handoff body plus per-tile PCB bodies.
- `connection_mode = 1` remains geometry-only with `connection_status = "skipped_series"` and no collector source solids, external tabs, or port-sheet-ready metadata.
- Parallel routing uses same-polarity copper pours rather than thin row rail/spine traces: one broad start pour and one broad end pour feed the realized branch terminals and two adjacent external tabs in a dedicated port bay.
- Routing must preserve geometric/electrical symmetry: aggregate start/end pour reach must balance, per-branch spread must stay bounded after tilt, and metadata must expose the branch balance audit.
- Routing must avoid excessive start/end inter-layer overlap: start and end pours are biased to opposite X sides and must not become two full-array overlapping planes; positive-volume start/end collector intersection is a fail-fast error.
- The future port handoff consists of exactly two metadata-owned tab faces. HFSS lumped-port reconstruction and assignment remain out of scope.
