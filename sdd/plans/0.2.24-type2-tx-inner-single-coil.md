# 0.2.24 Type2 TX Inner Single Coil

## Goal
- Add the first explicit TX modeled geometry after the RxOnly reset.
- Keep the geometry EM-inactive: no TX port, TX source, TX mesh owner, or TX output variables.
- Reuse rect-void single-coil geometry in the `XY` plane inside the derived `tx_inner_region`.

## Decisions
- Public role/object identity is `tx_inner_single_coil` / `tx_inner_rect_void_coil`.
- Placement owner is the resolved non-modeled `tx_inner_region`.
- Size is sampled by `outer_x_usage_ratio` and `outer_y_usage_ratio` against the resolved owner footprint.
- Multilayer fields are public from v1; underlay/ferrite fields are not.
- The active sweep example opens `tx_inner_rect_void_coil.layer_count` across integer candidates `1..8`.
- `underlay_repeat_count` must be fixed to zero for the inner TX coil.
- Terminal metadata is retained in the modeled ledger for future EM, but active setup-ready filters modeled objects to RX only.

## Acceptance
- Type2 fixed/sweep examples can include `tx_inner_single_coil` and still run RxOnly setup-ready.
- STEP export includes `tx_inner_*` PCB/copper bodies and ledger metadata.
- Sampling includes inner-coil sampled owners when their ranges have `count > 1`.
- `examples/type2_sweep.toml` exposes `modeled_objects.tx_inner_rect_void_coil.layer_count` as `[true, 1, 8, 8]`.
- Focused STEP tests cover an 8-layer TX inner coil body-name/export contract.
- Active EM setup creates only RX mesh, RX port, RX source, and RX output variables.
