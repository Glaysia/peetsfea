# 0.2.22 Type2 TX Columns Reset

## Goal
- active type2 public surface에서 `tx_rect_void_columns`를 철회한다.
- 기존 TX columns geometry/export path는 fail-fast unsupported surface로 내린다.
- 후속 TX 재설계는 새 sampled contract와 분배 규칙을 문서로만 먼저 동결한다.

## Decisions
- active operator/default path는 계속 RX-only다.
- `tx_rect_void_columns` modeled role은 parser에서 즉시 reject한다.
- 기존 `turn_count_x0`, `turn_count_x1`, `turn_count_x2`, `column_connection_mode`, `row_connection_mode`,
  `tx_rect_void_columns_no_series_series`는 future active schema에서 제거 대상으로 문서화한다.
- future TX contract는 아래 sampled fields를 기준으로 다시 설계한다.
  - shared `layer_count = [true, 1, 4, 4]`
  - shared `layer_gap_mm = [false, 1.0, 1.8, 5]`
  - shared `terminal_stub_length_mm = [false, 10.0, 10.0, 1]`
  - `connection_mode = [true, 0, 1, 2]`
  - `parallel_equivalent_turn_count = [false, 0.1111111111, 36.0, 150]`
  - `series_total_turn_count = [true, 1, 36, 36]`
  - `turn_weight_a = [false, 0.5, 1.5, 5]`
  - `turn_weight_b = [false, -0.5, 0.5, 21]`
  - `turn_weight_c = [false, -0.5, 0.5, 21]`
- future turn allocation rule:
  - `x`는 realized coil center의 RX-center 대비 `|x|`를 realized max distance로 나눈 `0..1` 값이다.
  - `w_i = a + b x_i + c x_i^2`는 모든 realized coil에서 `> 0`이어야 한다.
  - series는 `series_total_turn_count >= realized_coil_count`를 강제하고, 각 coil 1턴 선할당 후 largest remainder로 분배한다.
  - parallel은 `1 / T = sum(1 / n_i)`를 정의로 하고 reciprocal-share target에서 greedy reciprocal-error 보정으로 자연수 턴을 확정한다.

## Scope
- 포함:
  - parser/sample/build/example/doc surface에서 old TX columns 계약 제거
  - `type2_sweep.toml`과 `type2_fixed.toml`의 public field surface를 통일
  - fail-fast rejection tests와 SDD note 갱신
  - `tmp/tx개편.md` future contract/TODO 정리
- 제외:
  - 새 TX geometry authoring
  - 새 TX export/import/setup-ready runtime
  - 새 TX turn allocator implementation

## Acceptance
- source TOML에서 `role = "tx_rect_void_columns"`가 즉시 실패한다.
- active example TOML은 TX columns block 없이 로드된다.
- old TX columns parser/sampling/export tests는 rejection coverage 또는 removal-aware coverage로 갱신된다.
- build/setup-ready는 기존처럼 TX columns surface를 지원하지 않는다.
- future TX contract와 TODO가 `tmp/tx개편.md`에 decision-complete 상태로 정리된다.

## 30 Percent Milestone
- Parser reopens `tx_rect_void_columns` only as a sampling/preflight surface, not as a geometry/runtime surface.
- `examples/type2_sweep.toml` is the SSOT for the TX columns variable surface.
- `examples/type2_fixed.toml` is a fixed realization of the same public RX/TX field surface.
- New public TX columns fields replace the removed per-X turn and row/column connection fields:
  - `connection_mode`
  - `series_total_turn_count`
  - `parallel_equivalent_turn_count`
  - `turn_weight_a`
  - `turn_weight_b`
  - `turn_weight_c`
- Effective sampled owners are mode-aware:
  - `connection_mode`, `turn_weight_a`, `turn_weight_b`, and `turn_weight_c` are always effective when sampled.
  - `series_total_turn_count` is effective only when realized `connection_mode = 1`.
  - `parallel_equivalent_turn_count` is effective only when realized `connection_mode = 0`.
- Turn allocation is pure Python and deterministic. It must not create STEP geometry or AEDT runtime behavior.
- Export/build/runtime entrypoints still fail fast for `tx_rect_void_columns` with a message that the role is parser/sampler-only until the geometry milestone.
- The existing old geometry helper may remain in the repository, but active export paths must not call it for accepted TX columns specs.

## 30 Percent Acceptance
- New TX columns source TOML parses and can be sampled with `make_step_on_sample = false`.
- Sampled metadata includes exactly the effective owner set for the realized connection mode.
- Old fields `turn_count_x0`, `turn_count_x1`, `turn_count_x2`, `column_connection_mode`, and `row_connection_mode` fail as unsupported.
- Allocation helpers cover positive weights, series infeasibility, series largest-remainder distribution, and parallel reciprocal-error distribution.
- Full STEP export, direct modeled export, and build/setup-ready still reject `tx_rect_void_columns`.
