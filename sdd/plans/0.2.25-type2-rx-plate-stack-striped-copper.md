# 0.2.25 Type2 RX Plate Stack Striped Copper

## Goal
- active `rx_plate_stack` role을 유지한 채 RX copper를 full-face slab에서 multi-turn striped copper coil로 바꾼다.
- TOML이 `turn_count`와 `metal_fill_factor`를 받아 front/back plate와 bridge geometry를 deterministic하게 만든다.
- current `rx_plate_stack` geometry/export-only 방향은 유지하고, import/setup-ready/EM은 계속 guardrail로 막는다.

## Scope
- 포함:
  - `rx_plate_stack` TOML/spec 확장
  - sampled owner-path 수집과 realized fixed/free range 처리
  - RX striped copper geometry/export/ledger body contract
  - 관련 tests/docs/SDD note 갱신
- 제외:
  - `tx_plate_stack` topology 변경
  - `rx_plate_stack` import/setup-ready/EM 지원
  - terminal/port reconstruction metadata 설계

## Decisions
- active RX role/object id는 계속 `rx_plate_stack` / `rx_plate_stack`이다.
- public RX plate spec은 기존 `pcb_total_thickness_mm`, `copper_thickness_mm`, `ferrite_set_count`에 아래 두 range field를 추가한다.
  - `turn_count`
  - `metal_fill_factor`
- current example baseline은 아래 비자유변수로 고정한다.
  - `turn_count = [true, 3, 3, 1]`
  - `metal_fill_factor = [false, 0.4, 0.4, 1]`
- 구현은 fixed-only special case를 두지 않는다. sampled/free range가 들어와도 같은 geometry formula를 그대로 적용한다.
- placement owner source of truth는 계속 `rx_region_max` full `YZ` bounds다.
- full-face non-copper bodies는 유지한다.
  - `rx_pcb_wall`
  - `rx_stack_ferrite_u*`
  - `rx_stack_pet_psa_u*`
  - `rx_stack_air_u*`
  - `rx_pcb_coil`
- copper는 아래 exact-name family로 바꾼다.
  - wall-side stripes: `rx_copper_wall_t0..t{N-1}`
  - coil-side stripes: `rx_copper_coil_t0..t{N-1}`
  - side bridge stubs: `rx_bridge_s0..s{2N-2}`
- `front/back` user language는 repository geometry에서는 `wall-side` / `coil-side` face를 뜻한다.
- realized geometry formula는 아래로 고정한다.
  - `N = realized turn_count`
  - `pitch_z = owner_size_z / N`
  - `trace_height_z = pitch_z * realized metal_fill_factor`
- wall-side stripe `t{i}`는 `z_min + i * pitch_z`에서 시작한다.
- coil-side stripe `t{i}`는 `z_min + (pitch_z / 2) + i * pitch_z`에서 시작한다.
- current half-pitch offset contract 때문에 `metal_fill_factor`는 `0 < fill <= 0.5`만 허용한다.
- bridge는 via/edge-plating abstraction이 아니라 copper cuboid stub body다.
- bridge sequence는 가변 `turn_count`에도 같은 serpentine 규칙을 따른다.
  - `s0`: `wall_t0 <-> coil_t0` at `Y=max`
  - `s1`: `coil_t0 <-> wall_t1` at `Y=min`
  - `s2`: `wall_t1 <-> coil_t1` at `Y=max`
  - 같은 패턴을 반복해 마지막 `s{2N-2}`는 `wall_t{N-1} <-> coil_t{N-1}` at `Y=max`
- bridge stub size는 아래로 고정한다.
  - X: wall copper outside face에서 coil copper outside face까지 전체 stack thickness
  - Y: `copper_thickness_mm`
  - Z: 연결되는 stripe의 `trace_height_z`
- `terminal_metadata`는 계속 sentinel `{"kind": "none"}`를 쓴다.
- import/setup-ready/style/mesh/port/EM path는 `rx_plate_stack` geometry-only unsupported role guard를 그대로 유지한다.

## Acceptance
- active example RX modeled object가 `rx_plate_stack`로 parse되고, 새 두 field를 포함해도 fail-fast validation을 통과한다.
- `turn_count=3`, `metal_fill_factor=0.4` baseline에서 striped copper export가 exact-name contract를 만족한다.
- RX body count는 `3 * ferrite_set_count + 4 * turn_count + 1` 공식과 일치한다.
- stripe bbox는 wall-side `0, pitch_z, 2*pitch_z...`, coil-side `pitch_z/2, 3*pitch_z/2...` half-pitch offset을 만족한다.
- bridge bbox는 `Y=max/min` 교차 serpentine sequence와 full stack X span을 만족한다.
- sampled owner-path와 realized snapshot이 `rx_plate_stack.turn_count`, `rx_plate_stack.metal_fill_factor`를 lossless로 보존한다.
- import/setup-ready/EM은 `rx_plate_stack`를 계속 explicit unsupported role로 거부한다.
