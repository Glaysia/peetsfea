# Type2 Single-Coil Void Usage Ratio

## Intent
- Promote the centered rect/void keepout size from fixed `0.3 x 0.3` to a canonical sampled owner.
- Use one public field, `void_usage_ratio`, so local X and local Y void ratios remain equal and centered.
- Keep legacy split/centered `void_*` fields removed from active type2 public TOML.

## Implementation Contract
- `examples/type2_sweep.toml` RX single-coil uses `[modeled_objects.void_usage_ratio] range = [false, 0.2, 0.8, 10]`.
- `examples/type2_fixed.toml` keeps fixed reference behavior with `[false, 0.2, 0.2, 1]`.
- Type2 parser requires `void_usage_ratio` for single-coil modeled objects and validates realized candidates as `0 < ratio < 1`.
- `render_tx_rect_void_toml()` passes the canonical ratio to the reusable core bridge.
- Core realization applies the selected value to both `void_x_over_outer_x` and `void_y_over_outer_y`; void center ratios remain fixed at `0.0`.
- Sampling metadata includes `modeled_objects.<object_id>.void_usage_ratio` when count is not `1`.

## Tests
- Parser accepts `void_usage_ratio` and rejects missing/invalid ranges.
- Parser continues rejecting legacy `void_x_over_outer_x`, `void_y_over_outer_y`, and `void_center_*`.
- Sample manifest/sampled TOML owner paths include `void_usage_ratio` for the RX sweep.
- Core realization proves equal X/Y void ratios are selected from the field instead of the old fixed constant.
