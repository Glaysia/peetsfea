# 0.2.23 Type2 TX Wall-Parallel Ferrite Stack

## Goal
- type2 TX modeled object에 TX-only sampled `wall_parallel_stack_present` field를 추가한다.
- existing XY `tx_underlay_*` stack를 유지한 채, 같은 repeat count의 additional `YZ` wall-parallel tri-layer stack을 `tx_region` wall corridor에 추가한다.
- export/import/material styling/test contract를 새 `tx_wall_*` exact-name taxonomy까지 확장한다.

## Scope
- 포함:
  - TX-only sampled parser/runtime contract
  - TX scene-layer wall stack geometry와 fail-fast fit validation
  - export expected-body names/count extension
  - import partition/material styling exact-name extension
  - sample/build/export/import pure-Python tests
  - examples/docs/SDD note 갱신
- 제외:
  - RX geometry contract 변경
  - port-sheet geometry contract 변경
  - `tx_rect_void` core geometry/TOML bridge 변경

## Decisions
- new field: `wall_parallel_stack_present`
  - canonical sampled encoding: `[true, 0, 1, 2]`
  - fixed replay encoding: `[true, 0, 0, 1]`, `[true, 1, 1, 1]`
  - TX-only field이며 RX declaration은 즉시 fail-fast
- wall stack은 `underlay_repeat_count > 0`이고 resolved `wall_parallel_stack_present == 1`일 때만 생성한다.
- wall stack body names:
  - `tx_wall_ferrite_u{n}`
  - `tx_wall_pet_psa_u{n}`
  - `tx_wall_air_u{n}`
- wall stack은 `tx_region.max_x` wall에 붙여 `-X` 방향으로 쌓고, `u0`는 wall-adjacent first unit이다.
- unit 내부 물리 순서는 `wall -> coil = ferrite -> PET_PSA -> air`다.
- wall stack Y footprint는 `tx_region` full span을 쓰고, Z footprint는 existing XY underlay를 모두 깐 뒤 남는 하부 공간 `tx_region.min_z .. floor_underlay_min_z`를 canonical source로 쓴다.
- wall stack fit은 `modeled_max_x .. tx_region.max_x` corridor 두께와 positive remaining Z height를 동시에 만족해야 한다. 둘 중 하나라도 부족하면 geometry repair 없이 fail-fast한다.
- import/runtime은 new `tx_wall_*` exact names도 TX underlay family로 취급하고, material ownership은 existing underlay와 동일하게 유지한다.
- mesh owner는 계속 conductor-only다. `tx_wall_*` exact solids는 mesh target 바깥이다.

## Acceptance
- parser가 TX-only `wall_parallel_stack_present` canonical/fixed encoding을 허용하고 RX declaration을 reject한다.
- sampled TOML/manifest owner paths가 new TX field를 deterministic sampled owner로 포함한다.
- export expected body names가 existing `tx_underlay_*` 뒤에 deterministic `tx_wall_*` ordering을 추가한다.
- scene geometry regression이 wall contact, internal material order, remaining-space Z ownership, non-overlap을 고정한다.
- import partition/material styling tests가 `tx_wall_*` exact names를 same underlay material family로 처리하고 mesh target에 섞지 않는다.
