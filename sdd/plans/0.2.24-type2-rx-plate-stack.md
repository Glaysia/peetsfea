# 0.2.24 Type2 RX Plate Stack

## Goal
- active RX modeled object를 coil-backed `rx_single_coil`에서 geometry-only `rx_plate_stack`으로 교체한다.
- active RX export path가 `tx_rect_void` reusable coil bridge를 더 이상 호출하지 않도록 분리한다.
- 이번 패스는 `geometry/export/spec/sampled/docs`까지만 다루고, import/setup-ready/EM은 geometry-only guardrail로 막는다.

## Decisions
- active RX role/object id는 `rx_plate_stack` / `rx_plate_stack`으로 고정한다.
- RX plate stack footprint source of truth는 `rx_region_max` full `YZ` bounds다.
- stack anchor는 `rx_region_max.min_x`이고, wall-to-coil order는 다음으로 고정한다.
  1. `rx_copper_wall`
  2. `rx_pcb_wall`
  3. `rx_stack_ferrite_u0..u9`
  4. `rx_stack_pet_psa_u0..u9`
  5. `rx_stack_air_u0..u9`
  6. `rx_pcb_coil`
  7. `rx_copper_coil`
- public RX plate spec fields는 `pcb_total_thickness_mm`, `copper_thickness_mm`, `ferrite_set_count`만 가진다.
- RX plate stack terminal metadata는 port reconstruction contract를 갖지 않고 sentinel `{"kind": "none"}`만 가진다.
- setup-ready/import/style/mesh/port/EM path는 `rx_plate_stack`를 geometry-only unsupported role로 fail-fast 해야 한다.

## Acceptance
- active example RX modeled object parses as `rx_plate_stack`.
- RX scene export produces exact 34-body contract with literal 10 ferrite/PET/air sets.
- sampled owner-path collection no longer requires coil-only RX range fields.
- setup-ready/import guardrail fails with explicit geometry-only unsupported-role message when fed `rx_plate_stack`.
