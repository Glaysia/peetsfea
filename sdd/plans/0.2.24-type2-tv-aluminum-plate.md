# Type2 TV Aluminum Plate

## Goal
- Add a 0.04 mm aluminum sheet on the outer `+X` face of the existing `tv` context body.
- The plate is active modeled geometry, not a non-model guide/context object.

## Canonical Geometry
- Source owner is non-model object `tv`.
- `tv` current fixed/sweep bounds are `origin_xyz = [0.0, -921.0, 170.0]` and `size_xyz = [9.0, 1842.0, 1055.0]`.
- The plate origin is derived from the owner `+X` face: `[9.0, -921.0, 170.0]`.
- The plate size is `[0.04, 1842.0, 1055.0]`.
- The exported top-level body name is `tv_aluminum_plate`.

## Interface
- Add a modeled object table in both active examples:
  - `object_id = "tv_aluminum_plate"`
  - `role = "tv_aluminum_plate"`
  - `primitive = "box"`
  - `material = "aluminum"`
  - `model_state = true`
  - `source_non_model_object_id = "tv"`
  - `face = "+x"`
  - `thickness_mm = 0.04`
- `role = "tv_aluminum_plate"` is not sampled and must not add dataset owner paths.
- The parser must fail fast if the source object is missing, not `tv`, the face is not `+x`, material is not `aluminum`, model state is not true, primitive is not `box`, or thickness is not finite positive.

## Export And Import Contract
- STEP export creates one modeled solid named `tv_aluminum_plate` from the parsed modeled object.
- Ledger entry uses `placement_owner_id = "tv"`, `plane = "YZ"`, `material = "aluminum"`, `model_state = true`, and canonical coordinates matching the derived plate bounds.
- Backend import must treat the role as a one-body modeled object, not as a PCB/copper/ferrite partitioned coil or plate stack.
- Import validation must prove the plate is flush to `tv` `+X`, spans the full TV Y/Z bounds, and has 0.04 mm X thickness.
- Import styling sets AEDT material to `aluminum`, model state to true, and does not reconstruct ports or body groups.

## Work Split
- Spec/schema worker owns parser/types/examples/sampling constraints.
- Export worker owns STEP body construction and ledger metadata.
- Backend worker owns AEDT import validation and styling.
- Test worker owns parser/export/backend targeted regression tests and matching code notes.
