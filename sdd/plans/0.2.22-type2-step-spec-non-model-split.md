# 0.2.22 Type2 Step Spec Non-Model Split

## Goal
- Move the non-model TOML validation and parsing boundary out of `src/peetsfea/type2_step_spec.py` into `src/peetsfea/type2_step_spec_non_model.py`.
- Preserve the public import surface through `type2_step_spec.py` re-exports so downstream code does not need migration.

## Scope
- Shared TOML validation helpers used by the non-model path.
- `schema_id`, `design.units`, simulation policy, `non_model_objects`, and derived non-model load-time checks.
- Minimal wiring updates in `type2_step_spec.py`.

## Risks
- Import cycles if the new module reaches back into `type2_step_spec.py`.
- Accidental behavior drift in unsupported-key and fail-fast checks.
- Re-export omissions that would break existing type2 callers.

## Exit Criteria
- Existing type2 parser tests still pass.
- Non-model fail-fast behavior matches the pre-split contract.
- `type2_step_spec.py` remains a thin facade for the moved non-model types and loader entrypoints.
