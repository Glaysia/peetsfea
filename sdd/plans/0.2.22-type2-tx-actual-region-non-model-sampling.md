# 0.2.22 Type2 TX Actual Region Non-Model Sampling

## Summary
- Keep `tx_region` as the maximum TX reservation.
- Add `tx_region_actual` as a non-modeled, sampled actual TX region derived from `tx_region`, with optional equal X/Y grid division.
- This change does not restore TX modeled geometry, TX ports, TX sources, or TX output expressions.

## Decisions
- Public schema advances to `peetsfea.type2.step.v6`.
- `tx_region_actual` is declared in `[[non_model_objects]]` and derives from `source_region_id = "tx_region"`.
- Sampled owners are:
  - `non_model_objects.tx_region_actual.x_usage_ratio`
  - `non_model_objects.tx_region_actual.y_usage_ratio`
  - `non_model_objects.tx_region_actual.x_division_count`
  - `non_model_objects.tx_region_actual.y_division_count`
- Both sampled ranges are canonical `[false, 0.3, 1.0, 27]`; fixed examples use `[false, 0.3, 0.3, 1]`.
- Both division ranges are canonical `[true, 1, 3, 3]`; fixed examples use `[true, 1, 1, 1]`.
- Geometry is anchored at `tx_region.min_x`, centered on `tx_region` Y, and uses the full `tx_region` Z span.
- Division happens after ratio sizing. Tiles are contiguous, equal-sized, gapless, and named `tx_region_actual_x{xi}_y{yi}` when more than one tile is emitted.

## Implementation Notes
- Extend the parser with a derived non-model spec shape instead of overloading fixed box fields.
- Extend sampled owner enumeration, freezing, replay validation, and design-variable rendering to support `non_model_objects.<id>.<field>` paths.
- Extend non-model scene grouping so the scene ledger contains `environment`, `tx_region`, concrete `tx_region_actual` tile members, and `rx_region_max`.
- Keep single-tile fixed output named `tx_region_actual`; multi-tile output uses only the concrete tile names and does not emit a duplicate aggregate body.
- Existing modeled placement owners remain unchanged; future TX modeled work can explicitly opt into `tx_region_actual`.
- `src/peetsfea/type2_step_spec.py`, `src/peetsfea/type2_sampled.py`, and `src/peetsfea/type2_step_scene.py` exceed 800 lines. This patch is a narrow ownership extension, so no split is required now; future broader parser/sampler work should split first.

## Verification
- Parser tests cover schema v6, fixed and sampled `tx_region_actual`, invalid ratios/division counts, missing source region, and duplicate ids.
- Export tests verify the single-tile fixed case and a forced 3x3 tile case, including equal bounds and member ordering.
- Sample/build tests verify ratio and division owner metadata, sampled TOML freezing, and unitless design variables.
- Backend import/setup-ready tests update fixture member lists where exact non-model member names are asserted, including multi-tile compatible expectations where needed.
