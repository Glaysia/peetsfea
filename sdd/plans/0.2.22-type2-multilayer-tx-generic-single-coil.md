# 0.2.22 Type2 Multilayer TX Parallel-Bus and Generic Single-Coil Engine

## Goal
- type2 single-coil geometry/export path를 TX 전용 naming과 단층 가정에서 분리해,
  TX/RX가 같은 generalized single-coil engine 위에서 생성되도록 설계 계약을 고정한다.
- `tx_single_coil` multilayer parallel-bus milestone의 implemented contract를 고정한다.
- active `examples/type2_fixed.toml`이 TX multilayer runtime path를 실제로 통과하는 상태를 반영한다.

## Scope
- 포함:
  - generalized single-coil engine 방향
  - TX multilayer parallel-bus contract
  - RX single-layer-only support matrix
  - derived stub rule
  - type2 export/import/viewer exact-name/body-count implications
- 제외:
  - Python 구현
  - notebook/runtime fix
  - example TOML rollback
  - public docs(`docs/`) 업데이트

## Decisions
- `tx_single_coil`은 generalized single-coil core 위에서 multilayer를 지원한다.
- TX multilayer topology는 series가 아니라 parallel이다.
- 각 layer는 기존 planar coil path를 유지하고, start/end stub column을 각각 full-height vertical bus로 common한다.
- TX multilayer exported body set은 `tx_pcb_l{n}` + `tx_copper_stack`이다.
- TX multilayer external terminal은 two bottom bus faces only다.
- `rx_single_coil`은 같은 generalized engine을 공유하지만, 이 milestone에서는 single-layer-only로 유지한다.
- TX/RX geometry/export는 같은 generalized single-coil engine + role/profile adapter 구조로 정리한다.
- current TX-specific class/function/instance naming은 구조 부채이며, implementation phase에서 single-coil-neutral naming으로 일반화한다.
- stub rule은 explicit `terminal_stub_length_mm` public field가 아니라 derived `layer_gap_mm * 0.8`이다.
- stub derivation rule은 TX multilayer design contract의 일부이며, RX가 single-layer-only인 동안에도 public semantics는 shared single-coil direction을 따른다.
- current explicit `terminal_stub_length_mm` field는 implementation-era compatibility surface로만 남아 있으며, future canonical modeled-object contract에서는 제거 대상이다.

## Future Layering Contract
1. `type2_fixed.toml` modeled object registry
2. generalized single-coil parser/resolver contract
3. generalized single-coil geometry/export engine
4. role/profile adapters
   - `tx_single_coil`
   - `rx_single_coil`
5. role-specific placement contracts
6. import/ledger/EM adapter handoff

## Support Matrix
- `tx_single_coil`
  - current: multilayer parallel-bus supported
- `rx_single_coil`
  - current: single-layer only
  - covered by this note: still single-layer only

## Acceptance
- SDD notes explicitly say TX multilayer topology is parallel via two stub-column buses.
- SDD notes explicitly say TX multilayer exported names are `tx_pcb_l{n}` + `tx_copper_stack`.
- stub-length rule is recorded as `layer_gap_mm * 0.8`.
- RX exclusion from the multilayer milestone is explicit.
- generalized single-coil engine direction and TX-specific naming debt are explicit.
