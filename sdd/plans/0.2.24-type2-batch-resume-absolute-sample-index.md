# Type2 Batch Resume and Absolute Sample Index

## Goal
- Default `entry/build.py` batch builds must resume after interruption by skipping already completed sampled designs.
- Type2 sampling must name designs by absolute sample index so `SEED_FIRST=12000` starts at `s012000...`, not `s000000...`.

## Decisions
- A completed build is a prepared design with a valid STEP ledger, an existing AEDT file, and an imported ledger whose canonical path fields match the current prepared build paths.
- Partial outputs are not completion: missing AEDT, missing imported ledger, invalid imported ledger JSON, or mismatched path fields cause the normal runner to execute again.
- Resume behavior is scoped to default best-effort batch build. Debug build and solve paths remain fail-fast and do not reuse completed AEDT artifacts.
- Persistent AEDT worker process/session failures such as `Type2AedtWorkerProcessError: Persistent AEDT worker ... failed: GrpcApiError: Failed to connect to Desktop Session` should not permanently end the batch when completed designs can be resumed. Future implementation should stop the failed batch attempt, wait 60 seconds, then restart the default build loop against the same manifest so resume-ready designs are skipped and unfinished designs continue.
- Sampling `sample_index` is the absolute seed-space index, equal to `seed_start + offset`. Manifest entry order remains successful-attempt order.
- `manifest_entry_for_sample_index()` resolves by `entry["sample_index"]`, not by list offset.

## TODO
- Add a bounded restart wrapper around default `entry/build.py` type2 batch builds for persistent AEDT worker process/session failures. On the specific fatal worker exception, sleep 60 seconds before retrying the same manifest; preserve fail-fast behavior for unsupported specs and non-resumable validation errors.

## Implementation Boundaries
- Sampling ownership lives in [type2_sampled.py](../code/src/peetsfea/type2_sampled.py.md) and its entrypoint note [sample.py](../code/entry/sample.py.md).
- Batch build resume ownership lives in [type2_runtime.py](../code/src/peetsfea/type2_runtime.py.md) and default entry handoff [build.py](../code/entry/build.py.md).
- Tests must cover both serial and parallel-relevant behavior without launching GUI AEDT.
