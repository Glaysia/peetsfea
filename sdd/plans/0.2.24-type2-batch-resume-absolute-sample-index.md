# Type2 Batch Resume and Absolute Sample Index

## Goal
- Default `entry/build.py` batch builds must resume after interruption by skipping already completed sampled designs.
- Type2 sampling must name designs by absolute sample index so `SEED_FIRST=12000` starts at `s012000...`, not `s000000...`.

## Decisions
- A completed build is a prepared design whose hash-derived target `.aedt` filename already exists, or whose exact `<target>.aedt.done` marker already exists.
- The imported ledger is not part of the default resume skip decision. Missing both target AEDT output and the exact target done marker causes the normal runner to execute again.
- Changed TOML content produces a different `design_id` and target `.aedt` filename, so it does not match an existing completion and builds normally.
- Resume behavior is scoped to default best-effort batch build. Debug build and solve paths remain fail-fast and do not reuse completed AEDT artifacts.
- Persistent AEDT worker process/session failures such as `Type2AedtWorkerProcessError: Persistent AEDT worker ... failed: GrpcApiError: Failed to connect to Desktop Session` should not permanently end the batch when completed designs can be resumed. The default build loop stops the failed attempt, waits 60 seconds, then restarts against the same manifest so resume-ready designs are skipped and unfinished designs continue.
- The restart wrapper is bounded: only `Type2AedtWorkerProcessError` is retried, with at most three restarts. Unsupported specs, validation errors, artifact hash mismatches, and coordinate drift remain fail-fast.
- Sampling `sample_index` is the absolute seed-space index, equal to `seed_start + offset`. Manifest entry order remains successful-attempt order.
- `manifest_entry_for_sample_index()` resolves by `entry["sample_index"]`, not by list offset.

## Implementation Boundaries
- Sampling ownership lives in [type2_sampled.py](../code/src/peetsfea/type2_sampled.py.md) and its entrypoint note [sample.py](../code/entry/sample.py.md).
- Batch build resume ownership lives in [type2_runtime.py](../code/src/peetsfea/type2_runtime.py.md) and default entry handoff [build.py](../code/entry/build.py.md).
- Tests must cover both serial and parallel-relevant behavior without launching GUI AEDT.
