# 0.2.22 Type2 TX Plate-Stack Parallel Array

## Goal
- active `tx_plate_stack`에 TX 총 개수 자유 변수 `tx_coil_count`를 추가한다.
- `tx_coil_count`개의 TX plate-stack branches를 하나의 parallel-connected TX conductor와 하나의 TX port로 만든다.
- active `tx_single_coil` / rect-void path는 이 변경 범위에 포함하지 않는다.

## Scope
- 포함:
  - type2 schema/parser/sampling owner path
  - fixed/sweep example TOML
  - TX plate-stack array geometry, branch naming, sheet connector topology, ledger/export/import contract
  - setup-ready single TX/RX port behavior 유지
- 제외:
  - `tx_single_coil`, legacy `type1`, rect/void coil geometry
  - multi-TX independent source phases or per-branch TX ports

## Decisions
- Public field:
  - `[modeled_objects.tx_coil_count]`
  - canonical sweep `range = [true, 1, 4, 4]`
  - fixed form `range = [true, n, n, 1]`, `n in 1..4`
- Public spacing field:
  - `[modeled_objects.tx_array_x_usage_ratio]`
  - canonical sweep `range = [false, 0.1, 0.6, 14]`
  - fixed replay form `range = [false, r, r, 1]`, `0 < r <= 1`
  - `r = 1.0` means the previous full available `tx_region` X span behavior.
- `tx_coil_count = N`은 original 포함 총 TX branch count다. `N=1`은 기존 single TX plate-stack exact-name contract를 유지한다.
- `N>1`은 branch-local non-copper names를 유지하되, branch copper bodies와 인접 branch input/output connector
  bridge solids를 하나의 `tx_plate_copper` solid로 unite한다.
- 모든 TX branches는 인접 branch 쌍마다 input/output connector bridge solid를 만들어 병렬 연결한다.
  Connector는 두 terminal edge 사이의 bridge footprint를 `copper_thickness_mm` 두께로 가진 copper solid이며,
  final STEP handoff 전 `tx_plate_copper`에 포함된다. setup-ready는 기존처럼 TX port 1개와 RX port 1개만 만든다.
- `N>1` TX lumped port metadata는 전체 array envelope가 아니라 기존 0번째 branch terminal surface를 그대로 사용한다.
- X placement는 `tx_region.min_x` anchored `+X` 균등 배치다. `tx_array_x_usage_ratio`는
  `(tx_region.size_x - branch_total_thickness)`로 계산되는 full branch-origin span에 곱해 branch spacing을 줄인다.
- `N>1`에서 branch `b0`는 기존 수직 배치를 유지하고, 복제 branch `b1..b{N-1}`는 각 branch의 최상단 far-side long edge를 힌지로 삼아 free end가 RX 바닥 중심 쪽으로 내려가도록 음수 기울기로 회전한다.
- 회전 후 TX array는 X 방향으로 `tx_region`을 벗어날 수 있다. Z bounds는 계속 `tx_region` 안에 머물러야 하며, 최상단 힌지 edge는 `tx_region.max_z`에 남아야 한다.
- Z placement는 회전 전 branch active window를 `tx_region.max_z`에 top-aligned한다. 회전 후 bounding Z가 owner 밖으로 나가면 fail-fast 한다.
- schema id는 active public field 변경에 맞춰 `peetsfea.type2.step.v4`로 올린다.

## Acceptance
- Parser accepts canonical/fixed `tx_coil_count` on `tx_plate_stack`, rejects it on RX, and rejects noncanonical ranges.
- Sampling metadata includes `modeled_objects.tx_plate_stack.tx_coil_count`; sampled TOML freezes it deterministically.
- `N=1` export remains backward-compatible with current TX exact body names.
- `N=4` export produces one united `tx_plate_copper`, branch-local PCB/ferrite-family bodies, unique labels,
  exact groups, and no generic `SOLID*`.
- `N>1` export rotates only copied branches (`b1..`) with negative slope toward the RX bottom center, records the hinge/angle canonical coordinates, keeps Z bounds valid, and allows X overflow.
- Import/setup-ready paths accept the united TX conductor while keeping one TX port, one RX port,
  and conductor-only mesh targets made from `tx_plate_copper` plus `rx_plate_copper`.
- Tests cover parser/sampling, STEP geometry/ledger, import partition/style, port assignment, mesh, and single TX/RX source/report behavior.
