# 0.2.23 Rect/Void Fast Face Export

## Goal
- Replace rect/void copper authoring that extrudes many segment solids and repeatedly fuses them.
- Use a shared 2D footprint/face path for `tx_single_coil`, `rx_single_coil`, and `tx_rect_void_columns`.
- Keep exported body names, metadata, and ledger contracts stable while reducing `build_scene` time.

## Decisions
- Copper live geometry owner becomes a layer footprint built from 2D polygons, not the debug `BoxSpec` decomposition.
- Segment-level `CopperPrimitive` remains available for metadata/debug and legacy validation tests, but fast scene export must not extrude/fuse one solid per segment.
- First implemented milestone unions segment faces in 2D and extrudes the resulting layer face once. Direct single-outline polygon extraction remains a later optimization because the current spiral terminal path can make naive left/right offset outlines self-intersect.
- First milestone keeps PCB `cut(copper)` semantics to preserve zero-overlap tests and EM geometry behavior.
- `tx_rect_void_columns` must stop building base and scaled build123d scenes separately; scaling/translation happens on 2D segment faces and anchor boxes before final solid creation.
- Fast path must fail fast when outline polygons are invalid; it must not silently fall back to old segment-fuse geometry.

## Acceptance
- Existing body-name contracts remain unchanged:
  - `tx_pcb_l*`, `tx_copper_l0`, `tx_copper_stack`
  - `rx_pcb_l0`, `rx_copper_l0`
  - `txrvc_x*_y*_pcb_l*`, `txrvc_x*_y*_cu_l*`, `txrvc_x*_y*_stub_*`
- `entry/sample.py` default sample+STEP remains successful.
- Performance evidence records stage-level timing before/after for at least seed 0.
