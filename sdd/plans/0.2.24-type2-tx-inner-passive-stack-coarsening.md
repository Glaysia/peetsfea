# 0.2.24 Type2 TX Inner Passive Stack Coarsening

## Goal
- Reduce active TX inner passive body count to shorten simulation/import time.
- Preserve the fixed-example total TX inner under-coil passive stack thickness at `4.0 mm`.
- Keep RX underlay, TX outer inactive state, and active schema shape unchanged.

## Decisions
- Active TX inner examples use `underlay_repeat_count = [true, 1, 1, 1]`.
- Active TX inner examples use `underlay_pet_psa_thickness_mm = [false, 2.0, 2.0, 1]` and `underlay_ferrite_thickness_mm = [false, 2.0, 2.0, 1]`.
- Because the TX inner void stack already reuses those nominal thickness fields, fixed-example void sheets reduce from 12 bodies to 3 bodies across the same `5.6 mm` void width: `2.0`, `2.0`, and final shortened `1.6 mm`.
- No fallback behavior or alternate stack path is added.

## Sub-Agent Work Packages
- Worker A owns active examples and example SDD:
  - Primary files: `examples/type2_fixed.toml`, `examples/type2_sweep.toml`, `sdd/code/examples/type2_fixed.toml.md`, `sdd/code/examples/type2_sweep.toml.md`.
  - Change only TX inner `underlay_repeat_count`, `underlay_pet_psa_thickness_mm`, and `underlay_ferrite_thickness_mm` fixed ranges.
- Worker B owns generation/export tests and SDD:
  - Primary files: `tests/type2/test_generate_type2_step.py`, `sdd/code/tests/type2/test_generate_type2_step.py.md`.
  - Update parsed default assertions, fixed expected body names/counts, underlay geometry checks, void names, and void width expectations.
- Worker C owns active entry/build/sample/viewer tests and SDD:
  - Primary files: `tests/type2/test_setup_type2_step_entry.py`, `tests/type2/test_build_type2_entry.py`, `tests/type2/test_sample_type2_entry.py`, `tests/type2/test_refresh_type2_step_viewer_artifacts.py`, plus matching SDD notes when edited.
  - Update active example assertions and design-variable/sample expectations for the new fixed TX inner passive defaults.
- Worker D owns backend/import compatibility and SDD:
  - Primary files: `tests/backend_em/test_type2_step_setup_ready.py`, `tests/backend_em/test_type2_step_import_pipeline.py`, plus matching SDD notes only if changes are needed.
  - Confirm backend import/setup tests do not hardcode active fixed-example repeat count 4; update only direct active-contract assertions if focused tests fail.

## Acceptance
- Active examples parse TX inner passive defaults as one `2.0 mm` PET_PSA layer plus one `2.0 mm` ferrite layer.
- Fixed STEP export emits `tx_underlay_pet_psa_u0`, `tx_underlay_ferrite_u0`, `tx_void_ferrite_u0`, `tx_void_pet_psa_u0`, and `tx_void_ferrite_u1` for TX inner passive material.
- Fixed STEP export no longer emits `tx_underlay_*_u1..u3` or `tx_void_*` names beyond the 3-sheet void stack.
- Total TX inner under-coil passive stack thickness remains `4.0 mm`.
