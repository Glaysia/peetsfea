# 0.3.0 SSW AEDT Design Space Identity

## Summary
- Add a public SSW design-space API that checks whether candidate TOML ranges are inside the reference `examples/0.3.0_sweep.toml` space.
- Replace the fixed SSW AEDT project/design/file stem with a short point identity derived from realized free-variable values.
- Keep AEDT object/body names semantic and independent from the project/design/file identity.

## Contracts
- Free dimensions are the reference range owners whose `count != 1`.
- Modeled object range paths are role-qualified, such as `modeled_objects[role=tx_ssw_coil].width_ratio`.
- The AEDT design/file stem is `0_3_0_d{NNNNN}_p{HASH16}`, where `HASH16` is `blake2b(digest_size=8)` over canonical JSON of free owner paths and realized point values.
- Candidate count/grid and seed are not part of the identity hash.

## Validation
- Candidate ranges must be present for all reference free paths, match integer flags, have positive integer counts, and keep lower/upper inside the reference bounds.
- Identity generation is fail-fast and accepts only a single realized point.
- Ledger JSON records the identity metadata, while imported object/body names remain unchanged.
- The reference sweep must include the fixed example as a valid realized point; RX `turn_n_int` therefore includes `1`.
