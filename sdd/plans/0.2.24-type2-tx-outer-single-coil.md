# 0.2.24 Type2 TX Outer Single Coil

## Goal
- Add the explicit outer TX rect-void modeled geometry that pairs with the existing `tx_inner_single_coil`.
- Keep this step geometry-first: emit STEP bodies, ledger metadata, and import-compatible modeled entries while adding only the explicit TX X-position ratio sampled coordinates.
- Preserve semantic placement so later edits to `tx_region` or `tx_inner_region` move the outer coil through `tx_outer_region`, not through hardcoded coordinates.

## Decisions
- Public role/object identity is `tx_outer_single_coil` / `tx_outer_rect_void_coil`.
- Placement owner is the resolved non-modeled `tx_outer_region`.
- Outer TX geometry reuses the canonical inner TX sampled geometry/topology fields from `tx_inner_rect_void_coil`: usage ratios, trace/gap/corner/taper ranges, layer count, PCB thickness, layer gap, layer type, via behavior, and fixed zero underlay.
- Outer TX placement uses a rigid tilted frame derived from `tx_outer_region_prism`; the coil must not be warped by per-X/Y Z interpolation.
- The tilted frame maps local +X to the semantic top-edge direction from the `tx_inner_region` +X/+Z edge toward the `tx_region` +X/+Z edge, keeps local +Y parallel to world +Y, and keeps local layer stacking along the rotated local +Z normal.
- `outer_x_usage_ratio` for `tx_outer_single_coil` is interpreted against the sloped top-face length, not the axis-aligned X span of the prism bbox; `outer_y_usage_ratio` remains interpreted against the semantic Y span.
- `tx_inner_single_coil` and `tx_outer_single_coil` placement must interpret `x_position_ratio` against the selected design outer footprint center, not against the decomposed physical modeled-body bbox minimum.
- For both TX roles, the owner is the resolved placement guide (`tx_inner_region` for inner, and the prism-local virtual `tx_outer_region` frame for outer). `actual_region` is derived output and must not be used as placement input.
- The allowed center interval is `owner_min_x + design_outer_x / 2` through `owner_max_x - design_outer_x / 2`; ratio `0.0` makes the design outer min touch owner min, and ratio `1.0` makes the design outer max touch owner max.
- The physical PCB/copper body placement follows the selected design outer footprint, but the physical bbox must not define the ratio interval.
- The outer tilted frame remains the orientation frame, but it must not introduce a different X anchoring rule from TX inner placement.
- The rotated stack may protrude slightly in world +X outside the `tx_outer_region` axis-aligned bbox. This protrusion is accepted for outer TX; the implementation must still fail if Y bounds drift or the body no longer follows the semantic prism frame.
- The only new TOML selector is a fixed terminal path value for the outer companion coil. The intended fixed value is `A_cw_to_a`.
- `tx_inner_rect_void_coil.terminal_path` remains `B_cw_to_b`, and `tx_outer_rect_void_coil.terminal_path` is `A_cw_to_a`; both are intended to produce downward magnetic direction under the current geometry convention.
- `tx_inner_single_coil` owns the public sampled path `modeled_objects.tx_inner_rect_void_coil.x_position_ratio`; the active sweep default is `[false, 0.0, 0.3, 45]`, and the fixed example default is `[false, 0.0, 0.0, 1]`.
- `tx_outer_single_coil` owns exactly one public sampled path: `modeled_objects.tx_outer_rect_void_coil.x_position_ratio`. Its TOML source/freeze table remains beside the inner source object as `modeled_objects.tx_inner_rect_void_coil.tx_outer_x_position_ratio`; the active sweep default is `[false, 0.0, 0.8, 36]`, and the fixed example default is `[false, 0.0, 0.0, 1]`.
- Other `tx_outer_single_coil` sampled geometry/topology coordinates remain derived from `modeled_objects.tx_inner_rect_void_coil.*` and must not add `modeled_objects.tx_outer_rect_void_coil.*` sampled owners.
- `tx_outer_actual_region` may be emitted only after the concrete outer modeled source exists. It must be derived from the realized outer coil fit envelope, not from guide-only placeholders.
- Active setup-ready behavior must not silently create new TX excitation semantics in this step. If EM activation or parallel terminal wiring is added later, it needs a separate SDD plan and tests.

## Schema / TOML Shape
- Keep the active Type2 step schema id at `peetsfea.type2.step.v8`; the new terminal selector and TX X-position ranges extend the existing modeled-object surface.
- Prefer locating the fixed selector next to the inner TX modeled object so the dependency is explicit, for example `modeled_objects.tx_outer_terminal_path.value = "A_cw_to_a"` inside the `tx_inner_rect_void_coil` entry.
- Locate the outer X-position source range next to the inner TX modeled object as `modeled_objects.tx_inner_rect_void_coil.tx_outer_x_position_ratio`, but publish/freeze it through sampled metadata and build design variables as canonical owner `modeled_objects.tx_outer_rect_void_coil.x_position_ratio`.
- The parser must fail if the outer selector is present without exactly one `tx_inner_single_coil`, or if more than one outer companion would be implied.

## Implementation Packages
- Non-model provenance package: expose a fail-fast accessor for the creation-time `tx_outer_region_prism` so modeled placement can read semantic vertices instead of reconstructing them from STEP geometry.
- Scene/export package: realize `tx_outer_single_coil` from the inner spec plus the tilted `tx_outer_region_prism` frame, emit bodies and ledger metadata, and keep inner/RX single-coil placement on the existing axis-aligned path.
- Tests package: assert the outer modeled body normal follows the prism top face, inner TX remains axis-aligned, and moved `tx_region` cases keep the outer coil semantically attached.
- Backend compatibility package: relax `tx_outer_single_coil` bounds validation for expected world +X protrusion while preserving strict role/body/import/setup-ready behavior.

## Acceptance
- `examples/type2_fixed.toml` and `examples/type2_sweep.toml` include fixed `tx_outer_terminal_path = "A_cw_to_a"` semantics plus TX inner/outer X-position ranges.
- Sampled owner metadata and build design variables include `modeled_objects.tx_inner_rect_void_coil.x_position_ratio` and `modeled_objects.tx_outer_rect_void_coil.x_position_ratio` in deterministic owner order.
- STEP export includes `tx_outer_*` PCB/copper bodies placed by `tx_outer_region`.
- `tx_outer_*` PCB/copper bodies are tilted as a rigid stack parallel to the semantic `tx_outer_region` top face.
- TX inner and TX outer modeled coil placement use the same owner-local design-outer center contract for `x_position_ratio`.
- The ledger contains a modeled object entry for `tx_outer_rect_void_coil` with role `tx_outer_single_coil`, terminal path `A_cw_to_a`, and creation-time placement provenance.
- The ledger records enough outer tilt metadata for downstream import/debug to see the prism-driven rotation basis, angle, and accepted +X protrusion contract.
- Dataset/sample ledgers contain no sampled owner paths under `modeled_objects.tx_outer_rect_void_coil.*` except `modeled_objects.tx_outer_rect_void_coil.x_position_ratio`.
- Sampled TOML freezes the outer X-position source at `modeled_objects.tx_inner_rect_void_coil.tx_outer_x_position_ratio.range = [false, selected, selected, 1]` even though the public owner path is `modeled_objects.tx_outer_rect_void_coil.x_position_ratio`.
- Focused pure-Python tests pass from `run/`; AEDT GUI validation remains out of scope.
