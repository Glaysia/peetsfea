# ssw_step.py

- Path: `src/peetsfea/ssw_step.py`
- Responsibility: parse the 0.3.1 fixed SSW TOML surface and constraints, build a single local SSW scene context that reuses coilmaker TX/RX plus optional TX under-coil assemblies, place MULL ferrite sheets in the TV scene, and generate CadQuery STEP geometry, action-token TOML, and a JSON ledger.
- Inputs: `examples/0.3.0_fixed.toml`, including `[constraints]`, output directory, seed.
- Outputs: `coil_making_token.toml`, `ssw_scene.step`, `ssw_step_ledger.json`, artifact metadata, and PeetsFEA timing logs through the SSW STEP export stage and its coilmaker assembly subcalls when called from instrumented debug entrypoints.
- Canonical state: fixed dimensions including the TV-to-TX spacing and MULL ferrite sheet thickness, TX/RX ferrite enable flags and position ratios, TX/RX coil parameters, TX under-coil enable/normal-spiral parameters, parsed SSW constraints, RX explicit SSW-vs-normal/spiral mode, realized RX normal/spiral trace width, `tv`, derived `tx_region`, current-placement `tx_region_max`, TOML-sized `rx_region_max` non-model bounds/transparency resolved to the TV back face and bottom, role-keyed scene parts with coilmaker assemblies/placements/body boxes, SSW port-anchor world coordinates, RX normal/spiral back-side port placement, TX-under x-min YZ placement, scene action tokens, generated part names, body bounds, and body roles in the ledger.
- Invariants: TX, TX under-coil, and RX modeled objects must exist once, all ranges in fixed mode have `min == max` and `count == 1`, dimensions are positive, TOML constraints must pass before geometry generation, ferrite enable flags are frozen integer `0/1` values and do not add sampled dimensions, TX/RX `void_profile` values are fixed to scaled void profile `1` in the 0.3.1 sweep surface, TX is always an XY-plane SSW coil inside the derived `tx_region` with its port anchor on the lower `z_min` face, enabled TX under-coil always reuses the coilmaker normal/spiral path with `is_ssw_enabled=false`, fixed `1/0` quarter-turn settings, YZ-plane orientation, and placement with its X-max touching the global-X-min face of `tx_region_max`, a single scene build calls each enabled role's coilmaker assembly builder once and reuses those assemblies for bounds, token anchors, and final scene assembly, `rx_region_max` keeps its TOML Y/Z size envelope while its X max aligns to TV X max and its Z min aligns to TV Z min, RX uses a YZ-plane coil placed inside `rx_region_max` with the full modeled RX stack, not only FR4, aligned to the region Z-min face so copper protrusion remains inside the envelope, RX SSW port anchors are on the RX X-max copper face, RX may use coilmaker normal/spiral only when `is_ssw_enabled` is explicitly false, RX normal/spiral keeps quarter-turn settings in scene/action tokens with the realized port copper on the RX X-min back face and port pad size equal to realized trace width, TX MULL ferrite is created only when enabled and TX under-coil is disabled, RX MULL ferrite is created only when enabled, RX MULL ferrite placement uses `rx_mull_position_ratio` between `rx_region_max.xmin` and the RX coil X-min face, ratio `1.0` means coil-adjacent without overlap, TX main and RX long dimensions follow the Y axis while TX under-coil is thin in X and spans Y/Z, `tx_region` is larger than the TX coil and its top equals `TV bottom - fixed_dimensions.tx_rx_min_distance_mm`, `tx_region_max` follows the current TX placement with 55 mm thickness and provides the Y/Z placement envelope for the x-min under-coil, `rx_region_max` uses 5 mm thickness, token TOML is saved before STEP export, body names are unique, timing logs stay diagnostic-only with enough depth to expose the export stage and coilmaker assembly calls, and CadQuery STEP export must produce a non-empty file.
- Fail-fast points: invalid TOML tables, missing parameter ranges, unfrozen fixed values, malformed or failed SSW constraints, TX with SSW disabled, TX under-coil quarter-turn values not fixed to `1/0`, TX under-coil missing from the x-min YZ placement frame, RX spiral quarter-turn values outside the coilmaker `0..7` and `0..3` ranges, ferrite ratio outside `0..1`, ferrite remaining interval smaller than sheet thickness, duplicate modeled object IDs, missing `tv` or `tx_region`, unsupported roles, invalid geometry dimensions, non-transformer-ready action tokens, unparseable token TOML, and failed STEP export.

- Change hazards: keep RX explicit normal/spiral mode separate from fallback behavior; keep TX under-coil generation focused on reusing the existing normal/spiral path instead of adding a bespoke generator; do not let non-coprime SSW turn/twist combinations reach geometry generation; do not rotate TX main into the TV plane, move the TX port anchor off the lower face, flatten TX under-coil back onto the TX main XY plane, reintroduce TX MULL ferrite when TX under-coil is enabled, move RX normal/spiral port copper back to the X-max/front face, make RX normal/spiral semantic port edge length use the fixed pad cap instead of trace width, collapse `tx_region` into a coil-tight box, drop the sweep-maximum non-model boxes or MULL ferrite sheets from the action/export ledger, move RX out of the TV bottom region, or add fallback minimal two-port geometry.
