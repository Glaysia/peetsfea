# ssw_ports.py

- Path: `src/peetsfea/backend/pyaedt/ssw_ports.py`
- Responsibility: import an SSW AEDT-port STEP ledger into HFSS, apply the recorded 0.3.0 mesh/setup/sweep payloads, create the radiation boundary, create the two terminal lumped ports, assign the fixed debug source voltages, and create the restored Tx/Rx plus solid-loss reports required for the SSW debug path.
- Inputs: an SSW AEDT port ledger with short design identity metadata, semantic body names, copper body names, non-model/ferrite names, and TX/RX semantic copper-edge endpoint coordinates recorded at generation time.
- Outputs: an AEDT project saved to the caller-provided identity-derived path, explicit material assignment for every ledger body, copper solve-inside enablement, non-model state assignment, visual state assignment, recorded `Length1` mesh, `Region_Abs_2000mm` radiation boundary, recorded `Setup1`/`Sweep`, direct edge-based lumped-port calls, terminal excitations `1_T1` and `2_T1`, source assignments of `100V` at `0deg` on TX and `100V` at `90deg` on RX, restored Tx/Rx impedance/FOM output variables, per-model-solid `VolumeLossDensity` integral named expressions plus the air-region loss expression, reports `Results1_Pass`, `Results2_Last`, and `Results3_Freq`, and imported ledger/result identity fields.
- Canonical state: the port ledger JSON, imported ledger JSON, short AEDT identity fields, AEDT object names, mesh/boundary/setup/sweep/source summaries, report summary, output-variable names, solid-loss expression names, and HFSS excitation names after `AssignLumpedPort`.
- Invariants: callers pass output AEDT path and HFSS design name explicitly, imported STEP object names must cover every semantic ledger body, identity hashes must not be injected into imported object/body names, every body must have its ledger material assigned through `Hfss.assign_material()`, imported copper objects must have `solve_inside=True` before loss expressions are created, repository-owned `fr4` is created/configured before assignment, semantic `mull_ferrite` ledger entries are assigned as the 0.2.25 dataset-backed `MULL12060ferrite` material, non-model objects are set non-model, ferrite sheet objects must stay model objects with ferrite material, mesh uses the single recorded RX copper body for the current RX mode followed by `tx_ssw_coil_ssw_copper` with `MaxLength=1mm` and `NumMaxElem=50000`, boundary generation creates `Region_Abs_2000mm` with absolute offset and assigns radiation boundaries to all six region faces, setup/sweep use the recorded `run/mesh_analysis.py` payload values, port edge specs must contain exactly one `tx` and one `rx` role, each role must provide exactly two semantic edge endpoint pairs, each endpoint pair must match exactly one imported copper edge, port assignment must create `1_T1` and `2_T1`, source editing must use incident voltage mode with TX at `100V`/`0deg` and RX at `100V`/`90deg`, output variables keep impedance/FOM columns, omit admittance, S-parameter, and non-FOM eta columns, solid-loss expressions cover model imported solids and the radiation air region with volume integration but exclude non-model helper solids, only the three requested reports are created, `Results1_Pass` uses `Setup1 : AdaptivePass` with `Pass` as X component, `Results2_Last` uses `Setup1 : LastAdaptive` with `Freq` as X component, `Results3_Freq` uses `Setup1 : Sweep` with `Freq` as X component, and reports are created after source assignment/setup/sweep and before project save.
- Fail-fast points: missing identity/ledger keys, invalid string lists, duplicate or missing port-edge roles, failed STEP import, missing imported objects, failed material lookup/assignment/readback, failed visual assignment, failed non-model state assignment, missing recorded mesh target, failed `AssignLengthOp`, failed `create_region`, missing region faces, failed `assign_radiation_boundary_to_faces`, failed `InsertSetup`, failed `InsertFrequencySweep`, unresolved copper edges, failed `AssignLumpedPort`, missing excitation names, failed `EditSources`, failed solid-loss named expression creation, missing S-parameter traces, failed output-variable creation, failed report creation or report registration, failed project save, or failed desktop release.
