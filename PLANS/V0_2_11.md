# V0.2.11 Index

## 상태
- 상태: Planned
- 이 문서는 `0.2.11`의 상위 인덱스 문서다.
- 세부 계약은 하위 divide-and-conquer 문서가 담당하고, 이 문서는 순서와 책임만 요약한다.

## 구현 순서
- `00A -> 00B -> 00C -> 01 -> 02 -> 03`
- 선행 기반 정리
  - `00A`: sampling ownership, registry, preflight
  - `00B`: selection API simplification, resolver/pipeline refactor
  - `00C`: replay safety, dataset ledger, uniform seedset contract
- 기능 작업
  - `01`: ferrite spec path와 adaptive defaults
  - `02`: ferrite geometry, metadata, EM grouping
  - `03`: tests and acceptance

## 문서 역할
- `00A`는 sampling ownership와 hidden dimension 방지만 정의한다.
- `00B`는 selection 구조 정리와 shared API 원칙만 정의한다.
- `00C`는 `dataset.toml`, `repro.toml`, uniform seedset public contract만 정의한다.
- `01`은 ferrite spec path와 adaptive policy 기본값만 정의한다.
- `02`는 ferrite geometry/metadata 구현 의도만 정의한다.
- `03`은 위 문서들을 검증하는 테스트와 완료 정의만 담는다.
