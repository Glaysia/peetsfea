# V0.3.1

## 목표
- `dataset.toml`의 `simulation.timeout_sec`을 고정값에서 동적 계산값으로 전환한다.

## 범위
In:
- timeout 계산 규칙: `timeout_sec = A * (coil_total_region_volume_mm3^2) + B`
- `coil_total_region_volume_mm3`는 Tx+Rx 코일 영역 볼륨(mm^3)으로 고정한다.
- 하한: `7200`초 (2h)
- 상한: `18000`초 (5h)
- 상수 `A`, `B`는 고정 상수로 하드코딩한다.

Out:
- timeout 외 다른 출력 계약 변경
- 시뮬레이션 실행 로직 변경

## 출력 계약
- `dataset.toml`의 `simulation.timeout_sec`은 아래 규칙으로 계산한다.
  - `raw_timeout = A * (coil_total_region_volume_mm3 ^ 2) + B`
  - `timeout_sec = clamp(raw_timeout, 7200, 18000)`
- 상수는 아래를 사용한다.
  - `A = 0.006`
  - `B = 7200`
- `timeout_sec` 단위는 초(`sec`)로 고정한다.

## 호환성/마이그레이션
- 0.2.7의 정적 timeout(`7200`)을 사용하던 파이프라인은,
  0.2.8부터 설계 복잡도 기반 timeout을 사용한다.
- 하위 파서가 정수 timeout을 기대하는 경우 그대로 호환된다(`timeout_sec` 키 동일).

## 테스트/수용 기준
- `A=0.006`, `B=7200` 상수가 문서 계약과 일치한다.
- `A>0`이므로 `x` 증가 시 timeout이 단조 증가한다.
- `clamp` 적용으로 항상 `7200 <= timeout_sec <= 18000`을 만족한다.
- 결과 `dataset.toml`에 `simulation.timeout_sec`이 항상 존재한다.
