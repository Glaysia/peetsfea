# V0.3.3

## 목표
- `dataset.toml`에 H-field 결과 저장용 placeholder를 사전 배치한다.

## 범위
In:
- `hfield_points` 배열 추가 (길이 100)
- 각 원소 구조 고정:
  - `{x, y, z, h_re, h_im}`
- `h_re`, `h_im`는 초기 placeholder 값으로 둔다.

Out:
- 실제 H-field 계산/채움 로직
- 좌표 샘플링 방식 변경

## 출력 계약
- `dataset.toml`에 `hfield_points`를 포함한다.
- `hfield_points`는 정확히 100개 원소를 가진다.
- 각 원소는 아래 필수 키를 모두 포함한다.
  - `x` (number)
  - `y` (number)
  - `z` (number)
  - `h_re` (placeholder)
  - `h_im` (placeholder)
- 후속 시뮬레이션 파이프라인은 이 키를 열어 값으로 업데이트한다.

## 호환성/마이그레이션
- 0.2.9 형식을 확장하며 기존 키는 그대로 유지한다.
- 결과 채움 전 단계에서 placeholder 상태를 유효한 중간 산출물로 간주한다.

## 테스트/수용 기준
- `hfield_points` 길이가 100이다.
- 각 원소에 `x,y,z,h_re,h_im` 키가 모두 존재한다.
- placeholder 초기값 형식이 100개 원소에서 일관적이다.
- 후처리 단계에서 동일 키에 결과를 덮어쓸 수 있다.
