# V0.3.2

## 목표
- `dataset.toml`에 Tx/Rx 박스의 8점 좌표를 포함해 후처리/학습 입력을 강화한다.

## 범위
In:
- `tx_box.points` 추가 (8개 점)
- `rx_box.points` 추가 (8개 점)
- 좌표계 기준 명시: 월드 좌표, 단위 `mm`

Out:
- H-field placeholder 추가(0.2.10 범위)
- timeout 규칙 변경(0.2.8 범위 유지)

## 출력 계약
- `dataset.toml`에 아래 키를 포함한다.
  - `tx_box.points = [[x,y,z], ...]` (길이 8)
  - `rx_box.points = [[x,y,z], ...]` (길이 8)
- 각 좌표는 숫자형 3축 값으로 저장한다.
- 점 순서는 문서에서 고정된 규약(동일 순서)으로 유지한다.

## 호환성/마이그레이션
- 0.2.8 형식을 확장하며, 기존 키(`simulation.timeout_sec`, `output.*`)는 그대로 유지한다.
- 기존 파서가 추가 키를 무시할 수 있어야 하며, strict 파서는 스키마 업데이트가 필요하다.

## 테스트/수용 기준
- `tx_box.points`가 정확히 8점을 가진다.
- `rx_box.points`가 정확히 8점을 가진다.
- 모든 점이 `[x, y, z]` 숫자형 구조를 만족한다.
- 좌표 단위가 mm 계약과 일치한다.
