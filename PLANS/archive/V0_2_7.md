# V0.2.7

## 상태
- 상태: Done/Frozen
- 본 문서는 리팩토링 이전 완료 기준 문서로 동결한다.
- 구조개선 작업은 본 문서 완료를 전제로 `V0_3_0`에서 시작한다.

## 목표
- 시뮬레이션 실행 없이 바로 열 수 있는 `.aedt` 설계를 여러 개 생성한다.
- 산출물 단위를 `설계 1개 = zip 1개`로 표준화한다.

## 범위
In:
- `<design_id>.aedt`
- `<design_id>.repro.toml` (단일 설계 재현용, `count=1` 고정)
- `<design_id>.dataset.toml` (기존 `count!=1` 변수의 실제 선택값 기록 + 출력 placeholder + timeout 포함)
- `<design_id>.source.toml` (입력 원본 TOML 복사본)

Out:
- 시뮬레이션 실행
- 시뮬레이션 결과 채우기

## 출력 계약
- zip 파일 기본 payload는 아래 4개 파일로 고정한다.
  - `<design_id>.aedt`
  - `<design_id>.repro.toml`
  - `<design_id>.dataset.toml`
  - `<design_id>.source.toml`
- `<design_id>.repro.toml`
  - 기존 TOML과 동일 형식을 유지한다.
  - 해당 설계에 사용된 모든 가변 경로를 `count=1`로 고정한다.
  - 이 파일만으로 동일한 수치 설계를 재현할 수 있어야 한다.
- `<design_id>.dataset.toml`
  - 기존 `count!=1`이었던 변수는 실제 선택된 값으로 기록한다.
  - `output.*` 키는 모두 `-1` placeholder로 초기화한다.
  - `simulation.timeout_sec` 기본값은 `7200`(2h)으로 고정한다.
- `manifest.json`, `geometry_metadata.json`은 기본적으로 생성하지 않는다.
- 필요할 때만 옵션으로 생성 가능하도록 한다.

## 호환성/마이그레이션
- 0.2.6까지의 기본 산출물(`.aedt`, `manifest.json`, `geometry_metadata.json`) 중심 계약에서,
 0.2.7부터는 zip 단위 산출물 계약으로 전환하고 `manifest.json`, `geometry_metadata.json`은 기본 미생성으로 바꾼다.
- 기존 워크플로우에서 `.aedt`를 직접 참조하던 경로는 zip 해제 후 참조로 변경해야 한다.

## 테스트/수용 기준
- 설계 1개 실행 시 zip 1개가 생성된다.
- zip 내부에 정확히 아래 4개가 존재한다.
  - `<design_id>.aedt`
  - `<design_id>.repro.toml`
  - `<design_id>.dataset.toml`
  - `<design_id>.source.toml`
- `repro.toml`은 단일 설계 재현 계약(`count=1`)을 만족한다.
- `dataset.toml`에는 `output.*=-1`, `simulation.timeout_sec=7200`이 존재한다.
- `source.toml`은 실행 입력 원본 TOML과 바이트 동일 복사본이다.
- 기본 실행에서는 `manifest.json`, `geometry_metadata.json`이 생성되지 않는다.
- 옵션 활성화 시에만 `manifest.json`, `geometry_metadata.json` 생성이 허용된다.
