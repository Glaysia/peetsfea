0.3.0 Minimal STEP Two-Port

현재 구조는 기존 형상 생성 코드를 걷어내고, TOML의 non-model box 위에 Tx/Rx 금속 포트 셀만 생성하는 기본 EM 파이프라인이다. STEP 생성, HFSS import, mesh, terminal port, setup, sweep, report export까지 한 흐름으로 유지한다.

TOML SSOT headless AEDT fail-fast zero sampled dimensions
1 authoring TOML: examples/minimal_step_two_port.toml
2 generated port cells: Tx 1_T1, Rx 2_T1
4 mesh target copper pads recorded in minimal_step_ledger.json
0 sampled degrees of freedom in dataset.toml

Runtime Flow

모든 기본 실행은 run/에서 시작하고, sample 단계가 STEP과 manifest를 만든 뒤 build 단계가 AEDT를 설정한다.

1

TOML

minimal_step_two_port.toml에는 [design]과 [[non_model_objects]]만 남긴다.

2

Sample

entry/sample.py가 source, repro, dataset snapshot과 manifest를 쓴다.

3

STEP

minimal_step.py가 non-model body와 Tx/Rx port cell을 내보낸다.

4

Build

debug_view_step_files.py가 STEP을 생성하고 OCP CAD Viewer로 보낸다.

5

Solve

entry/build.py --solve가 Setup1을 실행하고 report CSV를 export한다.

Contracts

0.3.0의 핵심은 형상 자유도를 최소화하고, generated port 셀과 ledger 이름을 EM 쪽 계약으로 고정하는 것이다.

TOML parser

minimal_spec.py는 spec_version = "0.3.0", [design] units = "mm", non-model box만 허용한다.

  • modeled_objects, simulation, backend, constraints는 즉시 거부한다.
  • seed는 받지만 sampled dimension은 없다.

STEP exporter

minimal_step.py는 중앙 근처에 Tx/Rx 금속 포트 셀을 생성하고, canonical body name을 ledger에 기록한다.

  • 각 포트 셀은 signal pad, reference pad, vacuum port sheet로 구성된다.
  • 출력 파일은 minimal_scene.step와 minimal_step_ledger.json이다.

HFSS backend

minimal_em.py가 import 이후 mesh, terminal ports, sources, setup, sweep, report를 소유한다.

  • mesh target은 네 개 copper pad다.
  • Tx source는 1V @ 0deg, Rx source는 0V @ 0deg다.

Active Files

지금 제품 경로에 남아 있는 파일만 기준으로 정리한다. Type2와 legacy geometry surface는 active flow에서 제외한다.
