peetsfea · EM 교차검증 계획 · 6.78 MHz

4-솔버 교차검증: M3D 정전 · M3D AC 자기 · Q3D · HFSS Z-파라미터

동일한 fixed SSW 코일 형상(data/0.3.x_fixed.toml)에 대해 Maxwell 3D Electrostatic의 C, Maxwell 3D AC Magnetic의 L·R, Q3D Extractor의 R·L·C, HFSS frequency-sweep의 Z-파라미터에서 유도한 L/M/R/C가 6.78 MHz에서 서로 일치하는지 검증한다. HFSS는 실행 완료, Maxwell 3D·Q3D는 미실행(본 계획).

1. 목적과 가설

네 가지 EM 솔버가 같은 코일의 같은 양을 계산하면 동일 결과가 나와야 한다 — 이를 정량 확인.

검증 대상 양 (6.78 MHz)
  • L1, L2, M — 자기 인덕턴스(self)와 상호 인덕턴스
  • C1, C2 — TX/RX 코일 자기 캐패시턴스
  • R1, R2 — AC 직렬 저항(표피/근접 손실)
  • Z11, Z12, Z22 — 2-포트 임피던스(HFSS 1차 산출)
솔버별 1차 산출
  • M3D Electrostatic → C1, C2, 상호 Cm TODO
  • M3D AC Magnetic(Eddy@6.78MHz) → L1, L2, M, AC R1/R2 TODO
  • Q3D Extractor(AC RL + Cap) → R·L·M·C·G 일괄 TODO
  • HFSS freq sweep → Z11/Z12/Z22 → L/M/R, self-resonance로 C DONE
합격 가설: L(self/mutual)은 ±5%(M), R은 메시 민감으로 ±15%, C는 ±10% 이내 일치. 불일치 시 메시/경계/포트 정의 차이를 원인 후보로 추적. 또한 솔버별 솔브 시간(비용)을 함께 기록해 정확도–속도 trade-off를 비교한다(HFSS = 282초 기준, §8).

3. HFSS 실행 완료

Terminal-driven HFSS, Setup1 @ 6.78MHz 적응 메시 + interpolating sweep 0.1–100 MHz(81pt).

설정 (peetsfea 0.3.7)
  • 적응: MaximumPasses 11 / Minimum 8 / MinimumConverged 9, MaxDeltaS 0.005, PercentRefinement 23, BasisOrder 0(mixed)
  • 메시 seed: NumMaxElem 50,000 + MaxLength 1mm (RestrictLength·RestrictElem) → 적응 후 최종 156,761 tets
  • 포트: TX 1_T1, RX 2_T1 (lumped terminal), TX 100V@0°, RX 100V@90°
  • 경계: radiation, region margin 2000mm · 수렴 MaxMagDeltaS = 0.00088 (< 0.005 ✓)
  • 솔브 시간: 282초(≈4.7분) · GPU(RTX 3070, gpu_used=True) · 4 cores · 11 adaptive passes

추출식 (ω = 2π·6.78×10⁶ = 4.2599×10⁷ rad/s):

L1 = im(Z11)/ω   L2 = im(Z22)/ω   M = im(Z12)/ω
R1 = re(Z11)   R2 = re(Z22)   k = M/√(L1·L2)
C(self-res): im(Z)=0 인 f₀에서   C = 1 / ((2πf₀)²·L)

4. Maxwell 3D Electrostatic 미실행 — 계획

정전 캐패시턴스 행렬 [C] 추출 → C1, C2, Cm. (주파수 무관, DC 가정)

설정
  • Solution type: Electrostatic.
  • 재료: copper=PEC급 도체, FR4 εr≈4.4, MULL ferrite εr(데이터시트), 나머지 vacuum.
  • Region: 코일 최대치수의 ~2–3배 air box, 바깥면 Balloon 경계(무한원 기준).
  • 도체 net 정의: TX 코일 전체 = net_TX, RX 코일 전체 = net_RX(연속 도체 1개씩). under-coil은 TX와 직렬이므로 net_TX에 포함.
여기 · 행렬 · 산출
  • Excitation: 두 net에 Voltage 할당(예: TX=1V, RX=1V) 후 Parameters → Matrix(Capacitance) 정의.
  • Maxwell C-matrix [Cij] 산출 → SPICE 변환: C1 = ΣⱼC1ⱼ(net_TX 대지/무한원 self), C2 = ΣⱼC2ⱼ, Cm = −C12.
  • 비교: 위 C1/C2를 HFSS self-resonance값(16.35 / 21.62 pF) 및 Q3D Cap과 대조.
메시: 표면 근사 + 에너지기반 적응, Percent Error 1% 목표. 트레이스 모서리·트레이스간 갭·PCB 유전체 경계에서 C가 결정되므로 갭/모서리 세분이 핵심. 수렴은 ΔEnergy < 1%로 판정.

5. Maxwell 3D AC Magnetic (Eddy Current @ 6.78 MHz) 미실행 — 계획

6.78MHz 와전류 해석으로 인덕턴스 행렬 [L]과 AC 저항 추출 → L1, L2, M, R1, R2.

설정
  • Solution type: Eddy Current, Adaptive Frequency = 6.78 MHz(HFSS와 동일).
  • copper를 solid conductor로(σ=5.8e7), eddy effect ON(표피·근접 포함). ferrite는 μ/loss 데이터.
  • Region: air box + 바깥면 Zero Tangential H(또는 Balloon).
여기 · 행렬 · 산출
  • Excitation: 각 코일 단면에 Current 여기(터미널 in/out, TX·RX 각 1A). Parameters → Matrix(L) 정의.
  • 산출: L1=L11, L2=L22, M=L12; AC 저항은 옴손실 적분 Rᵢ = 2·P_loss,ᵢ / |Iᵢ|²(또는 매트릭스 R 항).
  • 비교: HFSS Z 유도값(L1=5.677, L2=4.991, M=0.1574 µH; R1=0.370, R2=0.236 Ω)과 직접 대조.
표피효과(핵심): 6.78MHz copper 표피깊이 δ ≈ 25 µm. 트레이스 두께 70 µm(0.07mm) ≈ 2.8δ이므로 두께방향 ≥3층 메시(skin-depth based / layered)가 필수 — 부족하면 R(및 일부 L)이 어긋난다. 적응 %error 0.5–1% 목표.

6. Q3D Extractor (RLCG 직접 추출) 미실행 — 계획

준정적 parasitic 추출기 — R·L·C·G를 한 도구에서. 6.78MHz는 self-resonance(~15MHz) 이하라 준정적 가정 유효 → 모든 양의 원스톱 교차검증.

설정 · net/터미널
  • 같은 STEP import. 도체를 net으로: net_TX, net_RX(연속 도체).
  • 각 net에 Source / Sink 지정(전류 입·출구 = 코일 양 끝, HFSS 포트 위치와 동일하게).
  • Setup 2종: AC RL @ 6.78 MHz + Capacitance(둘 다 한 프로젝트에서 솔브).
산출 · 비교
  • AC RL → L11=L1, L22=L2, L12=M(loop 인덕턴스), R11=R1, R22=R2(6.78MHz AC).
  • Capacitance → Maxwell C-matrix → C1, C2, Cm.
  • G(컨덕턴스) 추가 산출(유전손실 참고용).
  • 비교: L/M/R은 HFSS·M3D AC와, C는 HFSS self-res·M3D 정전과 동시 대조.
주의: Q3D 인덕턴스는 source→sink 경로 기반 loop L이므로, HFSS 포트/M3D 전류경로와 동일 경로 정의여야 비교가 성립. AC RL은 표피효과를 포함하므로 표면 메시(skin-depth) 필요. 준정적이라 방사손실은 미포함(6.78MHz에서 무시 가능).
