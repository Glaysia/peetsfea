peetsfea · EM 4-솔버 교차검증 결과 · 6.78 MHz

4-솔버 교차검증: M3D 정전 · M3D AC 자기 · Q3D · HFSS Z-파라미터

동일한 fixed SSW 코일 형상(data/0.3.x_fixed.toml)에 대해 Maxwell 3D Electrostatic의 C, Maxwell 3D AC Magnetic의 L·R, Q3D Extractor의 R·L·C, HFSS frequency-sweep의 Z-파라미터에서 유도한 L/M/R/C가 6.78 MHz에서 서로 일치하는지 검증한다. 4개 솔버 모두 실행 완료 — HFSS(§3)·Q3D(§6)·M3D Electrostatic(§4)·M3D AC Magnetic(§5).

1. 목적과 가설

네 가지 EM 솔버가 같은 코일의 같은 양을 계산하면 동일 결과가 나와야 한다 — 이를 정량 확인.

검증 대상 양 (6.78 MHz)
  • L1, L2, M — 자기 인덕턴스(self)와 상호 인덕턴스
  • C1, C2 — TX/RX 코일 자기 캐패시턴스
  • R1, R2 — AC 직렬 저항(표피/근접 손실)
  • Z11, Z12, Z22 — 2-포트 임피던스(HFSS 1차 산출)
솔버별 1차 산출
  • M3D Electrostatic → C1, C2, 상호 Cm DONE
  • M3D AC Magnetic(Eddy@6.78MHz) → L1, L2, M, AC R1/R2 DONE
  • Q3D Extractor(AC RL + Cap) → R·L·M·C·G 일괄 DONE
  • HFSS freq sweep → Z11/Z12/Z22 → L/M/R, self-resonance로 C DONE
합격 가설: L(self/mutual)은 ±5%(M), R은 메시 민감으로 ±15%, C는 ±10% 이내 일치. 불일치 시 메시/경계/포트 정의 차이를 원인 후보로 추적. 또한 솔버별 솔브 시간(비용)을 함께 기록해 정확도–속도 trade-off를 비교한다(HFSS = 282초 기준, §8).

3. HFSS 실행 완료

Terminal-driven HFSS, Setup1 @ 6.78MHz 적응 메시 + interpolating sweep 0.1–100 MHz(81pt).

설정 (peetsfea 0.3.7)
  • 적응: MaximumPasses 11 / Minimum 8 / MinimumConverged 9, MaxDeltaS 0.005, PercentRefinement 23, BasisOrder 0(mixed)
  • 메시 seed: NumMaxElem 50,000 + MaxLength 1mm (RestrictLength·RestrictElem) → 적응 후 최종 156,761 tets
  • 포트: TX 1_T1, RX 2_T1 (lumped terminal), TX 100V@0°, RX 100V@90°
  • 경계: radiation, region margin 2000mm · 수렴 MaxMagDeltaS = 0.00088 (< 0.005 ✓)
  • 솔브 시간: 282초(≈4.7분) · GPU(RTX 3070, gpu_used=True) · 4 cores · 11 adaptive passes

추출식 (ω = 2π·6.78×10⁶ = 4.2599×10⁷ rad/s):

L1 = im(Z11)/ω   L2 = im(Z22)/ω   M = im(Z12)/ω
R1 = re(Z11)   R2 = re(Z22)   k = M/√(L1·L2)
C(self-res): im(Z)=0 인 f₀에서   C = 1 / ((2πf₀)²·L)

4. Maxwell 3D Electrostatic 실행 완료

정전 캐패시턴스 행렬 [C] 추출 → C1, C2, Cm. (주파수 무관, DC 가정) — 저항은 전류가 없어 원리상 산출 불가.

HFSS→M3D Electrostatic 변환·솔브·추출 자동화 DONE
  • peetsfea backend/pyaedt/m3d_electrostatic.extract_m3d_es_capacitance() — 지오메트리 복사 → HFSS vacuum/region 잔재 제거 → 도체 자동 감지 → 전압 여기 + 접지된 air region → C-matrix 솔브 → export_matrix.
  • 접지 기준이 핵심: 도체 2개만 두면 Maxwell C-matrix가 coupling=1로 퇴화(한 코일 필드가 전부 상대 코일로 종단). air region 외곽면을 0 V 접지하면 self-C가 분리됨 → coupling 0.176(물리적).

5. Maxwell 3D AC Magnetic (Eddy Current @ 6.78 MHz) 실행 완료

6.78MHz 와전류 해석으로 loop 인덕턴스 행렬 [L]과 AC 저항 추출 → L1, L2, M, R1, R2. Q3D가 수렴 못한 AC R의 정식 기준.

HFSS→M3D AC Magnetic 변환·솔브·추출 자동화 DONE
  • peetsfea backend/pyaedt/m3d_ac_magnetic.extract_m3d_ac_magnetic_rl() — 지오메트리 복사 → 페라이트 상수 μ(135.6) → 코일별 여기·솔브·export_matrix.
  • 갭 코일 여기가 핵심 난제: 포트 갭이 있는 열린 코일은 외부 전류 터미널을 쓸 수 없음(eddy current는 도통 경로 필요). 해결 — 갭 끝면을 반대편으로 직선 압출(sweep)해 구리 브릿지를 만들고 코일과 union → 닫힌 루프, 그 안에 갭 단면 복사 시트를 inner coil terminal로 두어 순환 전류(1A)를 흘림.
  • eddy effect ON(표피·근접), 코일 mesh length로 메시 품질 확보, air region 50% padding(작으면 상호자속 잘림).

6. Q3D Extractor (RLCG 직접 추출) 실행 완료

준정적 parasitic 추출기 — R·L·C·G를 한 도구에서. 6.78MHz는 self-resonance(~15MHz) 이하라 준정적 가정 유효 → 모든 양의 원스톱 교차검증.

HFSS→Q3D 변환·솔브·추출 전부 자동화 DONE
  • peetsfea backend/pyaedt/q3d_convert.convert_hfss_to_q3d() — GUI "복사→Q3D" 플로우를 자동화(지오메트리 복사 + net 자동 인식 + Q3DSetup).
  • Source/Sink 지정 + 페라이트 6.78MHz 상수화(μr=135.6, tanδ=0.00218; Q3D는 주파수 종속 μ 미지원) 후 CG·AC RL·DC 모두 min 12 pass로 솔브(AC R 수렴 확보).
  • 행렬 추출: export_q3d_matrices() — 네이티브 ReportSetup("Q3DSetup : AdaptivePass", X=Pass) + ExportToFile로 C / AC RL / DC RL CSV를 headless 추출(PyAEDT export_matrix_data는 gRPC 모드에서 버그 → 우회).

경로 정의: Q3D 인덕턴스는 source→sink loop L이며 HFSS 포트와 동일 위치(코일 양 끝)에 지정. 준정적이라 방사손실 미포함(6.78MHz 무시 가능).

부록 A. Q3D AC 저항 수렴 탐구 — 결론: AC R 부적합

12-pass에서 AC R이 HFSS의 2~6배로 과대였던 원인을 패스 수렴으로 추적. 결론적으로 이 코일의 Q3D AC 저항은 수렴하지 않아 교차검증에 부적합하다.

적응 정제 설정 (HFSS vs Q3D)
  • HFSS: PercentRefinement = 23%, 수렴 MaxDeltaS = 0.005, min 8 pass.
  • Q3D: PerRefine = 30%(Cap/AC/DC 블록별), 수렴 PerError = 1%. 정제율은 오히려 HFSS보다 높음 → 수렴 실패는 정제율 탓이 아님.
양별 수렴 속도 (12-pass run, 최종값 ±5% 안정 진입 패스)
  • L1·L2·M: 1 pass — 기하 지배, 즉시 수렴.
  • C2: 5 pass, C1: 6 pass — 무난.
  • R1: 9 pass, R2: 12 pass — 저항만 현저히 느림.
