peetsfea · pfsolver(open-source CUDA full-wave) vs HFSS · 6.78 MHz

교차검증 계획: 오픈소스 CUDA 솔버 ⟷ HFSS 터미널 Z-파라미터

동일한 fixed SSW 코일 STEP(src/peetsfea/data/0.3.x_fixed.toml → ssw_scene.step)에 대해, HFSS terminal full-wave(이미 실측 완료)와 우리가 만들 오픈소스 CUDA full-wave 솔버 pfsolver(Palace Driven 코어, 구현 예정)가 6.78 MHz에서 같은 Z(f)·L·M·R·C·k를 내는지 검증한다. pfsolver 열은 의도적으로 빈칸으로 두고 구현 후 채운다(§4·§5). 4-솔버 준정적 비교는 별도 문서 em-cross-validation-plan.html 참고.

1. 목적과 합격 가설

둘 다 full-wave terminal-network 솔버다. 같은 형상·같은 포트·같은 주파수면 같은 Z가 나와야 한다 — 이를 정량 확인하고, HFSS 라이선스 없이 동일 결과를 재현할 수 있음을 증명한다.

검증 대상 양 (6.78 MHz)
  • Z11, Z12, Z22 — 2-포트 임피던스(양쪽 1차 산출)
  • L1, L2, M, k — im(Z)/ω 유도
  • R1, R2, Q1, Q2 — re(Z), AC 손실
  • C1, C2 / SRF — full-wave라 self-resonance 직접 산출
  • 손실·field — copper/ferrite loss, air-gap B-plane (선택)
왜 pfsolver도 full-wave인가
  • HFSS full-wave가 무조건 가장 정확(M3D AC/Electrostatic/Q3D는 실측 탈락).
  • pfsolver = Palace Driven(변위전류 포함) → E·H·C·L·손실·SRF 전부.
  • HFSS와 정식화가 같으므로 준정적 솔버보다 tight tolerance를 기대.
  • CUDA mandatory · 4-core MPI · CPU 폴백 없음.
합격 가설(full-wave↔full-wave): mesh 수렴 후 L1·L2·M ±5%, |Z| ±5%, k ±10%, C/SRF ±10%, R ±15%(표피 메시 민감) 이내 일치. Z12/Z21 부호는 port current 방향으로 추적해 공통 postprocess에서 고정. 불일치 1차 원인 후보: 메시 밀도(표피), 포트 정의, region 경계, ferrite μ 모델. 솔브 시간(비용)도 함께 기록 — HFSS 기준 282초(GPU·4코어·11 pass), pfsolver 목표 Mode 1 ≤30분.

4. pfsolver (Palace full-wave) 구현 예정 · 결과 빈칸

오픈소스 CUDA C++ 솔버. 같은 STEP을 gmsh로 메시 → Palace Driven full-wave 솔브 → port S/V/I → Z(f). 아래 표는 구현 후 채운다.

예정 설정 (HFSS와 정렬)
  • 문제 유형: Driven(주파수영역 full-wave), 6.78 MHz point + sweep 0.1–100 MHz.
  • 포트: LumpedPort ×2 (1_T1/2_T1), Z₀=50 Ω 기준, current 방향 명시.
  • 재질: copper σ=5.8e7, FR4 εr/tanδ, ferrite 복소 μ(135.6, tanδ 0.00218); vacuum region + 흡수경계.
  • 메시: gmsh(OpenCASCADE)로 STEP→tet, copper edge·port gap refine; p-refinement 적응.
  • 실행: CUDA Solver.Device=GPU + 4-core MPI, HYPRE Umpire pool override(device/unified 512 MiB).

추출식 (Palace 출력 → Z)

port-S.csv → S(f); Z = Z₀ (I+S)(I−S)⁻¹ (Z₀=50Ω 기준, 정규화)
또는 port-V.csv·port-I.csv 직접: Z_ij = V_i / I_j |(I_{k≠j}=0)
L = im(Z)/ω, R = re(Z), M = im(Z12)/ω, k = M/√(L1·L2), Q = ωL/R
C·SRF: sweep에서 im(Z)=0 인 f₀ → C = 1 / ((2πf₀)²·L)
부호 함정: S↔Z 변환과 V/I 직접 추출이 Z12/Z21 부호에서 갈릴 수 있다. 두 경로를 모두 계산해 일치시키고, HFSS와 같은 port current 방향으로 고정한 뒤에만 표를 채운다.

6. solver 구현 계획 (pfsolver)

이 교차검증을 가능케 하는 solver/ 파이프라인. 부트스트랩(빌드환경·CUDA 게이트)은 완료, 이후 ingest→post를 쌓는다.
