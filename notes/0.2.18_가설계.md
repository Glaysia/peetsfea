# 일차 573포인트에 대해 학습 / NSGA2 돌려봤음
- Ansys/Pyaedt 최신버전 시뮬레이션 세팅하는 데에 오래 걸렸음.

- Tx 수직코일 90도 돌려서도 뿌려봤을 땐 NSGA에서 도태됨 

- Tx DD코일 1겹/2겹으로 뿌렸는데 1겹만 살아남음 -> 2겹은 그냥 빼기

- Tx 수직코일 1~6겹으로 뿌렸는데 1, 2겹만 살아남음 -> 1~3겹으로 줄이기

- Rx DD코일 금속이 차지하는 비율 15~60%으로 뿌렸는데 58/60%만 살아남음 -> 상한/하한 높이기

- Tx DD코일 턴수 2턴/3턴으로 뿌렸는데 3턴만 살아남음

- [coil_shape.inner_margin_x]/[coil_shape.inner_margin_y] << 안쓰는 변수 지우기

- Tx DD코일의 영역 Z는 형상에 영향을 미치지 않음 

- 에타코일의 경우 L1 = L2 230nH, M = 12nH, k=0.05 정도
- 지금 만든 코일들은 다음과 같은 분포를 가지고 있고
    - L1: 2.2uH, $\sigma$ = 1uH
    - L2: 3.2uH, $\sigma$ = 2uH
    -  M: 33nH,  $\sigma$ = 7.8nH
    -  k: 0.01,  $\sigma$ = 0.023 

- 파레토를 M, k와 효율로 뿌렸을 때 강한 비례성을 가지고 있음

- 보통 잘 정렬된 코일의 경우 self L을 키울 때 M도 같이 증가함. 그러나 정렬되지 않은 경우 L을 키워도 M이 같은 정도로 늘지 않음

- 에타에서는 이러한 문제를 해결하기 위해 L을 줄이고 k를 높인 대신 전류를 많이 흘리는 방법을 택한 것으로 보임

- 현재 효율이 낮게 나오는 이유는 턴수를 너무 크게 잡아서 L이 크고 k가 작은 형상이 아직 학습되지 않음 
- 현재 코일 형상을 유지하고 변수 범위를 잘 정해서 데이터를 많이 모으면 M은 20~40nH, L=600nH정도로 고효율 달성할 것으로 보임

- Rx 코일 형상을 추가해서 결합을 수백에서 수천nH정도로 올리면 더 고효율 달성할 것으로 보임
